# 乙篇写作简报（供并行撰写章节使用）

本文件是写作时的共享约定，完成后会删除，不属于书的内容。

## 书与读者

乙篇《LLM 驱动的可解释决策学习：理论与学术全景》，中文，面向**没学过机器学习**但愿意把每一步弄懂的读者。目录见 `theory/src/SUMMARY.md`，导读见 `theory/src/00-guide.md`。已完成的第 1–3 章（`01-learning-problem.md`、`02-pac-learning.md`、`03-complexity-control.md`）是风格样板，动笔前至少通读第 1 章的前半部分和一个完整证明，体会写法。

## 必须遵守

1. **风格**：`STYLE.md` 全部条款。核心是"知识不打折扣，但每一步讲透"：问题 → 带数字的例子 → 一般说法 → 公式；重要公式后有"**怎么读**"（逐个解释符号并代入数字）；命题/定理后有"#### 证明（第一遍可以跳过）"，先一句"**思路**"，再分步写理由；每节末尾"### 小结"（"这一节说的是：……"）。
2. **篇幅**：比第 1–3 章收紧。每章 3–4.5 万字符；卷零每节 1.5–3 万字符。收紧靠少写重复的铺垫，不靠删掉定义、定理、证明或文献。
3. **章结构**（照第 2、3 章）：`# 第 N 章　标题` → `## 本章导引`（`### 这一章要做什么`、`### 读完这一章，你会知道`、`### 本章新词` 表、`### 需要的预备知识`）→ 正文各节 `## N.k 标题` → `## N.x 这一章在全书中的位置`（一张表：本章结论在"语言模型读事实、规则做判定"的系统里意味着什么）→ `## N.y 本章小结` → `## 练习`（★/★★/★★★ 三档，共 8–10 题）→ `## 练习提示与答案`（每题一个 `<details>` 块）→ `## 延伸`（列后续章节号）→ `## 文献`（分"教材"与"论文"，每条一句说明）。
   卷零各节用同样结构，但标题为 `# 0.k　标题`，导引小标题用"这一节要做什么"等；编号用 `定义 0.k.1`、`命题 0.k.2`、`定理 0.k.3`、`引理 0.k.4`，正文小节用 `## 0.k.1 标题`；练习 5–8 题，编号 `练习 0.k.1`。
4. **编号**：第 N 章内定义、命题、定理、引理、推论统一按出现顺序编号 `N.1, N.2, …`（定义单独一套：`定义 N.1, N.2…`；命题/定理/引理/推论共用一套），和第 2、3 章一致。
5. **贯穿例子**：生鲜售后定责。结论 S（卖家责任）、B（买家责任）、O（超出时限），必要时有"转人工"。第 1 章的 8 个案例：事实 $a$（是否在 48 小时内）、$b$（是否腐烂），案例 1–8 的 $(a,b,\text{结论})$ 为 (1,1,S)(1,1,S)(1,1,B)(1,0,B)(1,0,B)(1,0,S)(0,1,O)(0,0,O)；规则甲："不在时限内→O；否则腐烂→S；否则→B"；规则乙："不在时限内→O；否则→S"。代价矩阵行是真实、列是预测：$c(\mathrm S,\mathrm B)=3$，其余错误为 1，对角为 0。新增事实记 $p$（包装破损导致汁液渗出），只对案例 6 为 1。可以在此基础上编新的、规模更大的数字例子，但数字必须自洽。
6. **记号**（与第 1–3 章一致）：$\mathcal{X},\mathcal{Y},\mathcal{D}$；样本 $S$，大小 $n$；假设 $h$、假设空间 $\mathcal{H}$；代价 $c(y,\hat y)$（第一个参数是真实值）；风险 $R(h)$、经验风险 $\hat R_S(h)$；$\eta_k(x)=\Pr(Y=k\mid X=x)$；特征映射 $\phi$；指示函数写 `\mathbf{1}[\cdot]`（不要用 `\mathbb{1}`）；精度 $\varepsilon$、把握 $1-\delta$；$\ln$ 是自然对数。
7. **已有结论的引用**：可以引用第 1–3 章的编号结论（例如"第 2 章定理 2.7"、"第 1 章命题 1.2"）。正文里提到**后面**的章节时说"后面讲……时会讲"，具体章号只放在"延伸"里。
8. **数学必须正确**：每个数字例子用 Python 实际算一遍再写；每个证明逐步检查不等号方向与量词。不确定的文献细节（卷期号、年份）宁可少写，不要编造。
9. **渲染**（mdBook + KaTeX，并打印成 A4 PDF）：
   - 行内 `$...$`，独立公式 `$$` 单独占行。
   - 一行显示公式如果超过约 90 个 TeX 字符且含求和、积分、分式等大算符，用 `\begin{aligned} … \end{aligned}` 拆成多行。
   - Markdown 表格里的数学不要出现竖线 `|`，用 `\lvert`、`\rvert`、`\mid`、`\Vert`。
   - `<details>` 块：`<summary>…</summary>` 后空一行再写正文，正文后空一行再写 `</details>`。
   - 不要用 KaTeX 不支持的宏；`\operatorname`、`\mathfrak`、`\dfrac`、`\lceil`、`\binom`、`\underbrace`、`aligned`、`cases` 都可以用。
10. **只写自己负责的文件**。不要修改 `SUMMARY.md`、其他章节、`STYLE.md` 或本简报，也不要运行 git 命令。
