# 第 6 章　分布偏移与捷径学习

## 本章导引

### 这一章要做什么

第 1 章 1.3.4 节列出了独立同分布假设被破坏的三种方式，其中第二种是"样本和将来的分布不同"。第 1–3 章的所有保证，都是关于**训练时那个池子**的：霍夫丁不等式说测试集上的错误率离真实错误率不远，但这个"真实错误率"是在产生测试集的那个分布上算的。

规则上线以后，池子会变：

- 冬天年货季，海鲜订单突然多了起来；
- 一次冷链事故，让卖家责任的案例比例明显上升；
- 平台把售后时限从 48 小时改成了 72 小时；
- 负责读事实的语言模型换了一个新版本。

这一章回答四个问题：

1. **偏移有哪几种？** 按"联合分布的哪一部分变了"分类。对读事实的系统，还要多加一种：读取器本身变了。
2. **知道是哪种偏移时，怎样修正？** 协变量偏移用重要性加权，标签偏移用混淆矩阵估计新的类别比例。两种修正各有代价和前提。
3. **怎样发现偏移？** 两样本检验、域分类器、随时间监控。
4. **偏移让模型"抄近路"时怎么办？** 训练数据里碰巧有用、上线后失效的线索（捷径），用平均错误率看不出来。分组评估、分组稳健优化、不变性、对比集是四种应对思路。

最后，把这些工具落到"语言模型读事实、规则做判定"的系统上：读取器怎样版本化、换读取器时怎样重新测量、怎样把政策变化和测量变化分开。

### 读完这一章，你会知道

1. 协变量偏移、标签偏移、概念偏移、测量偏移的定义，以及在事实层面上，一种偏移为什么可能"看起来像"另一种。
2. 重要性加权的推导、它的方差为什么会爆炸、有效样本量怎样算、权重截断怎样在偏差和方差之间折中。
3. 标签偏移下怎样只用无标签的上线数据估计新的类别比例（黑盒偏移估计），以及怎样据此调整规则。
4. 置换检验为什么有效；域分类器的 AUC 说明了什么、没说明什么。
5. 域适应界的三项分别是什么意思。
6. 捷径学习是什么，为什么训练误差和同分布测试误差都揭示不了它。
7. 最差组误差、分组分布稳健优化的目标，以及它在平均准确率上的代价。
8. 不变因果预测和不变风险最小化的基本想法，以及后者已知的失败方式。
9. 压力测试与对比集怎样用作评估工具。
10. 换读取器、改政策时，系统应当怎样测量和记录。

### 本章新词

| 词 | 一句话解释 |
|---|---|
| 分布偏移 | 训练数据的分布和上线后遇到的分布不同 |
| 协变量偏移 | 输入的比例变了，但"给定输入，结论的比例"没变 |
| 标签偏移 | 各种结论的比例变了，但"给定结论，输入长什么样"没变 |
| 概念偏移 | "给定输入，结论的比例"本身变了，例如政策改了 |
| 测量偏移 | 输入没变，但读事实的模型或提示词变了，读出来的事实变了 |
| 重要性权重 | 一个案例在上线分布里的比例除以它在训练分布里的比例 |
| 有效样本量 | 加权以后，这批样本"相当于"多少个不加权的样本 |
| 权重截断 | 把过大的权重压到一个上限，用少量偏差换取方差的大幅下降 |
| 黑盒偏移估计 | 用一个固定分类器的混淆矩阵，从无标签数据里解出新的类别比例 |
| 两样本检验 | 检验两批数据是不是来自同一个分布 |
| 置换检验 | 把两批数据混在一起随机重分，看观察到的差异是否罕见 |
| 域分类器 | 一个专门区分"训练数据"和"上线数据"的分类器 |
| AUC | 随机取一个正例和一个负例，分类器给正例打分更高的概率 |
| 域适应界 | 用训练风险、两个分布的差距和一个"共同最优"项给上线风险定上界 |
| 捷径学习 | 学到了训练数据里碰巧有用、换个环境就失效的线索 |
| 虚假相关 | 在训练分布里成立、在关心的上线分布里不稳定的相关 |
| 最差组误差 | 在事先划好的各组里，错误率最高的那一组的错误率 |
| 切片评估 | 把测试集按某个属性切成若干片，分别报告每片的表现 |
| 分组分布稳健优化 | 训练时最小化最差组的损失，而不是平均损失 |
| 环境 | 产生数据的不同条件，例如不同月份、地区、应用版本 |
| 不变因果预测 | 找出在所有环境里与结论关系都不变的那组变量 |
| 不变风险最小化 | 学一个表示，使同一个分类器在所有环境里同时最优 |
| 压力测试 | 专门构造困难或极端的输入来检验模型 |
| 对比集 | 对测试样例做小而有意义的改动、使正确结论随之改变的一组样例 |
| 锚定集 | 一批固定不变、事实经过人工核实的案例，用来在读取器变化前后对照测量 |

## 6.1 训练时的池子与上线后的池子

### 6.1.1 一个例子

一条定责规则在夏季的数据上学好，留出测试集上的错误率是 12%。冬季年货季上线后，抽检的错误率是 20%。规则一个字都没改，错误率为什么升了？

假设案例分成两类：水果和海鲜。这条规则在水果案例上错 10%，在海鲜案例上错 30%（海鲜的描述更难读，"腥味重"可能是变质也可能是正常）。

- 夏季：水果占 90%，海鲜占 10%。平均错误率 $0.9\times0.10+0.1\times0.30=0.12$。
- 冬季：水果、海鲜各占 50%。平均错误率 $0.5\times0.10+0.5\times0.30=0.20$。

规则在每一类上的表现都没变，变的是**两类案例所占的比例**。

### 6.1.2 定义

**定义 6.1（分布偏移）** 记训练数据来自分布 $P$，上线后遇到的案例来自分布 $Q$，两者都是 $\mathcal{X}\times\mathcal{Y}$ 上的联合分布。训练样本 $S\sim P^n$。规则 $h$ 在两个分布上的风险分别是

$$
\begin{aligned}
R_P(h)&=\mathbb{E}_{(X,Y)\sim P}\big[c(Y,h(X))\big],\\
R_Q(h)&=\mathbb{E}_{(X,Y)\sim Q}\big[c(Y,h(X))\big].
\end{aligned}
$$

$P\ne Q$ 时，说发生了**分布偏移**（distribution shift，也叫 dataset shift）。

**怎么读**：$P$ 是"训练时的池子"，$Q$ 是"上线后的池子"。第 1 章的 $\mathcal{D}$ 和 $R(h)$ 在这一章分别写成 $P$ 和 $R_P(h)$。在 6.1.1 节的例子里，$R_P=0.12$，$R_Q=0.20$。

第 1–3 章的所有保证都是关于 $R_P$ 的。测试集如果也来自 $P$，它估计的还是 $R_P$；它对 $R_Q$ 什么也没保证，除非我们知道 $Q$ 和 $P$ 是怎样联系起来的。

### 6.1.3 把联合分布拆开

一个联合分布可以按两种顺序拆成两个因子：

$$
P(x,y)=P(x)\,P(y\mid x)=P(y)\,P(x\mid y).
$$

**怎么读**：第一种拆法是"先抽一个输入，再按这个输入下各结论的比例抽结论"；$P(y\mid x)$ 就是第 1 章的 $\eta_y(x)$。第二种拆法是"先抽一个结论，再抽这个结论下的输入"；$P(y)$ 是类别先验，$P(x\mid y)$ 描述"卖家责任的案例，描述一般长什么样"。

偏移的分类，就是问：从 $P$ 到 $Q$，**哪个因子变了、哪个因子没变**。只有知道某个因子没变，才能用 $P$ 的数据推断 $Q$ 上的表现。完全不加限制的 $Q$，可以和 $P$ 毫无关系，那样训练数据就没有用了。

### 小结

这一节说的是：训练分布 $P$ 和上线分布 $Q$ 不同时，前面各章的保证只管 $R_P$，不管 $R_Q$；要从 $P$ 推断 $Q$，必须知道联合分布的哪一部分保持不变。

## 6.2 偏移的四种类型

### 6.2.1 协变量偏移

**定义 6.2（协变量偏移）** 若 $Q(x)\ne P(x)$，但对所有 $x$ 有 $Q(y\mid x)=P(y\mid x)$，就说发生了**协变量偏移**（covariate shift）。

"协变量"是统计学里对输入变量的叫法。6.1.1 节的例子就是协变量偏移：输入里海鲜变多了，但同一个海鲜案例该判什么，冬夏没有区别。

售后里其他典型的协变量偏移：

- **新品类上线**：平台开始卖冻品，训练数据里几乎没有冻品案例；
- **季节**：夏天"软烂""出水"的描述多，冬天"冻伤""冻坏"的描述多；
- **用户群体变化**：一次推广带来大量新用户，描述写得更口语化。

协变量偏移的关键前提是"**同一个输入，结论的规律不变**"。只要输入里包含了决定结论的全部信息，这个前提往往合理。

### 6.2.2 标签偏移

**定义 6.3（标签偏移）** 若 $Q(y)\ne P(y)$，但对所有 $y$ 有 $Q(x\mid y)=P(x\mid y)$，就说发生了**标签偏移**（label shift，也叫先验偏移 prior shift）。

**例子**：某个产地的冷链出了事故，一周内卖家责任案例的比例从 40% 升到 60%。但"真正是卖家责任的案例，描述长什么样"没变：还是那些"到手就烂了""汁水流了一箱"。变的是各种结论的比例。

标签偏移下 $P(y\mid x)$ **会变**。由贝叶斯公式，$P(y\mid x)\propto P(x\mid y)P(y)$，先验 $P(y)$ 变了，后验也跟着变。所以标签偏移和协变量偏移是两种不同的假设，一般不会同时成立。

哪种假设更合理，取决于因果方向。粗略地说，结论"产生"输入时（先有质量问题，后有描述），标签偏移更自然；输入"产生"结论时（先有事实，再按政策定责），协变量偏移更自然。Schölkopf 等人（2012）把这称为反因果学习与因果学习的区别。

### 6.2.3 概念偏移

**定义 6.4（概念偏移）** 若存在 $x$ 使 $Q(y\mid x)\ne P(y\mid x)$，就说发生了**概念偏移**（concept shift）。

**例子**：平台把售后时限从 48 小时改成 72 小时。签收后 60 小时提出的、描述为"草莓发霉"的案例，以前判 O，现在判 S。输入一模一样，正确结论变了。

概念偏移最难处理：旧数据告诉我们的"给定输入该判什么"，有一部分作废了。没有新的标签，任何方法都不知道新的规律。好在业务里的概念偏移常常有一个**明确的来源和生效日期**：政策文件改了。这时正确的做法不是"适应"，而是直接改规则，再用新标签验证。

### 6.2.4 测量偏移

前三种偏移都是**世界**变了。在"语言模型读事实、规则做判定"的系统里，还有一种偏移来自**我们自己的仪器**。

第 1 章 1.10 节说过，规则 $g$ 只看事实 $\phi(x)$。在这类系统里，$\phi$ 是由一个读取器（模型 + 提示词 + 后处理）算出来的。记读取器版本 $v$ 读出的事实为 $\phi_v(x)$；如果读取有随机性，它是一个随机量。

**定义 6.5（测量偏移）** 规则 $g$ 是在 $(\phi_v(X),Y)$ 上学到的。上线时换成了读取器版本 $v'$。即使 $(X,Y)$ 的分布完全不变，$(\phi_{v'}(X),Y)$ 的分布也可能与 $(\phi_v(X),Y)$ 不同。这种由读取器变化引起的偏移叫作**测量偏移**（measurement shift）。

**例子**：换了一个新模型以后，它对"有点软"更敏感，更多案例被读成"腐烂"。案例本身没变，规则看到的事实变了。

测量偏移有两个特点：

1. **在事实层面，它可以伪装成任何一种偏移。** 新读取器把更多案例读成 $b=1$，在事实表里看就像 $P(b)$ 变了（像协变量偏移）；读错的方向和结论有关时，$P(y\mid b)$ 也变了（像概念偏移）。
2. **它是唯一一种我们能做对照实验的偏移。** 世界变了，我们无法让同一个案例"回到夏天"；但读取器变了，我们可以让新旧两个读取器读**同一批**案例，直接比较。6.11 节会利用这一点。

医学影像里有一个类似的概念：换了扫描设备或成像参数，同一个病人的图像就不一样了，那里叫作采集偏移（Castro、Walker、Glocker 2020）。

### 6.2.5 四种偏移放在一起

| 偏移 | 变的部分 | 不变的部分 | 售后例子 | 能否只用无标签上线数据发现 |
|---|---|---|---|---|
| 协变量偏移 | $P(x)$ | $P(y\mid x)$ | 年货季海鲜变多 | 能，输入的比例变了 |
| 标签偏移 | $P(y)$ | $P(x\mid y)$ | 冷链事故，卖家责任变多 | 通常能，输入的比例也随之变了 |
| 概念偏移 | $P(y\mid x)$ | 不一定 | 时限从 48 小时改为 72 小时 | 若 $P(x)$ 不变，不能（命题 6.8） |
| 测量偏移 | $\phi$ 本身 | $(X,Y)$ 的分布 | 换读取器模型或提示词 | 能看出读数变了；变好变坏要靠锚定集 |

### 6.2.6 输入层面的协变量偏移，在事实层面可能是概念偏移

规则看不到原始输入，只看到事实。所以真正要问的是：**在事实层面**，哪个因子不变？

先看一个例子。在"在时限内、没读出腐烂"（$a=1,b=0$）的案例里，有两种原始输入：

- 描述里提到包装破损、汁液渗出（第 1 章的事实 $p=1$），这类案例卖家责任的比例是 0.8；
- 其他案例，卖家责任的比例是 0.1。

假设原始输入层面是协变量偏移：这两种案例"各自该判什么"不变，只是比例变了。夏季训练数据里，包装破损占这一格的 5%；冬季换了一家包装供应商，这一比例升到 30%。

规则只看 $(a,b)$，它看到的是这一格里卖家责任的总比例：

- 夏季：$0.05\times0.8+0.95\times0.1=0.135$；
- 冬季：$0.30\times0.8+0.70\times0.1=0.31$。

在事实 $(a,b)$ 的层面，$P(y\mid a=1,b=0)$ 从 0.135 变成了 0.31，**看起来是概念偏移**。如果用第 1 章 1.5.2 节的代价矩阵，判 S 的门槛是 0.25（第 1 章 1.8.3 节）：夏季这一格应判 B，冬季应判 S。

一旦把 $p$ 加进事实，$(a,b,p)$ 每一格里的比例都不变，又回到了协变量偏移。

**命题 6.1** 设从 $P$ 到 $Q$ 是协变量偏移（定义 6.2）。

1. 若在 $P$ 下，$Y$ 只通过 $\phi(X)$ 依赖于 $X$，即存在 $r$ 使 $P(y\mid x)=r(y\mid\phi(x))$ 对所有 $x$ 成立，则对每个在 $P$、$Q$ 下概率都为正的事实取值 $z$，有 $Q(y\mid\phi=z)=P(y\mid\phi=z)$。也就是说，在事实层面仍是协变量偏移。
2. 否则，一般有

$$
Q(y\mid\phi=z)=\sum_{x:\,\phi(x)=z}P(y\mid x)\,Q(x\mid\phi=z),
$$

它随 $Q(x\mid\phi=z)$ 的变化而变化，在事实层面表现为概念偏移。

**怎么读**：第 1 条的条件"$Y$ 只通过 $\phi(X)$ 依赖于 $X$"，就是"事实够用"：知道了事实，原始输入里再没有关于结论的额外信息。这时表示误差（第 1 章 1.11 节）为零。第 2 条说：事实不够用时，事实格子内部"哪种原始输入多"的变化，会改变格子里结论的比例。

#### 证明（第一遍可以跳过）

**思路**：按"事实取值为 $z$"这个条件，对格子里的原始输入求平均。

1. 由全概率公式，对任一分布（$P$ 或 $Q$）：$\Pr(y\mid\phi=z)=\sum_{x:\phi(x)=z}\Pr(y\mid x)\Pr(x\mid\phi=z)$。这里用到了"$\phi(x)=z$ 由 $x$ 决定"，所以给定 $x$ 时再加上条件 $\phi=z$ 不改变 $\Pr(y\mid x)$。
2. 协变量偏移下 $Q(y\mid x)=P(y\mid x)$，代入第 1 步的 $Q$ 版本就得到第 2 条的公式。
3. 在第 1 条的条件下，格子里每个 $x$ 都有 $P(y\mid x)=r(y\mid z)$，与 $x$ 无关，可以提出求和号：$Q(y\mid\phi=z)=r(y\mid z)\sum_xQ(x\mid\phi=z)=r(y\mid z)$。同样的计算对 $P$ 给出 $P(y\mid\phi=z)=r(y\mid z)$，两者相等。$\square$

这个命题把"事实够不够用"和"对偏移稳不稳"联系了起来：**补全事实，不只降低表示误差，也让规则对输入比例的变化更稳健。**

### 小结

这一节说的是：协变量偏移是输入的比例变了，标签偏移是结论的比例变了，概念偏移是输入与结论的关系变了，测量偏移是读事实的仪器变了；规则只看事实，事实不够用时，输入层面的协变量偏移在事实层面会表现为概念偏移。

## 6.3 协变量偏移的修正：重要性加权

### 6.3.1 问题与例子

回到 6.1.1 节。假设我们知道冬季的品类比例（这是结构化字段，上线后马上能统计出来），但还没有冬季的标签。能不能只用夏季的带标签数据，估计规则在冬季的错误率？

能。夏季有 1000 个带标签的案例：900 个水果、100 个海鲜。冬季两类各占一半。想让夏季样本"看起来像冬季"，就给每个案例一个权重：

- 水果：冬季比例 0.5，夏季比例 0.9，权重 $0.5/0.9\approx0.556$；
- 海鲜：冬季比例 0.5，夏季比例 0.1，权重 $0.5/0.1=5$。

海鲜案例在夏季太少，每个要"顶" 5 个；水果太多，每个只算半个多。加权以后，水果的总权重是 $900\times0.556=500$，海鲜是 $100\times5=500$，正好各占一半。

用加权后的平均错误率估计冬季错误率。若规则在 900 个水果上错 90 个、在 100 个海鲜上错 30 个：

$$
\frac{1}{1000}\big(0.556\times90+5\times30\big)=\frac{50+150}{1000}=0.20 .
$$

正是 6.1.1 节算出的 $R_Q=0.20$。

### 6.3.2 一般结论

**定义 6.6（重要性权重）** 设 $Q(x)>0$ 时总有 $P(x)>0$。输入 $x$ 的**重要性权重**是

$$
w(x)=\frac{Q(x)}{P(x)}.
$$

**怎么读**：$w(x)$ 是"这种输入在上线池子里的比例，是在训练池子里的几倍"。文献里常把两个分布的密度记作 $q$、$p$，写成 $w=q/p$；这里用大写，避免与第 1 章的事实 $p$ 混淆。例子里 $w(\text{水果})\approx0.556$，$w(\text{海鲜})=5$。

条件"$Q(x)>0$ 时 $P(x)>0$"叫作**支撑条件**：上线时会出现的输入，训练时也必须有机会出现。

**定理 6.2（重要性加权恒等式）** 设从 $P$ 到 $Q$ 是协变量偏移，且支撑条件成立。则对任意规则 $h$，

$$
R_Q(h)=\mathbb{E}_{(X,Y)\sim P}\big[w(X)\,c(Y,h(X))\big].
$$

因此，对不依赖于样本的 $h$，加权经验风险

$$
\hat R_{w}(h)=\frac1n\sum_{i=1}^nw(x_i)\,c(y_i,h(x_i))
$$

是 $R_Q(h)$ 的无偏估计。

**怎么读**：左边是我们想要、却没有标签去算的上线风险；右边是在训练分布上算的"加权平均代价"。定理说两者相等。直观上，权重把训练池子里每种输入的比例"改写"成上线池子里的比例；而"给定输入时结论的比例"两边一样，不需要改。

#### 证明（第一遍可以跳过）

**思路**：把期望写成"先对输入求和，再对结论求和"，然后在输入的比例上乘以 $P(x)/P(x)$。

为了记号简单，设输入是离散的（连续时把求和换成积分）。

1. 按定义，$R_Q(h)=\sum_xQ(x)\sum_yQ(y\mid x)\,c(y,h(x))$。
2. 协变量偏移下 $Q(y\mid x)=P(y\mid x)$，代入。
3. 只对 $Q(x)>0$ 的 $x$ 求和（其余项为 0）；由支撑条件，这些 $x$ 都有 $P(x)>0$，可以写 $Q(x)=P(x)\cdot\frac{Q(x)}{P(x)}=P(x)\,w(x)$。
4. 于是 $R_Q(h)=\sum_xP(x)\sum_yP(y\mid x)\,w(x)\,c(y,h(x))=\mathbb{E}_P[w(X)c(Y,h(X))]$。
5. 无偏性：$h$ 固定时，各项 $w(x_i)c(y_i,h(x_i))$ 独立同分布，期望都等于第 4 步的值；平均值的期望等于期望的平均值（第 1 章命题 1.1 的证明）。$\square$

这个想法在统计学里叫**重要性抽样**。把它用于协变量偏移下的学习，系统的讨论始于 Shimodaira（2000）。训练时也可以用同样的权重：在加权经验风险上做经验风险最小化，挑出的规则就是在为 $Q$ 而不是为 $P$ 优化。

**支撑条件不成立时，没有任何权重能救。** 如果冬季出现了夏季完全没有的品类（比如冻品），$P(\text{冻品})=0$，权重是无穷大。训练数据对这部分案例一无所知，只能去收集新的标签。

### 6.3.3 方差的代价

定理 6.2 说加权估计**平均而言**是对的。但它的波动可能很大。

同一个例子，把冬季海鲜的比例从 0.5 改成 0.9。权重变成：

- 水果：$0.1/0.9\approx0.111$；
- 海鲜：$0.9/0.1=9$。

冬季的真实错误率是 $0.9\times0.30+0.1\times0.10=0.28$。加权估计仍然无偏，但现在**几乎全部的信息都来自那 100 个海鲜案例**：它们的总权重是 900，水果总共只有 100。我们有 1000 个案例，可实际上只是在用 100 个案例估计。

**定义 6.7（有效样本量）** 对一组权重 $w_1,\dots,w_n$，

$$
n_{\mathrm{eff}}=\frac{\big(\sum_{i=1}^nw_i\big)^2}{\sum_{i=1}^nw_i^2}.
$$

**怎么读**：分子是"权重之和的平方"，分母是"权重平方之和"。所有权重相等时 $n_{\mathrm{eff}}=n$；权重越不均匀，$n_{\mathrm{eff}}$ 越小。它的意思是：用这组权重对 $n$ 个独立同分布、方差为 $\sigma^2$ 的量求加权平均 $\sum w_iZ_i/\sum w_i$，方差是 $\sigma^2\sum w_i^2/(\sum w_i)^2=\sigma^2/n_{\mathrm{eff}}$，和 $n_{\mathrm{eff}}$ 个样本的普通平均一样。这个量来自抽样调查，常称为 Kish 有效样本量（Kish 1965）。

**代入例子**（$n=1000$，900 个水果、100 个海鲜）：

| 冬季海鲜比例 | 水果权重 | 海鲜权重 | $\sum w_i$ | $\sum w_i^2$ | $n_{\mathrm{eff}}$ |
|---|---|---|---|---|---|
| 0.1（无偏移） | 1 | 1 | 1000 | 1000 | 1000 |
| 0.5 | 0.556 | 5 | 1000 | 2778 | 360 |
| 0.9 | 0.111 | 9 | 1000 | 8111 | 123 |

偏移越大，有效样本量越小。海鲜比例为 0.9 时，1000 个案例只相当于 123 个。

**命题 6.3（权重的矩与估计的方差）** 在定理 6.2 的条件下：

1. $\mathbb{E}_P[w(X)]=1$；
2. $\mathbb{E}_P[w(X)^2]=\sum_xQ(x)^2/P(x)$，它总是不小于 1，等于 1 当且仅当 $Q(x)=P(x)$ 对所有 $x$ 成立；
3. 若代价取值于 $[0,C]$，则对固定的 $h$，$\operatorname{Var}\big[\hat R_w(h)\big]\le C^2\,\mathbb{E}_P[w(X)^2]/n$。

**怎么读**：第 1 条说权重平均是 1，所以 $\sum w_i$ 大约是 $n$。第 2 条的 $\mathbb{E}_P[w^2]$ 衡量两个分布差多远：它减去 1 叫作 $Q$ 相对于 $P$ 的 $\chi^2$ 散度（$\chi$ 读作"卡"）。第 3 条说加权估计的方差，最多是"没有加权时的上界 $C^2/n$"乘以 $\mathbb{E}_P[w^2]$。粗略地，$n_{\mathrm{eff}}\approx n/\mathbb{E}_P[w^2]$。例子里，海鲜比例 0.5 时 $\mathbb{E}_P[w^2]=0.9\times0.556^2+0.1\times5^2\approx2.78$，$1000/2.78=360$；比例 0.9 时约为 8.11，$1000/8.11\approx123$，与上表一致。

#### 证明（第一遍可以跳过）

1. $\mathbb{E}_P[w]=\sum_xP(x)\frac{Q(x)}{P(x)}=\sum_xQ(x)=1$（求和只在 $P(x)>0$ 上进行，由支撑条件，这已经包含了 $Q$ 的全部概率）。
2. $\mathbb{E}_P[w^2]=\sum_xP(x)\frac{Q(x)^2}{P(x)^2}=\sum_x\frac{Q(x)^2}{P(x)}$。由第 1 条和"方差非负"，$\mathbb{E}_P[w^2]\ge(\mathbb{E}_P[w])^2=1$；等号当且仅当 $w$ 是常数，即 $w\equiv1$，$Q=P$。
3. 各项 $Z_i=w(x_i)c(y_i,h(x_i))$ 独立同分布，所以 $\operatorname{Var}[\hat R_w]=\operatorname{Var}[Z_1]/n\le\mathbb{E}[Z_1^2]/n$。又 $c^2\le C^2$，所以 $\mathbb{E}[Z_1^2]\le C^2\mathbb{E}_P[w^2]$。$\square$

用标准差感受一下：海鲜比例 0.9 时，加权估计的标准差约为 0.049；如果手里有 1000 个**冬季**带标签案例，直接估计的标准差只有约 0.014。加权估计的标准差是后者的三倍多。

Cortes、Mansour、Mohri（2010）给出了重要性加权下的泛化界，起关键作用的正是 $\mathbb{E}_P[w^2]$ 这类量（他们用 Rényi 散度表示）：它无界时，加权学习可能完全没有保证。

### 6.3.4 权重截断

一个常用的折中是**权重截断**：选一个上限 $M$，用 $\tilde w=\min(w,M)$ 代替 $w$，并做**自归一化**：

$$
\tilde R(h)=\frac{\sum_i\tilde w_i\,c(y_i,h(x_i))}{\sum_i\tilde w_i}.
$$

**怎么读**：$\tilde w$（读作"$w$ 波浪"）是截断后的权重；除以权重之和是为了让截断后的权重仍然"加起来相当于 $n$ 个案例"。截断后的估计不再无偏，因为海鲜被压低了分量；但大权重不再支配一切，方差下降。

**代入例子**（海鲜比例 0.9，真值 0.28）：取 $M=3$，海鲜权重从 9 压到 3，水果权重 0.111 不变。按每类的平均错误率算，估计值是

$$
\begin{aligned}
\tilde R&=\frac{900\times0.111\times0.10+100\times3\times0.30}{900\times0.111+100\times3}\\
&=\frac{10+90}{100+300}=0.25,
\end{aligned}
$$

偏低 0.03；有效样本量从 123 升到 176。

值不值得？用模拟算一下均方根误差（估计值与真值之差的平方的平均，再开方；两种估计都做自归一化，重复抽样 20 万次）：

- 训练样本 $n=200$：不截断约 0.093，截断约 0.084。截断更好。
- 训练样本 $n=1000$：不截断约 0.041，截断约 0.046。不截断更好。

样本少时，方差是主要矛盾，截断划算；样本多时，方差已经不大，截断引入的偏差反而成了主要误差。这是第 3 章偏差-方差权衡的又一个例子。$M$ 本身也是一个要用数据选择的设置。

还有一种更直接的做法：**不加权，而是去收集一些上线分布的标签**。如果 $\mathbb{E}_P[w^2]$ 很大，花钱标注 100 个冬季案例，往往比对 1000 个夏季案例做复杂的加权更有效。

### 小结

这一节说的是：协变量偏移下，按 $w=Q(x)/P(x)$ 给训练案例加权，可以无偏地估计上线风险（定理 6.2）；但权重越不均匀，有效样本量越小，方差随 $\mathbb{E}_P[w^2]$ 增大（命题 6.3）；截断权重以少量偏差换取方差下降；支撑条件不成立时，加权无能为力。

## 6.4 标签偏移的修正

### 6.4.1 加权与后验调整

标签偏移下，"给定结论，输入长什么样"不变，变的只是 $P(y)$。和 6.3 节同样的推导，只是把权重放在结论上。

**定理 6.4（标签偏移下的加权与后验调整）** 设从 $P$ 到 $Q$ 是标签偏移，$Q(y)>0$ 时 $P(y)>0$。记 $w(y)=Q(y)/P(y)$。则

$$
\begin{aligned}
R_Q(h)&=\mathbb{E}_P\big[w(Y)\,c(Y,h(X))\big],\\
Q(y\mid x)&=\frac{w(y)\,P(y\mid x)}{\sum_kw(k)\,P(k\mid x)} .
\end{aligned}
$$

**怎么读**：第一个式子：给训练案例按"它的结论在上线时变多了几倍"加权，就能估计上线风险。第二个式子：已知训练分布下的 $\eta_y(x)=P(y\mid x)$，乘上各结论的权重再归一化，就得到上线分布下的 $\eta$。这个调整公式常归于 Saerens、Latinne、Decaestecker（2002）。

#### 证明（第一遍可以跳过）

1. $R_Q(h)=\sum_yQ(y)\sum_xQ(x\mid y)c(y,h(x))=\sum_yP(y)w(y)\sum_xP(x\mid y)c(y,h(x))=\mathbb{E}_P[w(Y)c(Y,h(X))]$，第二步用了 $Q(x\mid y)=P(x\mid y)$ 和 $Q(y)=P(y)w(y)$。
2. 由贝叶斯公式，$Q(y\mid x)\propto Q(x\mid y)Q(y)=P(x\mid y)P(y)w(y)\propto P(y\mid x)w(y)$，两个"$\propto$"（正比于）的比例常数都只依赖于 $x$；对 $y$ 归一化即得。$\square$

**代入例子**：只看时限内的案例，结论是 S 或 B。训练时 $P(\mathrm S)=0.4$；冷链事故后 $Q(\mathrm S)=0.6$。权重 $w(\mathrm S)=1.5$，$w(\mathrm B)=0.4/0.6\approx0.667$。第 1 章 8 个案例里，$(a,b)=(1,0)$ 那一格 $\eta_{\mathrm S}=1/3$，调整后

$$
\begin{aligned}
\eta^Q_{\mathrm S}&=\frac{1.5\times\frac13}{1.5\times\frac13+0.667\times\frac23}\\
&=\frac{0.5}{0.944}\approx0.53 .
\end{aligned}
$$

在 0-1 代价下，这一格的最优结论从 B 变成了 S，规则甲变成了规则乙。**先验变了，最优规则就可能变**，即使"每种结论的案例长什么样"一点没变。

### 6.4.2 不知道新比例时：黑盒偏移估计

上面假设知道 $Q(y)$。实际上，事故刚发生时还没有新标签。能否只用上线后的**无标签**数据估计 $Q(y)$？

**一个直接的想法**：看规则在上线后判 S 的比例。训练时规则判 S 的比例是 0.41，上线后变成 0.54，那么 $Q(\mathrm S)\approx0.54$？不对。规则会犯错，判 S 的比例不等于真实是 S 的比例。

**例子**。设上线规则 $f$（只看时限内的部分）在训练分布的带标签留出数据上表现为：真实 S 的案例，80% 判 S；真实 B 的案例，15% 判 S。把"判为 $i$、真实为 $j$"在训练分布中的比例排成一张表：

| | 真实 S | 真实 B |
|---|---|---|
| 判 S | $0.8\times0.4=0.32$ | $0.15\times0.6=0.09$ |
| 判 B | $0.2\times0.4=0.08$ | $0.85\times0.6=0.51$ |

标签偏移下，"真实是 S 的案例，规则有多少比例判 S"不变，因为它只取决于 $P(x\mid y)$。所以上线后判 S 的比例是

$$
Q(f=\mathrm S)=0.8\,Q(\mathrm S)+0.15\,Q(\mathrm B)=0.32\,w_{\mathrm S}+0.09\,w_{\mathrm B},
$$

最后一步把 $Q(\mathrm S)=0.4w_{\mathrm S}$、$Q(\mathrm B)=0.6w_{\mathrm B}$ 代入。判 B 的比例同理。观察到上线后判 S 的比例是 0.54，就得到两个方程：

$$
\begin{aligned}
0.32\,w_{\mathrm S}+0.09\,w_{\mathrm B}&=0.54,\\
0.08\,w_{\mathrm S}+0.51\,w_{\mathrm B}&=0.46 .
\end{aligned}
$$

两式相加得 $0.4w_{\mathrm S}+0.6w_{\mathrm B}=1$，即 $w_{\mathrm B}=(1-0.4w_{\mathrm S})/0.6$。代入第一式：$0.32w_{\mathrm S}+0.15-0.06w_{\mathrm S}=0.54$，解得 $w_{\mathrm S}=1.5$，$w_{\mathrm B}\approx0.667$，$Q(\mathrm S)=0.6$。直接看判 S 的比例（0.54）会低估事故的规模。

**定义 6.8（混淆矩阵）** 给定一个固定的分类器 $f$，它在分布 $P$ 上的**混淆矩阵** $C$ 的第 $(i,j)$ 个元素是 $C_{ij}=P(f(X)=i,\;Y=j)$。

**定理 6.5（黑盒偏移估计）** 设从 $P$ 到 $Q$ 是标签偏移，$f$ 是不依赖于上线数据的固定分类器。记 $\mu_i=Q(f(X)=i)$。则

$$
\mu_i=\sum_jC_{ij}\,w_j\quad\text{对所有 }i,\qquad\text{即 }\mu=Cw .
$$

若 $C$ 可逆，则 $w=C^{-1}\mu$，$Q(y)=P(y)\,w_y$。

**怎么读**：$\mu$（读作"缪"）是上线后"规则判成各结论的比例"，可以从无标签数据直接数出来；$C$ 从训练分布的带标签留出数据估计；解线性方程组就得到权重。这个方法叫**黑盒偏移估计**（Black Box Shift Estimation，BBSE），由 Lipton、Wang、Smola（2018）提出。"黑盒"的意思是：$f$ 不需要准确，也不需要输出校准的概率，只要它的混淆矩阵可逆。

#### 证明（第一遍可以跳过）

1. 全概率公式：$Q(f=i)=\sum_jQ(f=i\mid Y=j)\,Q(j)$。
2. $f$ 是固定的函数，$f(X)$ 在 $Y=j$ 下的分布由 $X$ 在 $Y=j$ 下的分布决定；标签偏移下后者在 $P$、$Q$ 中相同，所以 $Q(f=i\mid Y=j)=P(f=i\mid Y=j)$。
3. 代入 $Q(j)=P(j)w_j$：$Q(f=i)=\sum_jP(f=i\mid Y=j)P(j)w_j=\sum_jC_{ij}w_j$。$\square$

**误差有多大**？二分类时解可以写成 $Q(\mathrm S)=(\mu_{\mathrm S}-0.15)/(0.8-0.15)$，这是分类计数文献中的"调整计数"（Forman 2008）。分母 0.65 是两种真实结论下"判 S 比例"之差。上线后若只有 500 个无标签案例，$\hat\mu_{\mathrm S}$ 的标准差约为 $\sqrt{0.54\times0.46/500}\approx0.022$，$Q(\mathrm S)$ 的估计标准差放大为 $0.022/0.65\approx0.034$。分类器越接近"瞎猜"，分母越小，$C$ 越接近不可逆，估计越不稳定。Lipton 等人的误差界正是与 $C$ 的最小奇异值成反比。$C$ 本身也是估计出来的，会再贡献一部分误差；解出的权重偶尔为负，实践中截到 0。

估计出 $w$ 以后，可以用定理 6.4 估计上线风险：规则 $f$ 的错误率在训练分布上是 $0.4\times0.2+0.6\times0.15=0.17$，加权估计得 $0.4\times1.5\times0.2+0.6\times0.667\times0.15=0.18$；在代价矩阵 $c(\mathrm S,\mathrm B)=3$ 下，平均代价从 0.33 升到 0.42。

**前提要检查**：BBSE 依赖"$P(x\mid y)$ 不变"。如果事故带来了新的描述方式（比如"冰袋全化了"以前没出现过），那就同时有协变量偏移，解出的比例会有偏差。

### 小结

这一节说的是：标签偏移下，按 $Q(y)/P(y)$ 加权可以估计上线风险，后验比例按同样的权重调整（定理 6.4）；新比例未知时，可以用一个固定规则的混淆矩阵和上线后的判定比例解线性方程组（定理 6.5）；规则越接近瞎猜，解越不稳定。

## 6.5 发现偏移

修正之前先要知道有没有偏移。这一节的三种工具都只用无标签的上线数据，或者只用读出来的事实。

### 6.5.1 两样本检验与置换检验

**问题**：夏季训练数据 200 个案例里有 60 个读出"腐烂"（30%）；上线第一周 100 个案例里有 42 个（42%）。差 12 个百分点，是偏移还是运气？

**置换检验**的想法是：如果没有偏移，300 个案例来自同一个池子，"哪 100 个属于上线周"就是随机的。于是把 300 个混在一起，随机抽 100 个当"上线周"，算一次腐烂比例之差；重复很多次，看观察到的差（0.12）在这些随机差里是否罕见。

**定义 6.9（置换检验）** 两批数据合起来记为 $Z_1,\dots,Z_N$，前 $n_1$ 个来自第一批。$T$ 是一个统计量（例如两批的均值之差的绝对值），$T_0$ 是它在原始分组上的值。独立地随机打乱 $L$ 次，得到 $T_1,\dots,T_L$。**置换 $p$ 值**是

$$
\hat p=\frac{1+\#\{l:\;T_l\ge T_0\}}{L+1}.
$$

**怎么读**：$\#\{\cdot\}$ 是满足条件的个数。$\hat p$ 是"随机分组得到的差至少和实际一样大"的比例；分子分母各加 1，是把原始分组本身也算作一次。$\hat p$ 小，说明实际分组"不像随机的"。

**代入例子**：$L=9999$ 次随机打乱，得到 $\hat p\approx0.05$（精确的超几何分布计算给出双侧 0.052）。在 5% 的水平上恰好不显著。一周 100 个案例，12 个百分点的差只是勉强能看出来；如果上线周有 400 个案例、比例同样是 42%，$p$ 值约为 0.006。

**命题 6.6（置换检验的有效性）** 若两批数据合起来是可交换的（例如全部独立同分布，即没有偏移），则对任意 $\alpha\in(0,1)$，$\Pr(\hat p\le\alpha)\le\alpha$。

**怎么读**："可交换"是说把这 $N$ 个数任意重排，联合分布不变。命题说：没有偏移时，检验错误地报告偏移的概率不超过 $\alpha$。这对任何统计量 $T$ 都成立，不需要正态近似。

#### 证明（第一遍可以跳过）

**思路**：没有偏移时，原始分组只是"又一次随机分组"，所以 $T_0$ 在 $L+1$ 个值里的排名是均匀的。

1. 固定这 $N$ 个值组成的多重集合（不看顺序）。在可交换性下，给定这个集合，实际的排列在所有排列中均匀分布；$L$ 次随机打乱也是独立、均匀的排列。所以给定集合，$T_0,T_1,\dots,T_L$ 独立同分布，从而可交换。
2. 对可交换的 $L+1$ 个数，$T_0$ 是其中第几大是均匀的（有并列时，按对 $T_0$ 不利的方式计数，只会让 $\hat p$ 更大）。$\#\{l:T_l\ge T_0\}+1$ 就是 $T_0$ 从大到小的排名（并列时取最靠后的），所以对任意整数 $k$，$\Pr\big(\#\{l:T_l\ge T_0\}+1\le k\big)\le k/(L+1)$。
3. 取 $k=\lfloor\alpha(L+1)\rfloor$：$\Pr(\hat p\le\alpha)=\Pr(\text{排名}\le\alpha(L+1))\le\lfloor\alpha(L+1)\rfloor/(L+1)\le\alpha$。对多重集合取平均，结论不变。$\square$

**两点提醒**：第一，同时检验很多个事实，必然有一些"碰巧显著"，这是后面讲多重检验时要处理的问题。第二，高维输入（整段描述）上可以用核两样本检验（Gretton 等人 2012）等方法；Rabanser、Günnemann、Lipton（2019）的系统比较发现，对一个固定模型的输出分布做低维检验，往往就很有效。

### 6.5.2 域分类器

另一种办法是把"发现偏移"变成一个分类问题：把训练数据标为 0、上线数据标为 1，训练一个**域分类器**去区分它们，在留出的部分上看它分得开分不开（Lopez-Paz、Oquab 2017）。

衡量"分得开"常用 AUC。

**定义 6.10（AUC）** 一个打分函数 $s$ 的 **AUC** 是：从上线数据随机取一个案例、从训练数据随机取一个案例，前者得分更高的概率，得分相同时记一半：$\mathrm{AUC}=\Pr(s(X_Q)>s(X_P))+\tfrac12\Pr(s(X_Q)=s(X_P))$。

**怎么读**：完全分不开时 AUC 为 0.5，完全分开时为 1。

**例子**：水果和海鲜。夏季海鲜 10%，冬季 50%，域分类器只看品类，给海鲜打 1 分、水果打 0 分。冬季案例得分更高，只能是"冬季抽到海鲜、夏季抽到水果"，概率 $0.5\times0.9=0.45$；得分相同的概率是 $0.5\times0.1+0.5\times0.9=0.5$。$\mathrm{AUC}=0.45+0.25=0.70$。

域分类器还顺便给出了重要性权重。

**命题 6.7（用域分类器估计权重）** 把 $n_P$ 个训练输入和 $n_Q$ 个上线输入合在一起，记 $d(x)$ 为"输入为 $x$ 的案例来自上线数据"的比例。则

$$
w(x)=\frac{Q(x)}{P(x)}=\frac{n_P}{n_Q}\cdot\frac{d(x)}{1-d(x)}.
$$

**怎么读**：$d/(1-d)$ 是域分类器给出的"来自上线数据"的赔率。例子里两批数据一样多，海鲜的 $d=0.5/(0.1+0.5)\approx0.833$，赔率 5，正是 6.3 节的权重。

**证明（第一遍可以跳过）.** 合并后，输入为 $x$ 的案例里，来自上线的有 $n_QQ(x)$ 份，来自训练的有 $n_PP(x)$ 份，所以 $d(x)=n_QQ(x)/(n_QQ(x)+n_PP(x))$，$d/(1-d)=n_QQ(x)/(n_PP(x))$，移项即得。$\square$

实践中 $d$ 是估计出来的。$d$ 接近 1 时，一点估计误差就让权重剧烈变化，这又是需要截断的原因。

**AUC 接近 0.5 说明什么？** 只能说明"这个域分类器、在这么多数据上，分不开两批**输入**"。它不说明没有偏移，原因有二：分类器可能不够强、样本可能不够多；更根本的是下面这一条。

**命题 6.8（无标签数据看不见纯粹的概念偏移）** 若 $Q(x)=P(x)$ 对所有 $x$ 成立，而 $Q(y\mid x)\ne P(y\mid x)$，则任何只使用无标签上线输入的检验，检出偏移的概率都不超过它在"没有偏移"时误报的概率。

**证明（第一遍可以跳过）.** 检验只看到上线输入，而上线输入的分布 $Q(x)$ 与没有偏移时完全相同，所以检验结果的分布也完全相同。$\square$

时限从 48 小时改为 72 小时，输入的分布一点没变，任何只看输入的监控都发现不了。概念偏移只能靠**标签**（抽检、复核、投诉）或**政策变更记录**来发现。

### 6.5.3 随时间监控

上线以后，偏移是持续的过程。最朴素也最有用的做法，是按周画出几个比例：

- **判定的分布**：S、B、O、转人工各占多少；
- **事实的分布**：每个事实读成 1 的比例；
- **未知率**：每个事实读成"无法判断"的比例。

给每个比例画一条基线和一个波动带。设基线比例 $p_0=0.30$，每周 $m=400$ 个案例，没有偏移时周比例的标准差约为 $\sqrt{0.3\times0.7/400}\approx0.023$。"基线加减三个标准差"的带子是 $[0.23,0.37]$，落在带子外就值得调查。这是质量控制里的控制图。

监控的局限在 6.11 节会看到：**事实的比例可能一点不变，规则的错误率却大幅上升**。

### 小结

这一节说的是：置换检验通过随机重分判断两批数据的差异是否罕见，在没有偏移时误报率可控（命题 6.6）；域分类器的 AUC 衡量两批输入分得开的程度，它的赔率还给出重要性权重（命题 6.7）；但只看输入永远发现不了纯粹的概念偏移（命题 6.8）；上线后应持续监控判定、事实和未知率的比例。

## 6.6 域适应界

知道偏移存在以后，能否给上线风险一个上界？Ben-David 等人（2010）给出了一个经典的结果。

**定义 6.11（$\mathcal{H}\Delta\mathcal{H}$ 距离）** 设二分类、0-1 代价。两个输入分布 $P_X$、$Q_X$ 之间的 **$\mathcal{H}\Delta\mathcal{H}$ 距离**是

$$
\begin{aligned}
&d_{\mathcal{H}\Delta\mathcal{H}}(P_X,Q_X)\\
&\quad=2\sup_{h,h'\in\mathcal{H}}\Big\lvert\Pr_{P}\big(h\ne h'\big)-\Pr_{Q}\big(h\ne h'\big)\Big\rvert .
\end{aligned}
$$

**怎么读**：$\Pr_P(h\ne h')$ 是在 $P$ 下 $h(X)\ne h'(X)$ 的概率。任取两条候选规则，看它们"意见不一致"的比例在两个分布上差多少，取最大的差，再乘以 2。如果在两个分布上，任何两条规则分歧的比例都差不多，这个距离就小。它只依赖于输入，所以可以用无标签数据估计。

**定理 6.9（域适应界，Ben-David 等人 2010）** 对任意 $h\in\mathcal{H}$，

$$
\begin{aligned}
R_Q(h)&\le R_P(h)+\tfrac12\,d_{\mathcal{H}\Delta\mathcal{H}}(P_X,Q_X)+\lambda^*,\\
\lambda^*&=\min_{h'\in\mathcal{H}}\big[R_P(h')+R_Q(h')\big].
\end{aligned}
$$

这里不给证明。原文把训练分布叫"源域"$S$、上线分布叫"目标域"$T$，写作 $\varepsilon_T(h)\le\varepsilon_S(h)+\tfrac12d_{\mathcal{H}\Delta\mathcal{H}}+\lambda$。原文还给出了用有限样本估计各项时的版本，多出与 VC 维有关的项。

**怎么读**：上线风险不超过三项之和。

- **$R_P(h)$**：训练分布上的风险，可以用测试集估计。
- **$\tfrac12d_{\mathcal{H}\Delta\mathcal{H}}$**：两个输入分布在"规则看得到的差别"上差多少。只用规则空间能区分的差别，所以规则空间越简单，这一项越小。
- **$\lambda^*$**：是否存在**一条**在两个分布上都好的规则。概念偏移大时，没有一条规则能同时讨好两边，这一项就大。它涉及上线标签，无法从无标签数据估计。

这个界通常很松（6.7.1 节末尾会代入一个例子），它的价值在于**结构**：只让两个分布"看起来像"（缩小第二项）是不够的，第三项也必须小。Zhao 等人（2019）证明：当两边的类别比例不同时，强行让表示的分布在两边对齐，会抬高"两边错误率之和"的下界，也就是让第三项无法变小。

### 小结

这一节说的是：域适应界把上线风险拆成训练风险、两个输入分布在规则眼中的距离、以及"是否存在共同的好规则"三项；第二项可用无标签数据估计，第三项不能；只缩小第二项不保证上线表现好。

## 6.7 捷径学习与虚假相关

### 6.7.1 一个例子

只看时限内的案例，结论是 S 或 B，各占一半。两个事实：

- $b$：描述是否指向腐烂。真实规律是 $P(\mathrm S\mid b=1)=0.85$，$P(\mathrm S\mid b=0)=0.15$；$b=1$ 的案例占一半。
- $u$：描述里是否出现"急"字。

在训练数据收集的那段时间，旧版应用给"已按卖家责任受理"的工单自动加上"急件"标签，并写进了描述字段。于是训练数据里，95% 的 S 案例和 5% 的 B 案例出现了"急"字。

比较两条规则：

- **规则 $h_u$**：出现"急"→ S，否则 → B；
- **规则 $h_b$**：腐烂 → S，否则 → B（规则甲在时限内的部分）。

| | 训练分布错误率 | 同分布测试集错误率 | 新版应用上线后错误率 |
|---|---|---|---|
| 规则 $h_u$ | 0.05 | 约 0.05 | 0.50 |
| 规则 $h_b$ | 0.15 | 约 0.15 | 0.15 |

新版应用去掉了自动标签，"急"字出现与否和结论无关（各一半）。规则 $h_u$ 跌到瞎猜的水平，规则 $h_b$ 纹丝不动。在 $(b,u)$ 上做经验风险最小化，在全部 16 条规则里选中的正是规则 $h_u$：它的训练错误率最低。

这种现象叫**捷径学习**（shortcut learning）：学习器找到了一条在训练分布里管用、但不是我们想要的线索。Geirhos 等人（2020）的综述收集了大量例子：识别牛的模型依赖草地背景，换到沙滩上就认不出（Beery 等人 2018）；读胸片的模型学会了认医院的标记（Zech 等人 2018）；判断两句话关系的模型只看假设句里有没有否定词（Gururangan 等人 2018；McCoy 等人 2019）。名字来自"聪明的汉斯"：一匹据说会算术的马，其实是在看提问者不自觉的表情（Pfungst 1907）。Lapuschkin 等人（2019）发现一个图像分类器靠图片角上的版权水印认"马"，并称这类模型为"聪明的汉斯预测器"。

**用域适应界看这个例子**。取 $\mathcal{H}$ 为 $(b,u)$ 上的全部 16 条规则。两条规则"意见不一致"的区域可以是四个格子的任意组合，所以 $\tfrac12d_{\mathcal{H}\Delta\mathcal{H}}$ 等于两个分布在四个格子上的比例之差的绝对值之和的一半。训练分布四格的比例是 $(0.4075,0.0925,0.0925,0.4075)$（按 $(b,u)=(0,0),(0,1),(1,0),(1,1)$），上线分布各为 0.25，算出 $0.315$。规则 $h_b$ 在两边都错 0.15，$\lambda^*=0.30$。于是定理 6.9 对规则 $h_u$ 给出 $R_Q\le0.05+0.315+0.30=0.665$（实际 0.50），对规则 $h_b$ 给出 $0.765$（实际 0.15）。界是对的，但很松，也分不出哪条规则更稳健。

### 6.7.2 为什么训练误差和测试误差都看不出来

**定义 6.12（虚假相关）** 一个事实 $u$ 与结论的相关，如果在训练分布 $P$ 中成立，但在我们关心的上线分布中不稳定，就称为**虚假相关**（spurious correlation）。

这个定义是**相对于上线分布**的。"急"字和结论的相关在旧版应用里是真实存在的，并不是统计上的偶然；它"虚假"，只是因为上线后不成立。

同分布的测试集来自 $P$，相关在那里同样成立，所以测试误差也揭示不了问题。更一般地，只要数据都来自 $P$，**无论多少**都不够：

**命题 6.10（只用训练分布的数据分不清稳定与虚假）** 在 6.7.1 节的设定下，考虑两个可能的上线分布：$Q_1=P$（"急"字的规律不变）与 $Q_2$（"急"字与结论无关，$b$ 与结论的关系不变）。对任何只使用 $P$ 中样本的方法（可以随机化），在 $Q_1$、$Q_2$ 两者中至少一个上，它选出的规则的期望超额风险不小于 $7/90\approx0.078$。

**怎么读**：超额风险是"选出的规则的上线风险减去该上线分布下 16 条规则中最好的风险"。$Q_1$ 下最好的是规则 $h_u$（0.05），$Q_2$ 下最好的是规则 $h_b$（0.15）。命题说：不管训练数据有多少，单凭它没法同时在两个世界里都做对。

**证明（第一遍可以跳过）.** 方法只看到 $P$ 的样本，所以在两个世界里选出各条规则的概率完全相同，记选中规则 $h$ 的概率为 $\pi_h$。两个世界里的期望超额风险分别是 $\sum_h\pi_he_1(h)$ 和 $\sum_h\pi_he_2(h)$，$e_k(h)$ 是 $h$ 在 $Q_k$ 下的超额风险。逐一列出 16 条规则的 $(e_1,e_2)$（可以逐条验证），对所有概率分布 $\pi$ 最小化两者中较大的那个，这是一个两个目标的线性规划，最优值为 $7/90$，在"规则 $h_b$"与"$b=1$ 或 $u=1$ 则 S"两条规则以 $5:4$ 混合时取到。只在规则 $h_u$ 和规则 $h_b$ 之间选时，最优是以 $2:7$ 混合，值同样是 $7/90$。$\square$

所以，要避免捷径，**必须引入训练分布之外的信息**：哪些分组需要照顾（6.8 节）、数据来自哪些不同的环境（6.9 节）、哪些改动不应该改变结论（6.10 节），或者直接的业务知识（"急"字不是定责依据）。在规则系统里，最后一种往往最便宜：规则是可读的，审核者一眼就能看出规则 $h_u$ 依赖了一个不该依赖的事实。这是可解释性在稳健性上的直接回报。

### 小结

这一节说的是：捷径是训练分布里真实存在、上线后失效的线索；经验风险最小化会正确地利用它，同分布的测试集也看不出问题；只靠训练分布的数据无法区分稳定的和虚假的相关，必须引入额外的信息。

## 6.8 分组稳健性

### 6.8.1 最差组误差与切片评估

在 6.7.1 节的例子里，按"结论 × 是否有'急'字"把训练数据分成四组，每组 1000 个案例中的个数是：(S, 有急) 475、(S, 无急) 25、(B, 有急) 25、(B, 无急) 475。规则 $h_u$ 在两个多数组上全对，在两个少数组上**全错**；规则 $h_b$ 在每一组上都错 15%。

**定义 6.13（最差组风险）** 设事先划好分组 $\mathcal{G}$，$P_g$ 是第 $g$ 组内的分布，$R_g(h)=\mathbb{E}_{P_g}[c(Y,h(X))]$。**最差组风险**是 $R_{\max}(h)=\max_{g\in\mathcal{G}}R_g(h)$。

规则 $h_u$ 的最差组错误率是 1，规则 $h_b$ 是 0.15。平均错误率掩盖了少数组上的彻底失败。

**切片评估**是它的实践形式：按品类、地区、渠道、应用版本、描述长度等切分测试集，分别报告每一片的错误率**和样本数**。样本数必不可少：第 2 章命题 2.5 的余量是 $\sqrt{\ln(1/\delta)/(2n)}$，一片只有 25 个案例时，95% 把握下的余量约为 0.24，小切片的错误率几乎什么也说明不了。

### 6.8.2 分组分布稳健优化

**命题 6.11** 记 $\Delta$ 为分组上所有概率分布 $q=(q_g)_{g\in\mathcal{G}}$ 的集合，则 $\max_gR_g(h)=\max_{q\in\Delta}\sum_gq_gR_g(h)$。

**证明.** 右边是若干个 $R_g$ 的加权平均，不超过其中最大的；把全部权重放在最大的那一组上就取到等号。$\square$

**怎么读**：最小化最差组风险，等于"对手先挑一个最坏的分组比例，我们再在这个比例下最小化平均风险"。上线分布如果只是**各组的比例**变了，而每组内部不变，那么最差组风险就是所有可能的上线风险的上界。

**分组分布稳健优化**（Group DRO，Sagawa、Koh、Hashimoto、Liang 2020）就是在训练时最小化

$$
\min_{h\in\mathcal{H}}\;\max_{g\in\mathcal{G}}\;\hat R_g(h),
$$

其中 $\hat R_g$ 是第 $g$ 组的经验风险。

**怎么读**：内层的 $\max$ 找出当前规则表现最差的那一组；外层的 $\min$ 在候选规则里挑"最差的那一组也不太差"的规则。普通的经验风险最小化按样本数给各组加权，例子里少数组的分量只有 5%。对神经网络，他们的算法交替做两件事：按 $q_g\leftarrow q_g\,e^{\eta_q\hat R_g}$（再归一化）调高损失大的组的权重；按当前权重的加权损失更新模型参数。

**在例子里**：对 16 条规则逐一计算最差组错误率，只有规则 $h_b$ 低于 0.85，Group DRO 选中它。**代价**是训练分布上的平均错误率从 0.05 升到 0.15：如果上线后"急"字的规律确实不变，我们白白多错了 10 个百分点。稳健性是一份保险，保费是平均准确率。

**为什么需要强正则化**？Sagawa 等人发现：对足够大的神经网络，训练损失在每一组上都能降到接近 0，这时"最差组的训练损失"也是 0，Group DRO 与普通训练没有区别；少数组的问题出在**泛化**上，测试时最差组照样很差。只有配合强的 $\ell_2$ 罚分或提前停止，Group DRO 才在最差组上显著胜出。他们还建议给小组的经验风险加上与 $1/\sqrt{n_g}$ 成正比的调整，以补偿小组的泛化余量更大。在规则系统里，对应的做法是限制规则的复杂度、要求每个分支有最低支持案例数（第 3 章）：如果事实足够多、规则足够细，规则可以把 25 个少数组案例单独背下来，训练时最差组误差为 0，上线后毫无用处。

Group DRO 需要事先知道分组。分组从哪里来，本身就是业务知识：它是 6.7.2 节说的"训练分布之外的信息"的一种。

### 小结

这一节说的是：最差组风险关注表现最差的那一组，平均风险可能掩盖少数组上的彻底失败；Group DRO 直接最小化最差组风险，等价于对所有分组比例取最坏情形；它需要事先知道分组、需要强正则化，并以平均准确率为代价。

## 6.9 不变性

### 6.9.1 多个环境

如果数据来自几个不同的**环境**（不同月份、地区、应用版本），可以比较各个环境里"事实与结论的关系"。真正决定结论的关系，在环境之间应当不变；捷径则随环境变化。

继续 6.7.1 节的例子，有两个环境：$e_1$ 是旧版应用（S 案例 95% 有"急"字，B 案例 5%），$e_2$ 是过渡期（60% 与 40%）。两个环境里 $b$ 的规律相同，$P(\mathrm S)$ 都是 0.5。各组事实下卖家责任的比例：

| 用到的事实 | $e_1$ | $e_2$ | 是否不变 |
|---|---|---|---|
| 不用任何事实 | 0.50 | 0.50 | 是 |
| $b$（$b=0$；$b=1$） | 0.15；0.85 | 0.15；0.85 | 是 |
| $u$（$u=0$；$u=1$） | 0.05；0.95 | 0.40；0.60 | 否 |
| $b,u$（四格） | 0.01，0.77，0.23，0.99 | 0.11，0.21，0.79，0.89 | 否 |

（四格按 $(b,u)=(0,0),(0,1),(1,0),(1,1)$ 排列。）

**定义 6.14（不变性）** 设有环境集合 $\mathcal{E}$。称一组事实 $T$ 在 $\mathcal{E}$ 上**不变**，如果 $P_e(y\mid\phi_T(x))$ 对所有 $e\in\mathcal{E}$ 都相同，其中 $\phi_T$ 是只取 $T$ 中事实的映射。

### 6.9.2 不变因果预测

Peters、Bühlmann、Meinshausen（2016）的**不变因果预测**（invariant causal prediction，ICP）利用了这样一个想法：如果环境的变化没有直接作用在"结论如何由其原因产生"这一机制上，那么结论的**直接原因**那一组变量 $T^*$ 一定是不变的。于是：

1. 对每个候选事实组 $T$，检验"$T$ 不变"这一假设，水平为 $\alpha$；
2. 输出所有未被拒绝的 $T$ 的交集：$\hat T=\bigcap_{T\text{ 未被拒绝}}T$。

**命题 6.12（ICP 的覆盖保证）** 若 $T^*$ 确实不变，且每个检验在原假设成立时拒绝的概率不超过 $\alpha$，则 $\Pr(\hat T\subseteq T^*)\ge1-\alpha$。

**证明（第一遍可以跳过）.** 只要 $T^*$ 没有被拒绝，它就是参与求交集的集合之一，交集一定是它的子集。$T^*$ 被（错误地）拒绝的概率不超过 $\alpha$。$\square$

**怎么读**：保证是单方面的："选出来的都是真原因"，而不是"真原因都被选出来"。原论文的主要设定是线性高斯模型，并给出了系数的置信区间；后续有非线性的推广。

**在例子里**："急"字是受理结论之后才加上的，是结论的结果而不是原因；直接原因是 $b$。按上表，"不用任何事实"和"$\{b\}$"都不变，交集是**空集**。ICP 没有说错（空集是任何集合的子集），但它什么也没告诉我们，因为两个环境的 $P(\mathrm S)$ 恰好相同。如果 $e_2$ 里腐烂的案例只占 40%，$P(\mathrm S)$ 变成 0.43，"不用任何事实"被拒绝，交集才是 $\{b\}$。**ICP 的结论强弱取决于环境之间差异的丰富程度**，而且它是保守的。

### 6.9.3 不变风险最小化

Arjovsky、Bottou、Gulrajani、Lopez-Paz（2019）的**不变风险最小化**（invariant risk minimization，IRM）把同一个想法用于学习表示：找一个表示 $\Phi$（相当于"用哪些事实、怎样组合"），使**同一个**分类器 $w$ 在每个环境里都是最优的：

$$
\begin{aligned}
&\min_{\Phi,w}\;\sum_{e\in\mathcal{E}}R^e(w\circ\Phi)\\
&\text{使得}\quad w\in\arg\min_{\bar w}R^e(\bar w\circ\Phi)\quad\text{对所有 }e .
\end{aligned}
$$

**怎么读**：$\Phi$ 把输入变成表示，$w$ 是放在表示上面的分类器，$R^e$ 是环境 $e$ 里的风险。约束说：在每个环境里单独挑最好的 $w$，挑出来的都是同一个 $w$；目标是在满足约束的表示中，让各环境风险之和最小。

这个双层问题难解，论文给出了一个近似版本 IRMv1：把 $w$ 固定为常数 1，在目标里加上 $\lambda\sum_e\big\Vert\nabla_{w}R^e(w\cdot\Phi)\big\vert_{w=1}\big\Vert^2$，即罚"在每个环境里，最上层的分类器还有没有动一动就能变好的余地"。

"同一个分类器在所有环境都最优"依赖于损失函数。用对数损失、且上层分类器足够灵活时，它要求各环境的 $P_e(y\mid\Phi)$ 相同，接近定义 6.14。用 0-1 代价时，它只要求各环境的最优**判定**相同。例子里，只用 $u$ 时 $e_1$ 的比例是 0.95/0.05，$e_2$ 是 0.60/0.40，两边的最优判定都是"有'急'字判 S"，0-1 代价下这个表示满足约束；而这条规则在 $e_2$ 里错 40%，上线后错 50%。

### 6.9.4 IRM 会失败

IRM 提出后，一系列工作指出了它的局限。

- Rosenfeld、Ravikumar、Risteski（2021）在一个线性高斯的潜变量模型里证明：**环境个数不超过虚假特征的维数时**，存在使用虚假特征、满足 IRM 约束、且训练目标更低的解，IRM 并不能恢复不变的预测器；环境个数足够多（超过虚假特征的维数，再加上非退化条件）时才能恢复。在非线性情形，他们构造了这样的解：在训练环境的数据集中出现的区域内表现得近似不变，在这片区域之外却依赖虚假特征；它近似满足 IRMv1 的目标，在离训练环境稍远的测试分布上并不比经验风险最小化好。
- Kamath 等人（2021）给出了 IRMv1 的近似罚分与原始双层目标不一致的简单例子。
- Gulrajani、Lopez-Paz（2021）在统一的评测框架下发现，仔细调参的经验风险最小化与包括 IRM 在内的多种方法表现相当。

这些结果并不说明"不变性"的想法错了，而是说明：**从有限的几个环境中，可靠地学出不变的表示，比看上去难得多。** 在事实由人设计、规则可读的系统里，更实际的用法是把不变性当作**检验**而不是训练目标：对每个事实，按环境分别看它与结论的关系，把关系不稳定的事实标出来，交给人判断。

### 小结

这一节说的是：直接原因与结论的关系在各环境间不变，捷径则随环境变化；ICP 检验每组事实是否不变并取交集，保证选出的都是真原因，但很保守；IRM 要求同一个分类器在各环境同时最优，这依赖损失函数，而且在环境不够多或非线性时会失败。

## 6.10 压力测试与对比集

前面的方法都需要上线分布的某种信息。还有一类工具不需要：**主动构造**输入，看系统的反应。

**压力测试**专门构造困难或极端的输入（Naik 等人 2018）。售后里的例子：签收 47 小时 59 分和 48 小时 01 分的案例（时限边界）；很长的描述；中英混杂、错别字很多的描述；没有照片的案例。CheckList（Ribeiro 等人 2020）把这类测试分成三种：基本功能测试、**不变性测试**（改动不应改变结论）、方向性测试（改动应使结论朝已知方向变化）。

**定义 6.15（对比集）** 对一个测试样例做小而有意义的改动，使正确结论随之改变，得到的一组样例叫作**对比集**（Gardner 等人 2020）。评估时除了逐个样例的准确率，还看**对比一致性**：一组里每个样例都判对的组所占的比例。

对比集和反事实增强数据（Kaushik、Hovy、Lipton 2020）的想法相同：只改动"应该决定结论的部分"，看系统是否跟着变；改动"不应该决定结论的部分"，看系统是否不变。在读事实的系统里，可以在两层分别做：

- **读取器层**：把描述里的"发霉了"改成"没发霉"，检查 $b$ 是否从 1 变成 0；在描述末尾加一个"急"字，检查 $b$ 是否不变。
- **规则层**：直接改动事实向量，检查判定是否符合政策。

**例子**：取 200 个时限内的案例，每个做"加'急'字 / 去'急'字"两个版本。规则 $h_u$ 在全部 200 对上判定都变了，不变性违反率 100%；规则 $h_b$ 是 0%。再看读取器（下面的数字是假设的）：200 对里有 18 对的 $b$ 读数变了，违反率 9%。按霍夫丁不等式，95% 把握下的双侧余量是 $\sqrt{\ln(2/0.05)/(2\times200)}\approx0.096$，所以真实违反率大约在 0 到 19% 之间。

压力测试和对比集的局限是：**它们只能检验人想到的改动**。它们不估计 $R_Q$，而是用来证伪：发现一个系统性失败，比报告一个平均数更有用。

### 小结

这一节说的是：压力测试与对比集通过主动构造输入来检验系统，不需要上线分布的数据；在读事实的系统里，可以分别检验读取器与规则；它们只能覆盖人想到的改动，作用是发现失败而不是估计上线风险。

## 6.11 读事实的系统怎样应对偏移

这一节把前面的工具落到"语言模型读事实、规则做判定"的系统上。

### 6.11.1 一个让人警惕的例子

时限内的案例，真实腐烂（$b=1$）占一半；$P(\mathrm S\mid b=1)=0.85$，$P(\mathrm S\mid b=0)=0.15$。规则是"读出腐烂 → S，否则 → B"。

- 旧读取器：真实腐烂时读成 1 的比例 0.95，真实不腐烂时读成 1 的比例 0.05。规则错误率 0.185。
- 新读取器：两个比例分别是 0.80 和 0.20。规则错误率 0.29。

而两个读取器读成 $b=1$ 的总比例**都是 0.5**：$0.5\times0.95+0.5\times0.05=0.5\times0.80+0.5\times0.20=0.5$。只监控事实的比例，这次升级完全看不出问题。

### 6.11.2 实践要点

**一、把读取器当作有版本号的测量仪器。** 模型标识、提示词、解码设置、把模型回答变成事实值的后处理（包括"无法判断"怎样处理）一起构成 $\phi$ 的版本。每条判定都记录（读取器版本，规则版本）。

**二、在固定的锚定集上重新测量。** 维护一批事实经过人工核实的案例。读取器每次变化，都在锚定集上重测：每个事实对金标的混淆矩阵、新旧读数的一致率、未知率，再把规则跑一遍，统计判定变化。6.11.1 节的升级在锚定集上一测便知：$b$ 的准确率从 0.95 降到 0.80。锚定集不能用来调提示词，否则它上面的成绩就被选择污染了（第 1 章命题 1.2）。锚定集本身也会老化（协变量偏移），可以定期补充新的部分，但保留旧的部分以便前后对照。

**三、监控事实分布与未知率**，按 6.5.3 节画控制图。未知率上升往往是读取器遇到新类型输入的第一个信号。监控是锚定集的补充，不是替代。

**四、把政策变化和测量变化分开。** 时限从 48 小时改为 72 小时是概念偏移，应当改规则 $g$，并记录生效日期；换读取器是测量偏移，应当在锚定集上验证 $\phi$。两者不要在同一次发布里一起变。若不得不一起变，就在锚定集上跑三种组合：（旧读取器，旧规则）、（新读取器，旧规则）、（新读取器，新规则），分别归因。举一组假设的数字：设锚定集有 400 个案例，300 个在 48 小时内，40 个在 48–72 小时之间。按 6.11.1 节的数字，并假设两个读取器在给定真实值时独立出错，新旧读数在每个案例上不一致的概率是 $0.95\times0.20+0.05\times0.80=0.23$，换读取器约改变 $300\times0.23=69$ 个判定；改政策则改变那 40 个案例（从 O 变为 S 或 B）。

**五、换读取器后，用新读取器重读历史训练数据**，再重新学习或校验规则。否则规则是在旧 $\phi$ 上学的，却用在新 $\phi$ 上。

**六、按偏移类型选工具。** 品类、地区这类结构化字段上的协变量偏移，权重可以精确计算（6.3 节）；疑似标签偏移，可以把当前规则当作黑盒，用 BBSE 估计新的结论比例（6.4 节）；政策变化只能靠新标签和变更记录（命题 6.8）。

### 小结

这一节说的是：事实的总体比例不变时，读取器的准确率也可能大幅下降；应当给读取器版本化，在固定锚定集上对照测量，监控事实分布和未知率，并把政策变化与测量变化分开发布、分开归因。

## 6.13 本章小结

- 训练分布 $P$ 与上线分布 $Q$ 不同时，前面各章的保证只管 $R_P$。按不变的部分分为协变量偏移（$P(y\mid x)$ 不变）、标签偏移（$P(x\mid y)$ 不变）、概念偏移（$P(y\mid x)$ 改变）；读事实的系统还有测量偏移（读取器改变）。事实不够用时，输入层面的协变量偏移在事实层面表现为概念偏移（命题 6.1）。
- **协变量偏移**：按 $w(x)=Q(x)/P(x)$ 加权可无偏估计 $R_Q$（定理 6.2）；方差随 $\mathbb{E}_P[w^2]$ 增大，有效样本量为 $(\sum w_i)^2/\sum w_i^2$（命题 6.3）；截断权重以偏差换方差；支撑条件不成立时无法修正。
- **标签偏移**：按 $Q(y)/P(y)$ 加权并调整后验（定理 6.4）；用固定规则的混淆矩阵解 $\mu=Cw$ 估计新比例（定理 6.5）。
- **发现偏移**：置换检验在没有偏移时误报率不超过 $\alpha$（命题 6.6）；域分类器的 AUC 衡量输入是否可分，赔率给出权重（命题 6.7）；纯粹的概念偏移在无标签数据中不可见（命题 6.8）。
- **域适应界**：$R_Q\le R_P+\tfrac12d_{\mathcal{H}\Delta\mathcal{H}}+\lambda^*$（定理 6.9）。
- **捷径学习**：训练分布里真实的相关在上线后失效；只用 $P$ 的数据无法区分（命题 6.10）。
- **分组稳健性**：最差组风险等于对分组比例取最坏情形（命题 6.11）；Group DRO 需要分组信息与强正则化，以平均准确率为代价。
- **不变性**：ICP 只保证选出的是真原因的子集（命题 6.12）；IRM 在环境不够多或非线性时会失败。
- **压力测试与对比集**用于发现失败；**锚定集**是测量偏移的对照实验。

## 练习提示与答案

<details>
<summary>练习 6.1</summary>

（a）协变量偏移，而且可能不满足支撑条件（训练数据里没有冻品）。（b）标签偏移。（c）概念偏移。（d）测量偏移。（e）在原始输入层面，更多描述带上了"急"字，像协变量偏移；但对只看事实 $u$ 的规则，$P(y\mid u)$ 变了，在事实层面是概念偏移。这正是命题 6.1 第 2 条的情形：$u$ 不足以决定结论。

</details>

<details>
<summary>练习 6.2</summary>

第一，AUC 接近 0.5 只说明这个分类器在这些数据上分不开两批输入：分类器可能太弱，样本可能太少。第二，即使输入分布真的没变，概念偏移（例如政策变化）也检测不到（命题 6.8），错误率仍可能变化；读取器若也换了，还要看锚定集。

</details>

<details>
<summary>练习 6.3</summary>

按环境（应用版本、时间）划分：在旧版应用的数据上训练，在过渡期或新版应用的数据上测试。随机划分让测试集和训练集来自同一个分布，捷径在两边同样有效。如果已有分组信息，按"结论 × 是否有'急'字"做切片评估，也能看到规则 $h_u$ 在少数组上全错。

</details>

<details>
<summary>练习 6.4</summary>

水果权重 $0.7/0.9\approx0.778$，海鲜权重 $0.3/0.1=3$。$\sum w_i=900\times0.778+100\times3=1000$，$\sum w_i^2=900\times0.605+100\times9\approx1444$，$n_{\mathrm{eff}}=10^6/1444\approx692$。介于无偏移（1000）与海鲜比例 0.5（360）之间。

</details>

<details>
<summary>练习 6.5</summary>

由柯西-施瓦茨不等式，$(\sum_iw_i)^2\le n\sum_iw_i^2$，两边除以 $\sum_iw_i^2$ 得 $n_{\mathrm{eff}}\le n$。等号当且仅当向量 $(w_1,\dots,w_n)$ 与 $(1,\dots,1)$ 成比例，即所有权重相等。

</details>

<details>
<summary>练习 6.6</summary>

$C_{ij}=P(f=i\mid Y=j)P(j)$。按行（判 S、B、O）列（真实 S、B、O）：

- 判 S：$0.32$、$0.0675$、$0.0075$；
- 判 B：$0.06$、$0.36$、$0.0075$；
- 判 O：$0.02$、$0.0225$、$0.135$。

解 $Cw=\mu$ 得 $w=(1.375,\;0.667,\;1)$，新比例为 $(0.4\times1.375,\;0.45\times0.667,\;0.15\times1)=(0.55,0.30,0.15)$。直接用判定比例 $(0.4925,0.33,0.1775)$ 会低估 S、高估 B 和 O。

</details>

<details>
<summary>练习 6.7</summary>

$\eta^Q_{\mathrm S}=\dfrac{1.5\times\frac23}{1.5\times\frac23+0.667\times\frac13}=\dfrac{1}{1.222}\approx0.82$。原来 $2/3$ 已经判 S，现在更确定地判 S，最优结论不变。

</details>

<details>
<summary>练习 6.8</summary>

规则 $h_u$ 在少数组全错、多数组全对，加权错误率为 $m$；规则 $h_b$ 在每组都错 0.15，加权错误率为 0.15。$m>0.15$ 时规则 $h_b$ 更好（$m=0.15$ 时并列；中间的两条规则"$b$ 或 $u$ 则 S""$b$ 且 $u$ 则 S"此时也是 0.15）。训练数据里少数组占 $50/1000=0.05$，所以普通训练选规则 $h_u$。Group DRO 相当于让对手选最坏的分组权重：规则 $h_u$ 会被"全部权重放在少数组"惩罚到 1，所以它选规则 $h_b$。

</details>

<details>
<summary>练习 6.9</summary>

$e_1$ 与 $e_3$ 中：不用事实时 $P(\mathrm S)$ 为 0.50 与 0.43，不是不变的；$\{b\}$ 都是 0.15、0.85，不变；$\{u\}$ 为 0.05、0.95 与 0.038、0.935，不是不变的；$\{b,u\}$ 四格完全相同，不变，因为两个环境里"急"字的机制没变。未被拒绝的是 $\{b\}$ 和 $\{b,u\}$，交集为 $\{b\}$。

若 $\{u\}$ 也未被拒绝，交集变成 $\{b\}\cap\{u\}\cap\{b,u\}=\varnothing$。输出变弱了，但命题 6.12 的保证仍然成立。这也说明：不变性总是相对于**观察到的环境**而言的；在 $e_1$、$e_3$ 之间，$\{b,u\}$ 是不变的，但它在新版应用里并不可靠。

</details>

<details>
<summary>练习 6.10</summary>

参考要点：

1. 准备：带人工金标的锚定集，按品类、渠道分层，包含对比对和压力测试样例；它不参与提示词调优。
2. 计算：每个事实对金标的混淆矩阵与未知率（新旧对比）；新旧读数一致率；规则判定的变化数及其按结论的分布；对比一致性；按切片的错误率与样本数。
3. 阻止条件：任一关键事实的准确率下降超过事先约定的幅度（考虑样本数带来的余量）；未知率显著上升；对比集上出现系统性违反。
4. 上线后：按周监控判定、事实与未知率的控制图；定期抽检带标签案例。
5. 同周有政策变化：先在锚定集上分别评估（新读取器，旧规则）与（新读取器，新规则），两次发布错开；判定记录里同时保存读取器版本和规则版本，以便事后归因。

</details>
