# 导读

## 这本书讲什么

设想这样一个任务：有一批业务案例，每个案例有一段文字或几张图片，还有一个历史结论，例如"卖家责任"或"买家责任"。我们希望得到一份**人能读懂的规则**来做同样的判定。

难点在于，规则依赖的事实（比如"商品是否腐烂"）不能直接从结构化字段读出来，要让大语言模型去读材料。读一次要花钱，而且读得不一定对。

要把这件事做好，需要回答很多看起来互不相关的问题。下面每个问题后面的括号，是回答它的学科：

- 一条规则在历史案例上全对，为什么不代表它在新案例上也对？（统计学习理论）
- 给定一组已知的事实，怎样找到最简单、最准确的规则？为什么这在计算上很难？（符号学习与最优化）
- 模型读出的事实有噪声，拿不准时怎么办？（测量理论、弱监督、弃权）
- 现有事实区分不了两个结论不同的案例时，应该让模型去观察什么新事实？（概念发现、神经符号方法）
- 规则判错了，是事实读错了、缺了一个事实，还是规则本身不对？（诊断、程序修复、因果推断）
- 改了一版提示词，成绩好了一点，这是真的改善，还是运气？（实验设计、多重检验）
- 预算有限，下一次该把钱花在哪种尝试上？（多臂老虎机、信息价值）

这本书把这些问题背后的理论按"先学什么、后学什么"的顺序组织起来，从数学预备一直讲到当前的研究前沿。

读完以后，你应该能够：

1. 读懂这个方向的主要论文，知道每篇论文在解决哪个子问题、依赖什么假设；
2. 对一个具体系统的设计提出有依据的问题，例如"这个成绩有没有被反复挑选污染"；
3. 为一项设计取舍设计一个能给出答案的实验。

这本书不依赖任何具体软件。书中反复使用一个**生鲜售后定责**的小例子：输入是签收后的小时数和买家的描述，结论是超出时限、卖家责任、买家责任或转人工。这个例子只用来让抽象概念落地，不需要任何业务背景就能看懂。

## 写给初学者

这本书假设你**没有学过机器学习**，但愿意花时间把每一步弄懂。它的写法是：知识不打折扣，但每一步都尽量讲透。

几条阅读建议：

**按顺序读卷一。** 卷一是全书的地基，后面每一卷都会用到它的概念。卷一内部的章节也是一环扣一环的。

**卷零不必先读完。** 卷零是数学工具箱。每章开头会写明"需要的预备知识"，并告诉你去卷零的哪一节补。第 1 章甚至自带了一个十分钟的概率复习。

**证明可以先跳过。** 每个证明都标了"第一遍可以跳过"。第一遍先读懂定理"说了什么"和"怎么用"，第二遍再看"为什么成立"。证明前面通常有一句"思路"，先读这句，往往就明白了一大半。

**公式先读"怎么读"。** 每个重要的公式后面都有一段"怎么读"，逐个解释符号，并代入例子里的数字算一次。看到公式发怵时，先跳到"怎么读"。

**跟着例子算一遍。** 正文里的数字例子都很小，用纸笔几分钟就能算完。亲手算一遍，比读三遍记得更牢。

**用每节末尾的"小结"检查自己。** 读完一节，先遮住小结，用自己的话说一遍这一节讲了什么，再对照。

**练习按难度选。** ★ 题用来检验是否读懂，建议都做；★★ 题需要推导或计算；★★★ 题是开放问题，适合读完整卷后回头思考。所有练习都在章末附了答案或提示。

## 全书结构

全书分十一个部分。第一次读时只需要知道大致的路线，不用记住每一卷的内容。

| 部分 | 主题 | 回答的问题 |
|---|---|---|
| 卷零 | 数学与计算预备 | 后面要用到的概率、不等式、推断、信息论、优化、复杂性、逻辑工具 |
| 卷一 | 统计学习理论 | 学习问题是什么；训练成绩和真实表现差多少；怎样评估和选择 |
| 卷二 | 可解释的符号模型 | 决策树和规则怎样学；最优规则为什么难找；多个同样好的规则意味着什么 |
| 卷三 | 测量、标注与弱监督 | 事实由有噪声的"仪器"读出时，怎样建模和利用 |
| 卷四 | 蒸馏与模型抽取 | 怎样把一个复杂模型的行为压缩成简单规则 |
| 卷五 | 神经符号 | 感知（读材料）与推理（规则）怎样结合；LLM 怎样参与概念发现 |
| 卷六 | 程序综合、验证与修复 | 怎样自动写程序、在反例驱动下改进、定位并修复错误 |
| 卷七 | 因果推断 | 干预和反事实是什么；能从数据里得出什么因果结论 |
| 卷八 | 实验设计与序贯决策 | 怎样判断改进是真的；预算怎样分配 |
| 卷九 | LLM 程序优化 | 提示词和 LLM 程序怎样自动优化 |
| 卷十 | 综合与研究方法 | 统一视角、开放问题、怎样做研究 |

## 每章的结构

每章都按同样的顺序组织，熟悉以后可以很快找到需要的部分：

1. **本章导引**：这一章要做什么、读完会知道什么、本章新词（每个一句话解释）、需要的预备知识。
2. **正文**：每一节只讲一个新想法，顺序是"问题 → 具体例子 → 一般说法 → 公式"。
   - 重要的公式后面有**怎么读**。
   - 重要的结论标为"命题"或"定理"，后面附**证明**，标注"第一遍可以跳过"。
   - 每节末尾有**小结**。
3. **在全书中的位置**：这一章的内容在"语言模型读事实、规则做判定"这类系统里起什么作用。
4. **本章小结**：全章要点。
5. **练习**：按 ★、★★、★★★ 标难度。
6. **练习提示与答案**：放在可展开的折叠块里，先自己做再看。
7. **延伸**：本章话题在后面哪些章节继续展开。
8. **文献**：经典教材与原始论文，附一句说明，告诉你每本书适合读哪一部分。

## 记号约定

全书统一使用下面的记号。第一次读时不需要记住它们，每个记号在正文中第一次出现时都会再解释。附录 A 有完整的符号表。

| 记号 | 读作 | 含义 |
|---|---|---|
| $\mathcal{X}$, $\mathcal{Y}$ | 花体 X、花体 Y | 输入空间、输出（结论）空间 |
| $x$, $y$ | | 一个输入、一个结论 |
| $X$, $Y$ | 大写 X、大写 Y | 随机抽取的输入和结论 |
| $\mathcal{D}$ | 花体 D | 输入和结论的联合分布，通常未知 |
| $S=((x_1,y_1),\dots,(x_n,y_n))$ | | 手头的 $n$ 个案例（样本） |
| $h$, $\mathcal{H}$ | | 一条候选规则（假设）、全部候选规则（假设空间） |
| $c(y,\hat y)$ | c，y，y 帽 | 真实结论为 $y$、预测为 $\hat y$ 时的代价 |
| $R(h)$, $\hat R_S(h)$ | R，R 帽 | 风险（将来的平均代价）、经验风险（手头案例上的平均代价） |
| $\eta_k(x)$ | 艾塔 | 在输入为 $x$ 的案例里，结论为 $k$ 的比例 |
| $\phi(x)$ | 斐 | 特征映射：从输入中提取出的事实 |
| $\mathbb{E}$, $\Pr$ | 期望、概率 | 加权平均、比例 |
| $\mathbf{1}[\cdot]$ | 指示函数 | 方括号里的条件成立为 1，否则为 0 |
| $[n]$ | | 集合 $\{1,\dots,n\}$ |

## 需要的数学基础

开始阅读卷一之前，你只需要：

- 会做分数、百分数和加权平均的计算；
- 见过求和符号 $\sum$，或者愿意现学（第 1 章会解释）；
- 知道集合和函数大概是什么意思。

条件概率、期望这些工具，第 1 章开头会用一个十分钟的复习讲清楚。更系统的内容在卷零的 0.1 节。
