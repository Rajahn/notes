# 导读

## 这本书讲什么

设想这样一个任务：有一批业务案例，每个案例有一段文字或几张图片，还有一个历史结论（例如"卖家责任"或"买家责任"）。我们希望得到一份**人能读懂的规则**来做同样的判定。规则依赖的事实（"商品是否腐烂"）不能直接从结构化字段读出，要靠大语言模型去读材料。读一次要花钱，而且读得不一定对。

要把这件事做好，需要回答很多看起来不相关的问题：

- 一条规则在历史案例上全对，为什么不代表它在新案例上也对？（统计学习理论）
- 给定一组已知的事实，怎样找到最简单、最准确的规则？为什么这在计算上很难？（符号学习与最优化）
- 模型读出的事实有噪声，又拿不准时怎么办？（测量理论、弱监督、弃权）
- 现有事实区分不了两个结论不同的案例时，应该让模型去观察什么新事实？（概念发现、神经符号方法）
- 规则判错了，是事实读错了、缺了一个事实，还是规则本身不对？（诊断、程序修复、因果推断）
- 改了一版提示词，成绩好了一点，这是真的改善，还是运气？（实验设计、多重检验）
- 预算有限，下一次该把钱花在哪种尝试上？（多臂老虎机、信息价值）

本书把这些问题背后的理论按依赖顺序组织起来，从数学预备讲到当前的研究前沿。读完以后，你应该能够：

1. 读懂这个方向的主要论文，知道它们各自解决哪个子问题、依赖什么假设；
2. 对一个具体系统的设计提出有依据的问题，例如"这个成绩是否被自适应选择污染了"；
3. 为一项设计取舍设计一个能给出答案的实验。

本书不依赖任何具体软件。书中反复使用一个**生鲜售后定责**的小例子：输入是签收后的小时数和买家描述，结论是超出时限、卖家责任、买家责任或转人工。例子只用来让抽象概念落地。

## 全书结构

全书分十一个部分：

| 部分 | 主题 | 回答的问题 |
|---|---|---|
| 卷零 | 数学与计算预备 | 后面要用到的概率、不等式、推断、信息论、优化、复杂性、逻辑工具 |
| 卷一 | 统计学习理论 | 学习问题是什么；训练成绩和真实表现之间差多少；怎样评估和选择 |
| 卷二 | 可解释的符号模型 | 决策树和规则怎样学；最优规则为什么难找；多个同样好的规则意味着什么 |
| 卷三 | 测量、标注与弱监督 | 事实由有噪声的仪器读出时，怎样建模和利用 |
| 卷四 | 蒸馏与模型抽取 | 怎样把一个复杂模型的行为压缩成简单规则 |
| 卷五 | 神经符号 | 感知（读材料）与推理（规则）怎样结合；LLM 怎样参与概念发现 |
| 卷六 | 程序综合、验证与修复 | 怎样自动写程序、在反例驱动下精化、定位并修复错误 |
| 卷七 | 因果推断 | 干预和反事实是什么；能从数据里得出什么因果结论 |
| 卷八 | 实验设计与序贯决策 | 怎样判断改进是真的；预算怎样分配 |
| 卷九 | LLM 程序优化 | 提示词和 LLM 程序怎样自动优化 |
| 卷十 | 综合与研究方法 | 统一视角、开放问题、怎样做研究 |

各卷之间的依赖关系：

```text
卷零 ─► 卷一 ─► 卷二 ─┬─► 卷四 ─► 卷五 ─► 卷十
             │         └─► 卷三 ──┘         ▲
             └─► 卷七 ─► 卷八 ─► 卷九 ───────┤
                                卷六 ───────┘
```

卷零是工具箱。可以先通读，也可以在后面遇到时再回来查。卷一是全书的地基，建议按顺序读。

## 每章的结构

每章按以下顺序组织：

1. **核心问题**：这一章要回答什么。
2. **正文**：先给直觉和例子，再给形式化定义。
3. **要亲手推导的结论**：标为"命题"或"定理"，附完整证明。建议先合上书自己推一遍。
4. **在本领域中的位置**：这一章的内容在"LLM 读事实、规则做判定"这类系统里起什么作用。
5. **练习**：分为"检验理解""推导""思考"三类，答案或提示放在章末的折叠块里。
6. **文献**：经典教材与原始论文。

## 记号约定

全书统一使用下面的记号。附录 A 有完整的符号表。

| 记号 | 含义 |
|---|---|
| $\mathcal{X}$, $\mathcal{Y}$ | 输入空间、输出（标签）空间 |
| $x$, $y$ | 一个输入、一个标签 |
| $X$, $Y$ | 随机变量形式的输入和标签 |
| $\mathcal{D}$ | $\mathcal{X}\times\mathcal{Y}$ 上的联合分布，通常未知 |
| $S=((x_1,y_1),\dots,(x_n,y_n))$ | 大小为 $n$ 的样本 |
| $h$, $\mathcal{H}$ | 一个假设（预测函数）、假设空间 |
| $c(y,\hat y)$ | 真实标签为 $y$、预测为 $\hat y$ 时的代价 |
| $R(h)$, $\hat R_S(h)$ | 风险（期望代价）、经验风险 |
| $\eta_k(x)$ | 条件概率 $\Pr(Y=k\mid X=x)$ |
| $\phi(x)$ | 特征映射：把输入变成可供规则使用的表示 |
| $\mathbb{E}$, $\Pr$ | 期望、概率 |
| $\mathbb{1}[\cdot]$ | 指示函数，条件成立为 1，否则为 0 |
| $[n]$ | 集合 $\{1,\dots,n\}$ |

## 需要的数学基础

开始阅读卷一之前，你需要知道：

- 概率的基本运算：条件概率、贝叶斯公式、期望、方差；
- 求和与求积的记号，简单的不等式变形；
- 集合和函数的基本概念。

如果这些还不熟，先读卷零的 0.1 节。其余预备知识会在用到的章节标出，届时再查卷零。
