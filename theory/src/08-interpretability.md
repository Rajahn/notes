# 第 8 章　什么是可解释性

## 本章导引

### 这一章要做什么

卷一问的是"学到的规则在将来准不准"。这一章换一个问题：**一个判定系统，人能不能看懂、查得动、驳得了？**

这个问题比听上去难。"可解释"在文献里至少有三种互相竞争的立场；同一个判定可以给出好几种"解释"，它们彼此矛盾，而且看起来最有道理的那一个，未必反映了模型真正的计算。这一章做四件事：

1. 说清楚人们为什么要求可解释，以及为什么"模型很准"代替不了它（8.1 节）。
2. 介绍三种主要的定义立场：Lipton 的透明性层次、Doshi-Velez 与 Kim 的三级评估、Rudin 的"高风险决策直接用可解释的模型"（8.2–8.4 节）。
3. 介绍事后解释的主要方法（局部代理、Shapley 值、反事实、锚点），每种都在售后例子上算一遍，再看它们怎样失败（8.5–8.11 节）。
4. 回到符号模型本身：规则怎样才算好读，规则读的"事实"怎样才算可解释，可解释性和准确、博弈、隐私、公平怎样冲突；最后给一份检查清单（8.12–8.15 节）。

### 读完这一章，你会知道

1. 审计、申诉、调试、问责、信任校准、知识发现各自需要什么，为什么平均准确率回答不了这些问题。
2. 可模拟性、可分解性、算法透明性的区别；评估可解释性的三个层次；Rudin 主张的依据和边界。
3. 内在可解释与事后解释、全局与局部的区别；为什么"忠实"和"可信"是两回事，以及保真度能保证什么、不能保证什么。
4. 怎样精确计算一条小规则的 Shapley 值，为什么它是满足四条公理的唯一分配，以及基线不同时它为什么会变。
5. LIME、反事实解释、锚点各做什么，为什么它们不稳定、可被操纵、彼此不一致。
6. 决策树和决策列表各在什么情况下更好读，单调性怎样检查，人类实验说了什么。
7. 为什么规则读的事实本身也必须可解释，"事实问题夹带结论"是什么意思。
8. 公开规则怎样改变人的行为，解释怎样泄露信息，可解释性怎样帮助、又怎样不足以保证公平。

### 本章新词

| 词 | 一句话解释 |
|---|---|
| 可解释性 | 人能理解一个判定系统为什么给出某个结论的程度 |
| 可争议性 | 被判定的人能指出判定依据哪里错了，并要求重审 |
| 信任校准 | 人对系统的信任程度与系统实际的可靠程度相符 |
| 可模拟性 | 人拿着输入，能在合理时间内手算出模型的输出 |
| 可分解性 | 模型的每个输入、每个部件都有直观含义 |
| 算法透明性 | 人理解学习算法本身会怎样表现 |
| 内在可解释 | 模型本身就是人能读的形式，不需要另外解释 |
| 事后解释 | 模型训练好以后，另用一种方法生成的说明 |
| 全局解释、局部解释 | 说明整个模型怎样工作；说明某一个判定为什么这样 |
| 忠实性、保真度 | 解释与模型实际计算相符的程度；它的一种定量版本 |
| 可信度 | 解释在人看来是否合理 |
| 局部代理模型 | 在某个输入附近模仿黑盒的简单模型 |
| 特征归因、Shapley 值 | 把一个判定"记功"给各个输入；按所有加入顺序平均边际贡献的记功方法 |
| 反事实解释 | "如果某几个输入换成这样，结论就会变" |
| 锚点 | 一组条件，只要满足它们，结论几乎不变 |
| 单调性 | 某个事实朝"有利"方向变时，结论不会朝"不利"方向变 |
| 策略性行为 | 人知道规则以后，改变自己的输入来获得想要的结论 |
| 公平洗白 | 用一个看起来公平的解释掩盖不公平的模型 |

## 8.1 准确回答不了的问题

### 8.1.1 一个例子：知道规则在哪里会错

平台上线了规则甲（"不在时限内 → O；否则腐烂 → S；否则 → B"）。审核员可以照单全收，也可以推翻它。设想下面的数字（假设的）：

- 10% 的案例描述提到包装破损导致汁液渗出（$p=1$）。规则甲不看 $p$，在这部分案例上只判对 20%；在其余 90% 的案例上判对 90%。总准确率是 $0.1\times0.2+0.9\times0.9=0.83$。
- 审核员自己判，准确率 0.8，不分案例类型。

审核员如果只知道"系统准确率 83%"，最好的策略是全部照单全收，得到 0.83。如果他**读得懂规则**，发现它根本不看包装破损，就可以只在 $p=1$ 的案例上自己判：$0.9\times0.9+0.1\times0.8=0.89$。

多出来的 6 个百分点不是来自更好的模型，而是来自**知道模型在哪里不可靠**。平均准确率只是一个数，它说不出错误集中在哪里。

### 8.1.2 六种需求

把"为什么要可解释"拆开，常见的需求有六种。

1. **审计**：内控或监管方检查判定依据是否符合政策。问的是"规则里有没有不该用的依据"。第 6 章 6.7 节的规则 $h_u$ 依赖"急"字，审核者读到规则就能发现，同分布的测试集却发现不了。
2. **申诉**：被判定的人能指出依据哪里错了。这种性质叫**可争议性**（contestability）。问的是"我的案例因为哪几条事实得到这个结论？如果某条事实读错了，改过来结论会不会变？"
3. **调试**：开发者找错误的来源。第 1 章 1.10 节的碰撞组分析就是一种调试：剩下的错误来自事实不够，还是规则不对。
4. **监管与问责**：法律或制度要求能说明判定理由，并追溯到负责的人或版本。例如欧盟《通用数据保护条例》关于自动化决策的条款（它是否构成一项"解释权"有争论，见 Goodman 与 Flaxman 2017；Wachter、Mittelstadt 与 Floridi 2017），以及美国信贷领域要求向被拒者说明主要理由的规定。不同法域的要求不同、而且在变化，本书不作法律解释，只指出它们问的都是**具体判定的具体理由**。
5. **信任校准**：使用者的信任与系统的实际可靠性相符，既不盲从也不一概不信。8.1.1 节就是这一种。
6. **知识发现**：从模型中学到关于世界的东西，例如"包装破损的案例几乎都是卖家责任"，进而改进包装规范。

### 8.1.3 为什么"准确"不够

风险 $R(h)$ 是**在分布上取平均**得到的一个数。上面六种需求问的都是平均值以外的东西：

- 审计和知识发现问的是**机制**：模型用了什么。用了不同依据的两个模型可以有完全相同的风险；第 6 章命题 6.10 说，单靠训练分布的数据甚至分不出它们。
- 申诉和问责问的是**单个判定**：对这一个案例，理由是什么。风险对此一言不发。
- 调试和信任校准问的是**错误的结构**：错在哪里。
- 风险是在**过去的分布**上测的。分布一变，准确率就不再成立；而一条可读的规则仍能让人判断它在新情况下会怎么做。

Doshi-Velez 与 Kim（2017）把这一点概括为**问题表述的不完整**：如果目标能完全写成一个可优化的数，就不需要解释；需要解释，正是因为有一部分目标（公平、安全、合规、"依据正当"）没能写进那个数里。

### 小结

这一节说的是：可解释性服务于审计、申诉、调试、问责、信任校准、知识发现六种需求；它们问的是机制、单个判定和错误的结构，而准确率只是分布上的一个平均数。

## 8.2 透明性的三个层次

Lipton（2018）的《模型可解释性的神话》（The Mythos of Model Interpretability）指出，人们说"可解释"时指的东西并不相同。他把文献里的用法分成两大类：**透明性**（模型本身怎样工作）和**事后解释**（模型之外另给的说明，8.5 节）。透明性又分三个层次。

### 8.2.1 可模拟性

**定义 8.1（可模拟性）** 一个模型对某一类读者是**可模拟的**，如果这类读者拿到输入和模型的完整描述，能在合理时间内一步一步手算出模型的输出。

**例子**：规则甲只有三行，审核员拿到 $(a,b)=(1,0)$，几秒钟就能算出 B。一个由 500 棵小树组成的集成模型，每棵树都可读，但没人能在合理时间里把 500 棵的结果合起来，所以它不可模拟。

这个定义有两个要点。第一，它**相对于读者**：同一个模型对领域专家可模拟，对新手未必。第二，它有**时间尺度**：模型要小到人的有限认知能装得下。检验这一层的标准实验是"前向模拟"：给人输入，让他预测模型的输出（8.3 节）。

### 8.2.2 可分解性

**可分解性**是说模型的每一部分（每个输入、每个参数、每一步计算）都有直观含义。

**例子**：规则甲的每个条件都是一个有业务含义的事实。反过来，一棵问"嵌入向量第 17 维是否大于 0.3"的深度 2 决策树可模拟（三步就算完），但**不可分解**：没人知道第 17 维是什么意思。8.13 节会专门讨论这一点。

Lipton 特别提醒：线性模型常被当作"天然可解释"，但如果它的输入是大量经过复杂变换的特征，它既不可模拟（特征太多），也不可分解（特征没有含义）。

### 8.2.3 算法透明性

**算法透明性**是说人理解**学习算法**的行为。例如线性回归的最小二乘解唯一，换随机种子不会变；深度网络的训练结果依赖初始化，理论上不清楚会收敛到哪里。

对规则学习，这一层常被忽视。贪心建树可能因为增减一个案例而整棵改变；最优决策树算法给出的是某个目标下的最优解，但同样好的解往往不止一个。**一条规则可读，不等于"为什么是这一条"可读。** 后面讲同样好的规则不止一条时，会专门讨论这个选择。

### 小结

这一节说的是：透明性有三个层次：人能手算（可模拟）、每部分有含义（可分解）、学习算法的行为可理解（算法透明）；三者相互独立，一个小模型可以可模拟而不可分解。

## 8.3 怎样检验"可解释"

### 8.3.1 问题

说一个模型"可解释"，证据是什么？最常见的做法是报告一个指标，例如"树的深度只有 3"。但深度 3 的树读起来是否真的容易、对谁容易、是否帮人完成了任务，指标本身回答不了。

### 8.3.2 三级评估

Doshi-Velez 与 Kim（2017）按"离真实使用多近"把评估分成三级：

1. **应用层评估**（application-grounded）：真实的使用者、真实的任务。例如让售后审核员在真实案例上使用系统，比较有无规则说明时的复核准确率、处理时间、申诉改判率。证据最强，也最贵。
2. **人类层评估**（human-grounded）：真实的人、简化的任务。例如招募非专业人员，给出规则和输入，让他们预测规则的输出（前向模拟），或者问"输入怎样改，输出才会变成 S"（反事实模拟）。便宜一些，测的是一般意义上的"可理解"，不一定迁移到专家的真实任务。
3. **功能层评估**（functionally-grounded）：不用人，用形式化的代理指标，例如叶子数、深度、用到的事实个数。最便宜；但它的有效性依赖于"这个代理确实与人的理解相关"，而这需要前两级的证据。

**在售后例子里**：规则甲有 3 片叶子、用 2 个事实（功能层）；让 20 个非专业人员对 10 个输入做前向模拟，记录正确率和用时（人类层）；上线后比较审核员在"有规则说明"和"只有结论"两种界面下的复核质量（应用层）。

三级评估构成一条**证据链**：功能层的代理只有在上面两级被验证过与理解相关时才有意义。8.12.4 节会看到，人类实验的结果有时与直觉相反。

### 小结

这一节说的是：可解释性的证据分三级：真实用户真实任务、真实的人简化任务、不用人的代理指标；越往下越便宜，也越依赖上一级的验证。

## 8.4 高风险决策：先问能不能不用黑盒

### 8.4.1 Rudin 的主张

Rudin（2019）的文章题目就是主张：《不要再为高风险决策解释黑盒模型，改用可解释的模型》。她的论证有三条：

1. **准确与可解释的取舍常常不存在。** 在**结构化数据**上（每一列都有含义，比如年龄、前科次数、签收小时数），精心学出的稀疏模型（短规则列表、小评分卡）往往和复杂模型一样准。她举的例子之一是美国司法系统中的商业再犯风险工具 COMPAS：Angelino 等人（2018）的 CORELS 算法学到的、只用年龄、性别和前科次数的几行规则列表，准确率与 COMPAS 相近。
2. **黑盒的解释必然不完全忠实。** 如果解释在所有输入上都与黑盒一致，它本身就是一个等价的模型，那就直接用它；如果不完全一致，在不一致的地方解释就是错的（8.6 节给出定量的说法）。
3. **解释会制造虚假的安全感**，让人不再追问"有没有同样准的简单模型"。

### 8.4.2 这个主张的边界

Rudin 的论点针对结构化数据。对图像、语音、自由文本这类原始信号，取舍通常真实存在：没有人能用几行规则直接从描述文字判断"是否腐烂"。

本书讨论的系统在这里做了一个分工：**用语言模型把原始文本变成少数几个结构化事实，再用可解释的规则在事实上判定。** 这样，Rudin 的论点适用于后一半（规则不需要事后解释），前一半（读事实）仍是黑盒，需要别的保障。8.13 节讨论这个分工的长处和局限。

### 小结

这一节说的是：Rudin 主张高风险决策直接使用可解释的模型，因为在结构化数据上准确与可解释常常不冲突，而黑盒的事后解释必然不完全忠实；对原始信号这个主张不直接适用，"先读事实、再用规则"把两者分开处理。

## 8.5 两组区分：内在与事后，全局与局部

### 8.5.1 内在可解释与事后解释

**内在可解释**（interpretable by design）的模型本身就是人能读的形式，例如规则甲、一张评分卡、一棵小决策树。对它们，"解释"就是模型本身。

**事后解释**（post-hoc explanation）是在模型训练好之后另外生成的说明，模型本身可以是任何东西。例如对一个读原始描述的神经网络，事后说"这次判定主要因为'发霉'二字"。

根本区别在于：**内在可解释模型的解释与模型是同一个东西，不存在"解释是否忠实"的问题；事后解释总有这个问题。**

### 8.5.2 全局解释与局部解释

**全局解释**说明整个模型怎样工作，例如"在时限内、腐烂则判 S"。**局部解释**只说明某一个判定，例如"案例 1 判 S，因为在时限内且腐烂"。

两组区分交叉，得到四种情形：

| | 全局 | 局部 |
|---|---|---|
| 内在 | 读整条规则 | 读该案例走过的那条路径 |
| 事后 | 用一棵树模仿整个黑盒 | LIME、Shapley 值、反事实、锚点 |

8.1.2 节的需求中，审计和知识发现主要需要全局解释，申诉主要需要局部解释，调试和信任校准两者都要。

### 小结

这一节说的是：内在可解释的模型本身就是解释，事后解释是另外生成的说明，总有是否忠实的问题；全局解释说明整个模型，局部解释说明单个判定，不同需求需要不同的组合。

## 8.6 忠实与可信

### 8.6.1 一个有道理、却不忠实的解释

只看时限内的案例。和第 6 章 6.7 节一样，真实规律只与腐烂 $b$ 有关：$\Pr(\mathrm S\mid b=1)=0.85$，$\Pr(\mathrm S\mid b=0)=0.15$，$b=1$ 的案例占一半。另有一个事实 $\ell$："描述是否较长"。腐烂的案例买家往往写得长：$\Pr(\ell=1\mid b=1)=0.8$，$\Pr(\ell=1\mid b=0)=0.2$；给定 $b$ 以后，$\ell$ 与结论无关。

一个直接读描述的黑盒 $f$ 学到的其实是"描述长 → S，否则 → B"，这是一条捷径。对一个描述很长、确实提到腐烂的案例，它判 S。一个事后解释方法给出：

> 判 S，因为描述指向腐烂。

这个解释**很可信**：任何审核员都同意"腐烂所以卖家负责"。但它**不忠实**：把描述改成不腐烂而长度不变，$f$ 仍判 S；把描述改短而保留腐烂，$f$ 改判 B。$f$ 的判定根本不依赖腐烂。

把这个解释当作一个模型 $g$（"腐烂 → S，否则 → B"），它和 $f$ 一致当且仅当 $b=\ell$，概率是 $0.5\times0.8+0.5\times0.8=0.8$。也就是说，在 20% 的案例上，"解释"预言的结论和模型实际给的结论不同。

### 8.6.2 两个概念

**忠实性**（faithfulness）是解释与模型实际计算相符的程度。例如上面的解释在 20% 的案例上与模型不符。**可信度**（plausibility）是解释在人看来是否合理。例如上面的解释人人认可。Jacovi 与 Goldberg（2020）强调两者必须分开评估：请人打分测的是可信度，不是忠实性。语言模型给出的"自我解释"也有同样的问题：Turpin 等人（2023）发现，在提示里暗示某个答案会改变模型的选择，而模型写出的推理过程几乎从不提到这个暗示。

对全局的代理解释，忠实性有一个简单的定量版本。

**定义 8.2（保真度）** 设 $f$ 是被解释的模型，$g$ 是解释模型（代理模型），$Q$ 是输入的分布。$g$ 对 $f$ 在 $Q$ 上的**保真度**是

$$
\operatorname{Fid}_Q(g,f)=\Pr_{X\sim Q}\big(g(X)=f(X)\big).
$$

**怎么读**：从 $Q$ 里随机抽一个输入，$g$ 和 $f$ 给出相同结论的概率。上面的例子里 $\operatorname{Fid}=0.8$。保真度**相对于分布 $Q$**：在一种输入分布上一致，换一种分布就可能不一致（8.11 节会利用这一点）。

### 8.6.3 保真度管住了什么

**命题 8.1（保真度控制风险之差）** 设代价取值于 $[0,C]$，$\mathcal{D}_X$ 是 $\mathcal{D}$ 中输入的分布。则对任意 $f,g$，

$$
\big\lvert R(g)-R(f)\big\rvert\le C\,\big(1-\operatorname{Fid}_{\mathcal{D}_X}(g,f)\big).
$$

**怎么读**：解释模型和原模型的风险之差，不超过"最大代价 × 两者不一致的比例"。例子里用 0-1 代价，$C=1$：$g$ 的错误率是 0.15；$f$ 的错误率是 $0.5\times(0.8\times0.15+0.2\times0.85)+0.5\times(0.2\times0.85+0.8\times0.15)=0.29$。差 0.14，不超过 $1-0.8=0.2$。

#### 证明（第一遍可以跳过）

**思路**：只有在 $f$ 与 $g$ 不一致的输入上，两者的代价才可能不同。

1. 由风险的定义，$R(g)-R(f)=\mathbb{E}\big[c(Y,g(X))-c(Y,f(X))\big]$。
2. 若 $g(X)=f(X)$，方括号内为 0；否则它是两个 $[0,C]$ 中的数之差，绝对值不超过 $C$。所以方括号内的绝对值不超过 $C\cdot\mathbf{1}[g(X)\ne f(X)]$。
3. 取期望：$\lvert R(g)-R(f)\rvert\le C\Pr\big(g(X)\ne f(X)\big)=C\big(1-\operatorname{Fid}\big)$。$\square$

这个命题有两面。**正面**：高保真度的代理在**平均表现**上能代表原模型。**反面**：它只管平均。不一致的那部分案例，正是解释说错的地方；它们可以集中在某个群体上（8.14.4 节），而且从解释本身看不出是哪些。对申诉者来说，要紧的恰恰是**自己的案例**是否落在其中。这就是 Rudin 第二条论证的定量形式：保真度为 1 时解释就是模型；小于 1 时，总有一些判定的解释是错的。

### 小结

这一节说的是：忠实性是解释与模型实际计算相符，可信度是解释在人看来合理，两者可以背离；保真度把忠实性量化为一致的概率，它控制了风险之差，却不能告诉你哪些个别判定的解释是错的。

## 8.7 局部代理：LIME

### 8.7.1 想法

Ribeiro、Singh 与 Guestrin（2016）提出的 LIME（Local Interpretable Model-agnostic Explanations）基于一个直觉：黑盒整体也许很复杂，但在一个输入**附近**也许近似线性。做法是：

1. 在要解释的输入 $x$ 附近生成一批扰动样本 $z$；
2. 用黑盒算出每个 $f(z)$；
3. 按离 $x$ 的远近给每个 $z$ 一个权重 $\pi_x(z)$；
4. 用加权最小二乘拟合一个简单模型 $g$（通常是稀疏线性模型），把 $g$ 的系数作为解释。

写成一个优化问题：

$$
\xi(x)=\arg\min_{g\in\mathcal{G}}\;\sum_{z}\pi_x(z)\big(f(z)-g(z)\big)^2+\Omega(g).
$$

**怎么读**：$\mathcal{G}$ 是允许的简单模型（例如线性函数）；求和项是"在 $x$ 附近 $g$ 模仿 $f$ 模仿得多差"，越近的点权重越大；$\Omega(g)$ 惩罚 $g$ 的复杂度（例如非零系数的个数）；$\xi(x)$ 就是对 $x$ 的解释。

### 8.7.2 在售后例子上算一算

引入一条新规则，记为**规则戊**：

> 不在时限内 → O；否则，腐烂或包装破损 → S；否则 → B。

在 8 个案例上它只错案例 3，达到第 1 章 1.10.5 节在 $(a,b,p)$ 上算出的下界 $1/8$。把它当作"黑盒"，只看它是否判 S：$f(x)=\mathbf{1}[\text{规则戊判 S}]$。

解释案例 6，$x=(a,b,p)=(1,0,1)$，$f(x)=1$。扰动样本取全部 8 种 $(a,b,p)$ 组合；权重 $\pi_x(z)=\exp(-d(z,x)^2/\sigma^2)$，$d$ 是两者取值不同的事实个数，$\sigma$ 叫作**核宽度**。拟合 $g(z)=w_0+w_aa+w_bb+w_pp$（不加 $\Omega$），得到：

| 核宽度 $\sigma$ | $w_a$ | $w_b$ | $w_p$ |
|---|---|---|---|
| 0.5 | 1.00 | 0.00 | 1.00 |
| 1 | 0.93 | 0.07 | 0.89 |
| 2 | 0.75 | 0.25 | 0.43 |
| 很大 | 0.75 | 0.25 | 0.25 |

**怎么读这张表**：核宽度小时，实际起作用的只有和 $x$ 相差一个事实的点。在 $x$ 附近，把 $a$ 或 $p$ 翻成 0 都会让结论离开 S，翻 $b$ 不会，所以 $w_b\approx0$，解释是"因为在时限内且包装破损"，与规则戊在这个案例上走的路径一致。核宽度很大时，8 个点权重相同，拟合的是**全局**平均趋势，$b$ 和 $p$ 得到相同的系数，可是在案例 6 上翻转 $b$ 根本不影响结论。

**同一个模型、同一个输入，只因一个超参数不同，"哪个事实更重要"的排序就变了。** Garreau 与 von Luxburg（2020）对表格数据上的 LIME 做了理论分析，说明了解释对核宽度等设置的依赖。这里的扰动取的是全部组合；实际的 LIME 对表格数据按训练数据逐列抽样，细节不同，现象相同。

### 小结

这一节说的是：LIME 在输入附近采样、按远近加权、拟合简单模型，把系数当作解释；在规则戊上算一遍可以看到，核宽度改变了"局部"的含义，也就改变了解释本身。

## 8.8 Shapley 值

### 8.8.1 问题：功劳怎么分

案例 6 判 S。三个事实 $a=1$、$b=0$、$p=1$ 各"贡献"了多少？难处在于事实之间有交互：单有 $p=1$ 不够（还要在时限内），单有 $a=1$ 也不够（还要腐烂或破损）。博弈论里有一个分配合作收益的经典答案。

### 8.8.2 "只知道一部分事实"时的输出

先说清楚"只知道一部分事实时，模型输出是多少"。记全部事实的集合为 $N$（这里 $N=\{a,b,p\}$，$m=\lvert N\rvert=3$）。对子集 $T\subseteq N$，令

$$
v_x(T)=\frac1n\sum_{i=1}^n f\big(x_T,\;x^{(i)}_{N\setminus T}\big).
$$

**怎么读**：$x_T$ 是 $x$ 在 $T$ 中事实上的取值；$x^{(i)}_{N\setminus T}$ 是第 $i$ 个参照案例在其余事实上的取值。两者拼起来喂给模型，再对 $n$ 个参照案例平均。也就是：$T$ 里的事实固定为 $x$ 的值，其余事实"不知道"，用参照数据里的值代替。这叫**干预式**值函数，参照数据叫**基线**。

以 8 个案例为基线，案例 6 的 $v_x$ 为：

| $T$ | $\varnothing$ | $\{a\}$ | $\{b\}$ | $\{p\}$ | $\{a,b\}$ | $\{a,p\}$ | $\{b,p\}$ | $N$ |
|---|---|---|---|---|---|---|---|---|
| $v_x(T)$ | 1/2 | 5/8 | 1/8 | 3/4 | 1/8 | 1 | 3/4 | 1 |

例如 $v_x(\{p\})$：固定 $p=1$，$a,b$ 取 8 个案例各自的值，这时规则戊判 S 当且仅当 $a=1$，8 个案例中 6 个 $a=1$，得 $3/4$。$v_x(\varnothing)=1/2$ 是规则戊在 8 个案例上判 S 的比例（案例 1、2、3、6）。

### 8.8.3 按加入顺序平均

想象三个事实按某个顺序一个一个揭开。每揭开一个，$v_x$ 的增量就是它在这个顺序下的**边际贡献**。三个事实有 6 种顺序：

| 顺序 | $a$ 的贡献 | $b$ 的贡献 | $p$ 的贡献 |
|---|---|---|---|
| $a,b,p$ | 1/8 | $-1/2$ | 7/8 |
| $a,p,b$ | 1/8 | 0 | 3/8 |
| $b,a,p$ | 0 | $-3/8$ | 7/8 |
| $b,p,a$ | 1/4 | $-3/8$ | 5/8 |
| $p,a,b$ | 1/4 | 0 | 1/4 |
| $p,b,a$ | 1/4 | 0 | 1/4 |
| **平均** | **1/6** | **$-5/24$** | **13/24** |

例如第一行：先揭开 $a$，$v_x$ 从 $1/2$ 到 $5/8$，贡献 $1/8$；再揭开 $b$，从 $5/8$ 到 $1/8$，贡献 $-1/2$；最后揭开 $p$，从 $1/8$ 到 $1$，贡献 $7/8$。三个平均值之和 $1/6-5/24+13/24=1/2$，正好是 $f(x)-v_x(\varnothing)$。

**怎么读这个结果**：相对于"一半案例判 S"的基线，案例 6 判 S 的功劳主要归于 $p=1$（13/24），其次是 $a=1$（1/6）；$b=0$ 得到负分（$-5/24$），意思是"不腐烂"这个取值本身在把结论推离 S。这和读规则路径（"在时限内且破损，所以 S"）给人的印象不同：路径解释根本不提 $b$。

### 8.8.4 定义与唯一性

**定义 8.3（Shapley 值）** 设 $v$ 是定义在 $N$ 的所有子集上的函数，称为**合作博弈**。事实 $j$ 的 **Shapley 值**是

$$
\begin{aligned}
\varphi_j(v)&=\sum_{T\subseteq N\setminus\{j\}}w_T\,\big[v(T\cup\{j\})-v(T)\big],\\
w_T&=\frac{\lvert T\rvert!\,(m-\lvert T\rvert-1)!}{m!}.
\end{aligned}
$$

**怎么读**：$w_T$ 是"随机顺序中，$j$ 恰好排在 $T$ 的全部成员之后、其余成员之前"的概率：$T$ 的成员在 $j$ 之前有 $\lvert T\rvert!$ 种排法，其余 $m-\lvert T\rvert-1$ 个在 $j$ 之后有 $(m-\lvert T\rvert-1)!$ 种排法，除以总排法数 $m!$。所以这个和就是 8.8.3 节"对 6 种顺序取平均"。例如 $m=3$、$T=\varnothing$ 时 $w_T=0!\,2!/3!=1/3$：$j$ 排第一的顺序占三分之一。

Shapley（1953）证明了这是唯一满足下面四条要求的分配。

**定理 8.2（Shapley 值的唯一性）** 考虑满足 $v(\varnothing)=0$ 的合作博弈。在所有把博弈 $v$ 映射成向量 $(\psi_j(v))_{j\in N}$ 的方法中，同时满足以下四条的只有 Shapley 值：

1. **有效性**：$\sum_j\psi_j(v)=v(N)$。
2. **对称性**：若对所有不含 $i,j$ 的 $T$ 都有 $v(T\cup\{i\})=v(T\cup\{j\})$，则 $\psi_i(v)=\psi_j(v)$。
3. **零贡献者**：若对所有 $T$ 都有 $v(T\cup\{j\})=v(T)$，则 $\psi_j(v)=0$。
4. **可加性**：$\psi_j(v+u)=\psi_j(v)+\psi_j(u)$。

用于解释时，取 $v(T)=v_x(T)-v_x(\varnothing)$，有效性就是：**各事实的归因之和，等于这个案例的输出减去基线上的平均输出**。Lundberg 与 Lee（2017）把这条称为"局部准确性"，并借助 Young（1985）的结果说明：在他们称为"加性特征归因"的一类方法中，满足局部准确性、缺失性和一致性的只有 Shapley 值；基于此的一族方法统称 SHAP。更早，Štrumbelj 与 Kononenko（2010）已用 Shapley 值解释单个预测。

#### 证明（第一遍可以跳过）

**思路**：先验证 Shapley 值满足四条；再证明四条要求在一组"基本博弈"上唯一确定了答案，而任何博弈都是基本博弈的线性组合。

**Shapley 值满足四条。**

1. 有效性：对任一顺序 $j_1,\dots,j_m$，边际贡献之和 $[v(\{j_1\})-v(\varnothing)]+[v(\{j_1,j_2\})-v(\{j_1\})]+\cdots$ 中间项两两抵消，等于 $v(N)-v(\varnothing)=v(N)$。对所有顺序平均，仍是 $v(N)$。
2. 对称性：把每个顺序中的 $i$ 与 $j$ 互换，得到顺序之间的一一对应；由假设，$i$ 在原顺序中的边际贡献等于 $j$ 在新顺序中的边际贡献，平均后相等。
3. 零贡献者：公式中每一项 $v(T\cup\{j\})-v(T)$ 都是 0。
4. 可加性：公式对 $v$ 是线性的。

**唯一性。**

5. 对非空的 $T\subseteq N$，定义**一致博弈** $u_T(S)=\mathbf{1}[T\subseteq S]$：$T$ 的成员全部到齐时价值为 1。对任意实数 $c$，在博弈 $cu_T$ 中，$T$ 以外的事实都是零贡献者，$\psi_j=0$；$T$ 的成员两两对称，分到的相等；由有效性，它们之和为 $c$。所以 $j\in T$ 时 $\psi_j(cu_T)=c/\lvert T\rvert$，被四条要求完全确定。
6. 这 $2^m-1$ 个 $u_T$ 线性无关：若 $\sum_Tc_Tu_T=0$ 而有非零系数，取一个系数非零、且没有系数非零的真子集的 $T_0$，在 $S=T_0$ 处求值；$u_T(T_0)=1$ 当且仅当 $T\subseteq T_0$，按 $T_0$ 的取法只剩 $c_{T_0}$ 一项，得 $c_{T_0}=0$，矛盾。满足 $v(\varnothing)=0$ 的博弈由 $2^m-1$ 个数 $v(S)$（$S\ne\varnothing$）决定，所以这些 $u_T$ 构成一组基，任何这样的 $v$ 都能写成 $\sum_Tc_Tu_T$。
7. 由可加性，$\psi_j(v)=\sum_T\psi_j(c_Tu_T)$，每一项都已由第 5 步确定。所以满足四条的方法至多一种，而第 1–4 步说明 Shapley 值是其中之一。$\square$

### 8.8.5 基线是一个选择

上面的 $v_x$ 把"不知道的事实"换成基线案例里的值，不管它们和已知事实是否搭配。另一种做法是**条件式**值函数 $v_x(T)=\mathbb{E}[f(X)\mid X_T=x_T]$，只在已知事实取值相同的案例里平均。对案例 6，条件式给出 $a$、$b$、$p$ 的归因 $5/72$、$-5/36$、$41/72$，与干预式的 $1/6$、$-5/24$、$13/24$ 不同（两组之和都是 $1/2$）。

两种都叫"SHAP"，回答的是不同的问题。Janzing、Minorics 与 Blöbaum（2020）认为解释**模型**应当用干预式；Sundararajan 与 Najmi（2020）列举了多种 Shapley 值的变体及其各自的反常表现。对申诉者来说更要紧的是：**归因相对于基线**，换一个基线（比如只用本月的案例），同一个判定的归因就变了。还要注意，$p$ 的大幅正分完全建立在案例 6 一个案例上（第 1 章 1.10.6 节的警告）：Shapley 值描述的是模型，不是世界。

### 小结

这一节说的是：Shapley 值把"输出减基线"按所有加入顺序的平均边际贡献分给各事实，它是唯一满足有效性、对称性、零贡献者、可加性的分配；但值函数和基线要另外选择，选择不同，归因不同。

## 8.9 反事实解释

### 8.9.1 问题

案例 4，$(a,b,p)=(1,0,0)$，被规则戊判 B。买家想知道的通常不是"各事实各得几分"，而是：**要怎样不同，结论才会是 S？** Miller（2019）综述社会科学的研究后指出，人寻求的解释通常是**对比式**的："为什么是 B，而不是 S？"

### 8.9.2 定义

Wachter、Mittelstadt 与 Russell（2018）提出用反事实解释回答这个问题，并指出它不必打开黑盒就能给出，对被判定的人直接有用。

**定义 8.4（反事实解释）** 给定模型 $f$、输入 $x$、想要的结论 $y'\ne f(x)$ 和输入间的距离 $d$，**反事实解释**是

$$
x'\in\arg\min_{z:\,f(z)=y'}d(x,z).
$$

**怎么读**：在所有能得到结论 $y'$ 的输入里，找离 $x$ 最近的一个。解释的内容是 $x$ 与 $x'$ 的差别："如果……，结论就会是 $y'$。"对连续输入，Wachter 等人用的是带罚分的版本 $\lambda(f(z)-y')^2+d(x,z)$，并用各特征的中位数绝对偏差给 $L_1$ 距离加权，以便用梯度方法求解。

**在例子里**：取 $d$ 为取值不同的事实个数。案例 4 到 S 的最近反事实有两个，距离都是 1：

- 把 $b$ 改成 1："如果描述指向腐烂，结论会是 S。"
- 把 $p$ 改成 1："如果描述提到包装破损导致渗出，结论会是 S。"

到 O 的最近反事实是把 $a$ 改成 0，对买家没有意义。

### 8.9.3 三个问题

1. **不唯一。** 案例 4 有两个同样近的反事实，给哪个、给几个，是解释者的选择。
2. **可行性。** "如果你在 48 小时内申请"对已经超时的买家没有用。Ustun、Spangher 与 Liu（2019）把能通过实际行动达到的反事实称为**追索**（recourse），并给出在约束下计算它的方法，例如给不可改变的事实无穷大的距离。
3. **事实不是行动。** 在售后场景里，$b$ 和 $p$ 不是买家能"做到"的事，而是关于商品的事实。对它们的反事实，真正的用处是**申诉**："如果你认为系统把描述读错了，指出来，结论会变。"在"先读事实、再用规则"的系统里这一点特别清楚：规则上的反事实可以精确算出，申诉被分成两个能分别核实的问题：事实读对了吗？规则对吗？

### 小结

这一节说的是：反事实解释给出离当前输入最近、结论不同的输入，直接回答"怎样不同结论才会变"；它不唯一，要区分能做到与做不到的改变，在事实层面它最自然的用途是申诉。

## 8.10 锚点

### 8.10.1 想法

反事实问"改什么会变"；**锚点**问相反的问题："哪些条件不改，结论就基本不变？"Ribeiro、Singh 与 Guestrin（2018）把锚点定义为一条 if-then 规则：在满足它的扰动样本上，模型以高概率给出与原判定相同的结论。

**定义 8.5（锚点）** 设 $A$ 是关于输入的一组条件，$\mathcal{P}$ 是扰动样本的分布。$A$ 的**精度**和**覆盖率**分别是

$$
\begin{aligned}
\operatorname{prec}(A)&=\Pr_{z\sim\mathcal{P}}\big(f(z)=f(x)\mid A(z)\big),\\
\operatorname{cov}(A)&=\Pr_{z\sim\mathcal{P}}\big(A(z)\big).
\end{aligned}
$$

若 $x$ 满足 $A$ 且 $\operatorname{prec}(A)\ge\tau$，就称 $A$ 是 $x$ 的一个**锚点**；锚点之间优先选覆盖率大的。

**怎么读**：精度是"满足条件的扰动样本里结论没变的比例"；覆盖率是"条件有多常见"；$\tau$ 是事先定的门槛，例如 0.95。

### 8.10.2 在例子上算一算

解释案例 6 的 S，比较两种扰动分布：**经验分布**（直接从 8 个案例里抽）和**独立分布**（每个事实按 8 个案例中的比例独立抽：$\Pr(a=1)=3/4$，$\Pr(b=1)=1/2$，$\Pr(p=1)=1/8$）。

| 条件 $A$ | 经验：精度 | 经验：覆盖率 | 独立：精度 | 独立：覆盖率 |
|---|---|---|---|---|
| $p=1$ | 1 | 1/8 | 3/4 | 1/8 |
| $a=1$ | 2/3 | 3/4 | 9/16 | 3/4 |
| $a=1$ 且 $p=1$ | 1 | 1/8 | 1 | 3/32 |

取 $\tau=0.95$。在经验分布下，最短的锚点是"$p=1$"：8 个案例里 $p=1$ 的只有案例 6，它恰好在时限内。在独立分布下，"$p=1$"的精度只有 $3/4$（四分之一的扰动样本超时，判 O），锚点必须是"$a=1$ 且 $p=1$"，正是规则戊在这个案例上的路径。

经验分布下"$p=1$ 就够了"，是一个案例造成的偶然：手头恰好没有"超时且破损"的案例。锚点依赖扰动分布，这和 LIME 依赖核宽度、Shapley 值依赖基线是同一个问题。

### 小结

这一节说的是：锚点是一组"满足它结论就基本不变"的条件，用精度和覆盖率衡量；它的读法最像规则，但依赖扰动分布，在小样本上可能把偶然当作充分条件。

## 8.11 事后解释怎样失败

前面四节已经看到了失败的苗头。这一节把它们归成三类。

### 8.11.1 不稳定

同一个模型、同一个输入，解释随设置（核宽度、基线、扰动分布、随机种子）而变；输入稍有改动、模型输出几乎不变时，解释却可能大变。Alvarez-Melis 与 Jaakkola（2018）用局部利普希茨常数度量这种不稳定，发现 LIME 等方法在一些数据上相当不稳定；Ghorbani、Abid 与 Zou（2019）展示了对图像的微小扰动可以在不改变预测的情况下大幅改变显著图；Adebayo 等人（2018）发现，一些显著图方法在模型参数被随机化后给出的图依然相似，说明它们反映的更多是输入而不是模型。

### 8.11.2 可以被操纵

LIME 和 SHAP 都只通过**查询**模型来生成解释。这带来一个结构性的弱点。

**命题 8.3（解释只看见被查询的点）** 设解释方法 $E$ 对模型 $f$ 和输入 $x$ 给出的解释，只依赖于 $x$ 和 $f$ 在某个查询集合 $Q(x)$ 上的取值。若 $f$ 与 $f'$ 在 $Q(x)$ 上处处相同，则 $E(f,x)=E(f',x)$，不论两者在别处差多少。

**证明（第一遍可以跳过）.** $E$ 的输出是 $x$ 与 $\{(z,f(z)):z\in Q(x)\}$ 的函数；把 $f$ 换成 $f'$，这些量都不变，所以输出不变。$\square$

命题几乎是同义反复，但 Slack 等人（2020）把它变成了一种攻击。LIME 和 KernelSHAP 的扰动样本往往不像真实数据（例如各列独立抽样，拼出现实中不存在的组合）。于是可以训练一个分类器区分"真实输入"和"扰动样本"，再构造

$$
f'(z)=\begin{cases}f_{\text{偏}}(z),&z\text{ 像真实输入},\\ f_{\text{净}}(z),&z\text{ 像扰动样本}.\end{cases}
$$

$f_{\text{偏}}$ 在真实输入上直接使用种族等敏感属性，$f_{\text{净}}$ 只用与敏感属性无关的特征。解释方法查询的大多是扰动样本，看到的几乎全是 $f_{\text{净}}$，于是报告"模型不依赖敏感属性"。他们在 COMPAS 等数据集上演示了这种攻击。这也说明了保真度为什么必须指明分布（定义 8.2）：解释可以在扰动分布上高度忠实，在真实输入上完全不忠实。

### 8.11.3 方法之间不一致

对同一个判定，不同方法给出的重要性常常不同。案例 6 上：

- 读规则路径：$a$ 和 $p$ 起作用，$b$ 不出现；
- LIME（$\sigma=2$）：$a>p>b$，三者都为正；
- 干预式 Shapley：$p>a$，$b$ 为负；
- 条件式 Shapley：$p$ 远大于 $a$，$b$ 为负。

Krishna 等人（2022）访谈实践者并比较多种方法后发现，这种**分歧问题**普遍存在，而实践者常凭直觉挑一个"看起来对"的解释。这恰恰是用可信度代替忠实性。

对规则系统而言，规则本身是内在的全局解释，不需要上面任何一种方法；但规则上游的读取器是黑盒，"读取器为什么读出 $b=1$"的解释仍会遇到这三类问题。

### 小结

这一节说的是：事后解释会随设置和微小扰动而变，可以被专门针对查询分布的模型愚弄，不同方法对同一判定也常常不一致；挑一个"看起来对"的解释，是用可信度冒充忠实性。

## 8.12 符号模型怎样才算好读

### 8.12.1 几个维度

规则和树是内在可解释的，但"好读"有程度之分。常用的维度有：

1. **规模**：叶子数、规则条数、条件总数。
2. **深度**：一个判定最多看几个条件；按案例比例加权，得到**平均路径长度**，即典型案例要看几个条件。
3. **用到的不同事实个数**：读者要掌握多少个概念。一棵 7 片叶子、反复问同样 3 个事实的树，可能比 4 片叶子、用了 4 个陌生事实的树好读。
4. **单调性**与**领域一致性**：见 8.12.3 节。

第 3 章 3.9 节已经说明这些度量与泛化不是一回事，这里只关心它们与"人读得懂"的关系。规模小、用到的事实少，统称**稀疏性**，它是最常用的功能层代理（8.3 节），但也只是代理。

### 8.12.2 列表和树：谁更短取决于函数

**一个让树吃亏的例子。** 取四个事实 $x_1,\dots,x_4$ 和函数"$(x_1\wedge x_2)\vee(x_3\wedge x_4)$ 时为 1"。决策列表只要两条：

> 若 $x_1\wedge x_2$ → 1；否则若 $x_3\wedge x_4$ → 1；否则 → 0。

决策树则要在 $x_1\wedge x_2$ 不成立的每个分支里把"$x_3\wedge x_4$"重问一遍。穷举所有决策树可以验证，计算这个函数的最小树有 7 片叶子；换成三个互不相交的两事实合取，最小树有 15 片叶子，列表只要三条。这叫树的**重复子树问题**。

**一个让列表吃亏的例子。** 0.7.3 节已经指出，列表的第 $k$ 条只在前 $k-1$ 条都不成立时才生效，所以单独读第 $k$ 条是不够的。下面把这个隐含条件有多长算出来。

**命题 8.4（决策列表的隐含条件）** 设决策列表为"若 $t_1$ 则 $y_1$；否则若 $t_2$ 则 $y_2$；……"，每个 $t_j$ 是 $\ell$ 个文字的合取，且不同 $t_j$ 用到的事实互不相同。则输入落入第 $k$ 条的条件 $t_k\wedge\neg t_1\wedge\cdots\wedge\neg t_{k-1}$ 写成析取范式，至少需要 $\ell^{k-1}$ 个合取项，每项至少 $\ell+k-1$ 个文字，而且这个数目可以达到。相比之下，决策树的每片叶子都是一个合取式，长度等于它的深度。

**怎么读**：$\ell=2$、$k=5$ 时，第 5 条的完整生效条件要写成 $2^4=16$ 个合取项，每项 6 个文字。读者想不借助前面的规则、单独说清"这个案例为什么落在第 5 条"，要掌握的东西比第 5 条本身多得多。树的每片叶子则自带完整条件。

#### 证明（第一遍可以跳过）

**思路**：把每个 $\neg t_j$ 展开成析取再乘开，得到 $\ell^{k-1}$ 项；再为每一项构造一个"只有它能盖住"的输入。

1. 记 $t_j=\lambda_{j1}\wedge\cdots\wedge\lambda_{j\ell}$。由德摩根律（0.7 节），$\neg t_j=\neg\lambda_{j1}\vee\cdots\vee\neg\lambda_{j\ell}$。按分配律乘开：从每个 $\neg t_j$（$j<k$）里选一个 $\neg\lambda_{j,i_j}$，与 $t_k$ 合取，共 $\ell^{k-1}$ 种选法，每项 $\ell+k-1$ 个文字。所以这个数目可以达到。
2. 对每种选法 $(i_1,\dots,i_{k-1})$，构造输入 $z$：$t_k$ 的文字全真；对每个 $j<k$，$\lambda_{j,i_j}$ 为假、$t_j$ 的其余文字为真。各 $t_j$ 用到的事实互不相同，所以这些要求不冲突。$z$ 满足条件。
3. 任取一个与条件等价的析取范式，设 $C$ 是其中在 $z$ 上为真的一项；$C$ 为真时条件必为真。若 $C$ 不含 $\neg\lambda_{j,i_j}$（某个 $j<k$），把 $z$ 中 $\lambda_{j,i_j}$ 翻成真：$C$ 不含 $\lambda_{j,i_j}$（它在 $z$ 上为假），也不含 $\neg\lambda_{j,i_j}$，所以 $C$ 仍为真；但这时 $t_j$ 全真，条件为假，矛盾。同理，若 $C$ 缺少 $t_k$ 的某个文字，把它翻成假也得到矛盾。所以 $C$ 包含 $\neg\lambda_{1,i_1},\dots,\neg\lambda_{k-1,i_{k-1}}$ 和 $t_k$ 的全部文字，至少 $\ell+k-1$ 个。
4. 两种不同的选法若在第 $j$ 个位置不同（$i_j\ne i'_j$），第一种对应的 $C$ 含 $\neg\lambda_{j,i_j}$，而第二种构造的输入上 $\lambda_{j,i_j}$ 为真，所以这个 $C$ 在那里为假，不能兼任。于是不同选法对应不同的项，至少 $\ell^{k-1}$ 项。$\square$

两个例子合起来说明：列表和树哪个更好读，取决于要表达的函数，也取决于读者要回答的问题。审计整套规则时，紧凑的列表可能更好；对单个案例说"为什么"时，树的路径或**无序规则集**更好。Lakkaraju、Bach 与 Leskovec（2016）正是以"每条规则能独立读懂"为理由提出可解释决策集，并用用户实验支持了这一点。

### 8.12.3 单调性与领域一致性

**定义 8.6（单调性）** 只看时限内的案例，结论上有一个"对买家有利"的顺序 $\mathrm B\prec\mathrm S$。规则 $h$ 对事实 $j$ **单调**，是指对任何输入 $x$，把 $x_j$ 从 0 改成 1，结论不会从 S 变成 B。

**例子**：设学到的是**规则己**："不在时限内 → O；否则，腐烂和包装破损恰好有一个 → S；否则 → B"。在时限内的 4 种组合上，把 $b$ 从 0 改成 1：$p=0$ 时 B→S，没问题；$p=1$ 时 S→B，违反。对 $p$ 同理。4 条"翻一个事实"的边里有 2 条违反单调性。

规则己在某批数据上的训练误差可能很低（只要"既腐烂又破损"的案例碰巧多是 B），但审核员一读就会拒绝它："又腐烂又破损，反而买家负责？"这种检查对规则可以**穷举**：对每个事实、其余事实的每种组合各比较一次；单调性约束也可以直接加进学习算法。**领域一致性**是更一般的要求：规则不依赖政策排除的依据（例如第 6 章的"急"字），条件方向符合常识，阈值落在有业务含义的位置（48 小时，而不是 47.3 小时）。

### 8.12.4 人类实验说了什么

功能层代理在多大程度上反映"人读得懂"，要靠人类实验回答。下面几项的结论都应当看作初步的：

- Huysmans 等人（2011）比较了决策表、决策树和规则列表，发现在他们的任务上，决策表让参与者答得更准、更快、更有信心。
- Lage 等人（2019）在受控实验中改变规则的长度、条件数和引入的新概念数，发现这些因素都会增加人回答问题的时间，其中引入新概念的影响较突出。
- Poursabzi-Sangdeh 等人（2021）做了一组预先登记的大规模实验（数千名参与者，预测纽约公寓价格），改变模型的特征个数（2 个或 8 个）以及是否展示模型内部。看到 2 个特征的透明模型的参与者更会模拟模型的输出；但在跟随模型建议的程度上，各组差别不明显；而在模型对异常输入犯了明显错误时，看到透明模型的参与者**反而更不容易**发现和纠正错误，作者认为可能与信息过载有关。

最后一条和 8.1.1 节的乐观例子形成对照：读得懂规则，不等于会用它识别错误。那 6 个百分点要真正兑现，还需要培训和界面设计，这只能靠应用层评估来验证。

### 小结

这一节说的是：符号模型的可读性取决于规模、深度、事实个数、单调性和领域一致性；列表可能比树短得多，树的叶子却自带完整条件，哪个更好读取决于函数和读者的问题；人类实验表明更透明不一定带来更好的纠错。

## 8.13 输入也必须可解释

### 8.13.1 问题

规则甲的每个条件读起来都清楚，但这有一个前提：**条件里的事实本身是清楚的。** 如果规则是

> 若 $z_{17}>0.3$ 且 $z_{42}\le-1.1$ → S；否则 → B，

其中 $z$ 是某个神经网络的内部表示，那么这条规则很短、可模拟，却不可分解，对审计、申诉、知识发现都没有用。

### 8.13.2 好的事实要满足什么

一个事实要能支撑可解释的规则，至少要满足三条：

1. **可观察**：能从原始材料（描述、照片、签收记录）里直接看出来，而不是推测意图。"描述是否提到霉斑"可观察；"买家是否诚实"不可观察。
2. **定义清楚**：边界情形事先说定。"腐烂"包括"有点软"吗？包括"有异味但没看到霉斑"吗？定义不清，同一段描述不同的人会读出不同的值。
3. **可独立核查**：第三方不借助模型，只看原始材料就能判断读得对不对。这让事实层的错误可以单独发现、单独申诉（8.9.3 节）。

满足这三条的事实，让可解释性可以**分两层核查**：事实读得对不对（对照原始材料核对；后面讲测量与标注时会给出度量一致性的方法），规则对不对（读规则、对照政策）。这是"语言模型读事实、规则做判定"作为一种可解释性设计的核心：**不透明的部分被限制在一个个可以单独核查的小问题里。**

### 8.13.3 局限：事实问题可以夹带结论

这个设计有一个容易被忽视的漏洞。

**命题 8.5（透明可以被搬走）** 设 $\mathcal{Y}=\{\mathrm S,\mathrm B,\mathrm O\}$。对任何假设 $h:\mathcal{X}\to\mathcal{Y}$，定义事实 $q_k(x)=\mathbf{1}[h(x)=k]$。则规则"若 $q_{\mathrm S}=1$ → S；否则若 $q_{\mathrm B}=1$ → B；否则 → O"与 $h$ 在每个输入上结论相同。

**证明（第一遍可以跳过）.** 对任意 $x$，恰有一个 $k$ 使 $q_k(x)=1$，即 $k=h(x)$。若 $h(x)=\mathrm S$，第一条生效，输出 S；若 $h(x)=\mathrm B$，则 $q_{\mathrm S}=0$、$q_{\mathrm B}=1$，输出 B；否则 $h(x)=\mathrm O$，两者都为 0，输出 O。$\square$

**怎么读**：任何黑盒都能改写成一条两行的"透明"规则，只要允许事实是"卖家是否应负责"这样的问题。所以**规则短本身什么也不说明**，可解释性的分量全在事实上。

实际中的夹带往往没有这么露骨。例如"商品问题是否由卖家造成"听上去是关于商品的事实，其实已经包含了定责判断。几项可以用的检查：

- **不知道政策的人能回答吗？** 回答"是否提到霉斑"不需要懂售后政策；回答"是否由卖家造成"需要。
- **定义里有没有结论的词？** 出现"责任""过错""应当""合理"一类词，就要警惕。
- **核查它是否等于重新做一次判断？** 如果核查这个事实就是重新定一次责，它就不是独立的事实。
- **它是否几乎单独决定了结论？** 这一条只是信号：真正的好事实（如腐烂）也可能很有预测力。但若一个事实单独就把训练代价压到接近碰撞下界，而它又通不过前三项检查，它很可能就是结论换了个说法。

### 小结

这一节说的是：规则读的事实若是不透明的学习特征，规则再短也不可解释；好的事实应当可观察、定义清楚、可独立核查，这让事实和规则可以分开核查；但任何黑盒都能改写成"夹带结论的事实"上的短规则，所以可解释性最终落在事实的定义上。

## 8.14 可解释性与其他目标

### 8.14.1 准确

8.4 节已经说明：在结构化事实上，准确与可解释的取舍常常不大；在原始信号上取舍是真实的，"先读事实"的设计把它转移到了读取器上。还有一种常被忽视的情况：可解释的模型可能**更**准，因为人读得懂规则，就能发现测试集看不出来的捷径和数据错误（第 6 章 6.7 节）。

### 8.14.2 策略性行为

**例子**（数字是假设的）。只看时限内的案例，S 和 B 各一半。比较两个事实：

- $b'$：描述里**是否出现**腐烂相关的字眼。$\Pr(b'=1\mid\mathrm S)=0.9$，$\Pr(b'=1\mid\mathrm B)=0.1$。规则"$b'=1$ → S"的错误率是 $0.5\times0.1+0.5\times0.1=0.10$。
- $b''$：上传的照片**经核验**是否显示腐烂。$\Pr(b''=1\mid\mathrm S)=0.8$，$\Pr(b''=1\mid\mathrm B)=0.05$。规则"$b''=1$ → S"的错误率是 $0.5\times0.2+0.5\times0.05=0.125$。

规则公开前，$b'$ 更好。规则公开后，设本该买家负责、原来没写这些字眼的买家中有 30% 学会了在描述里加"发霉"：$\Pr(b'=1\mid\mathrm B)$ 变成 $0.1+0.9\times0.3=0.37$，错误率升到 $0.05+0.5\times0.37=0.235$。$b''$ 不受影响，仍是 0.125。只要这个比例超过约 5.6%，可核查的 $b''$ 就更好。

Hardt、Megiddo、Papadimitriou 与 Wootters（2016）把这类情形形式化为**策略性分类**：决策者先公布分类器，被分类的人再付出一定代价改变自己的特征以获得有利结论，决策者应当预见这一点来选分类器。后续工作（如 Kleinberg 与 Raghavan 2020）区分了两种改变：**钻空子**（特征变了，真实情况没变，例如加字眼）和**真实改进**（例如卖家真的改进了包装）。可解释性在这里有两面：公开规则让钻空子更容易；但如果规则用的是**难伪造、可核查**的事实，公开规则反而只会鼓励真实改进。这又回到了 8.13.2 节对事实的要求。

### 8.14.3 隐私

解释会泄露信息。规则里如果有一片只由一个训练案例支撑的叶子（比如规则戊的"包装破损"分支，在 8 个案例里只有案例 6 支持），公布规则就等于公布了这个案例的部分信息。对黑盒，Milli 等人（2019）指出，基于梯度的解释能让攻击者用少得多的查询重建模型；Shokri、Strobel 与 Zick（2021）研究了解释对成员推断攻击（判断某条记录是否在训练集里）的帮助。对规则系统，常用的做法是要求每片叶子至少覆盖若干个案例，这和第 2、3 章的复杂度控制方向一致。

### 8.14.4 公平

可解释模型让人能直接看到它是否用了敏感属性。但**看不到敏感属性不等于公平**：收货地区、设备型号等事实可能是它的代理。更麻烦的是，解释本身可以被优化得"看起来公平"：Aïvodji 等人（2019）展示了**公平洗白**（fairwashing），即为一个不公平的黑盒构造保真度高、但不公平程度低得多的规则列表作为"解释"。

命题 8.1 的反面在这里变得具体。设某个群体占 10%，代理规则的整体保真度为 0.95，但全部不一致都发生在这个群体里，那么群体内的保真度只有 $1-0.05/0.1=0.5$。**保真度要分组报告**，正如第 6 章 6.8 节要求错误率分组报告。

### 小结

这一节说的是：在结构化事实上可解释与准确的取舍常常不大；公开规则会诱发策略性行为，用可核查的事实能把它引向真实改进；解释可能泄露训练数据；可解释性有助于发现不公平，但看不到敏感属性不等于公平，解释本身也可以被优化成公平的样子。

## 8.15 一份检查清单

下面的问题用来评估一个判定系统在某个用途上是否可解释，按本章各节的顺序排列。回答"否"或"不知道"的地方，就是需要补证据或改设计的地方。

**一、为谁、为了什么**

1. 解释的读者是谁（审核员、被判定者、审计方、开发者）？要完成 8.1.2 节六种需求中的哪几种？
2. 需要全局解释、局部解释，还是两者都要（8.5 节）？

**二、输入**

3. 每个事实是否可观察、定义清楚、可独立核查（8.13.2 节）？
4. 有没有事实夹带了结论（8.13.3 节的四项检查）？
5. 读取器是否有版本号，换版本时是否在固定的核查集上重新测量（第 6 章 6.11 节）？

**三、模型本身**

6. 目标读者能否在规定时间内手算出结论（可模拟）？
7. 规模、深度、事实个数是多少？对单个案例的说明是否给出完整生效条件（命题 8.4）？
8. 是否穷举检查过单调性和与政策的一致性（8.12.3 节）？
9. 能否说明算法为什么选了这一条，而不是其他同样好的规则（8.2.3 节）？

**四、如果用了事后解释**

10. 能否直接改用内在可解释的模型（8.4 节）？
11. 报告了保真度吗？在哪个分布上？分组了吗（定义 8.2，8.14.4 节）？
12. 解释对设置（核宽度、基线、扰动分布）和不同方法是否稳定（8.11 节）？
13. 解释方法查询的点像不像真实输入（命题 8.3）？

**五、证据与后果**

14. 可解释性的证据属于功能层、人类层还是应用层（8.3 节）？
15. 被判定的人能否得到反事实形式的说明，并分别就事实和规则申诉（8.9 节）？
16. 规则公开后，有没有容易伪造的事实会被钻空子（8.14.2 节）？
17. 公布的规则或解释是否泄露个别案例（8.14.3 节）？
18. 每个判定是否记录了（读取器版本，规则版本），以便事后问责？

### 小结

这一节说的是：评估可解释性要依次检查读者与任务、事实、规则本身、事后解释的忠实与稳定，以及证据等级和副作用。

## 8.17 本章小结

- 可解释性服务于审计、申诉、调试、问责、信任校准和知识发现；它们问的是机制、单个判定和错误的结构，准确率回答不了（8.1 节）。
- Lipton 把透明性分为可模拟、可分解、算法透明三层；Doshi-Velez 与 Kim 把评估分为应用层、人类层、功能层；Rudin 主张高风险决策直接使用可解释的模型，这在结构化数据上常常不损失准确（8.2–8.4 节）。
- 内在可解释的模型就是自己的解释，事后解释总有忠实性问题。忠实与可信不同；保真度控制风险之差（命题 8.1），但不指出哪些判定的解释是错的（8.5–8.6 节）。
- LIME 拟合局部代理，依赖核宽度；Shapley 值是满足四条公理的唯一分配（定理 8.2），依赖值函数与基线；反事实解释回答"怎样才会不同"，不唯一、要区分可行性；锚点给出高精度的充分条件，依赖扰动分布（8.7–8.10 节）。
- 事后解释不稳定、可被操纵（命题 8.3）、彼此不一致（8.11 节）。
- 符号模型的可读性取决于规模、深度、事实个数、单调性和领域一致性；列表可能比树短得多，但第 $k$ 条规则隐含指数多的条件（命题 8.4）（8.12 节）。
- 规则读的事实必须可观察、定义清楚、可独立核查；任何黑盒都能改写成夹带结论的事实上的短规则（命题 8.5）（8.13 节）。
- 可解释性与准确、策略性行为、隐私、公平之间有张力（8.14 节）；8.15 节的清单把这些问题串在一起。
