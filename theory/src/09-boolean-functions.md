# 第 9 章　布尔函数与表达能力

## 本章导引

### 这一章要做什么

卷二讲人读得懂的符号模型：决策树、规则列表、规则集、评分卡。它们的输入都是语言模型读出来的 $m$ 个是/否事实。只看"判不判 S"这一个结论时，每条规则都是一个**布尔函数** $f:\{0,1\}^m\to\{0,1\}$，也就是输入为若干个 0/1、输出为 0 或 1 的函数。

0.7 节已经说过，同一个布尔函数可以写成真值表、析取范式、合取范式、决策树或决策列表，而且任何函数都能写成范式（命题 0.7.2）。这一章接着问：

- 同一个函数换一种写法，会短多少、长多少？差距什么时候是指数级的？
- 有没有一类函数，对"每次挑一个最有信息的事实"的贪心方法天生就难？是这一种算法笨，还是所有"只看统计平均"的方法都难？
- 加上"单调""线性"这类约束，可解释性得到了什么，表达能力又失去了什么？
- 写法的表达力越强，从数据里学它需要的样本越多。第 2 章的工具能把这个代价算出来吗？

主线是：**表达能力、样本复杂度、可读性三者互相牵制**。能写出一切函数的写法（真值表）既学不动也读不懂；读得懂的写法必然漏掉某些函数，被漏掉的往往正是奇偶函数这种"每个事实单看都没用，合起来才有用"的结构。

### 读完这一章，你会知道

1. 布尔函数的六种常用写法，以及各自的大小度量。
2. 写法之间的转换和大小界：$L$ 个叶子、深度 $d$ 的树给出不超过 $L$ 项、每项不超过 $d$ 个文字的析取范式；深度 $d$ 的树是 $d$-决策列表；$k$-DNF 和 $k$-CNF 都是 $k$-决策列表。
3. 两个指数级分离：奇偶函数在范式和树里都需要指数大小，也不是 $k<m$ 的 $k$-决策列表；有一族函数，析取范式只有 $m/2$ 项，决策树却至少要 $2^{m/2}$ 个叶子。
4. 为什么奇偶函数让贪心拆分失效：在均匀分布下，任何没有包含全部相关事实的事实组合都与结论独立。
5. 布尔函数的傅里叶展开：奇偶基函数、帕塞瓦尔恒等式、次数；低次函数为什么只靠相关系数就能学出来。
6. 统计查询模型，以及"只用统计平均的方法学不了奇偶函数"这个下界；它为什么覆盖了基于不纯度的贪心拆分。
7. 单调函数为什么更好审核，为什么贪心对它"总有信号"；什么是相关免疫函数。
8. 线性阈值函数和评分卡能写出什么、写不出什么（异或），以及 1-决策列表为什么总能写成阈值函数。
9. $k$-DNF、$k$-决策列表、深度 $d$ 的树的假设空间大小与 VC 维；Rivest 的 $k$-决策列表学习算法，以及它为什么总能找到一致的列表。

### 本章新词

| 词 | 一句话解释 |
|---|---|
| 布尔函数 | 输入是若干个 0/1、输出是 0 或 1 的函数 |
| 写法（表示） | 写下一个布尔函数的具体方式，如一棵树、一个公式 |
| 大小 | 一个函数在某种写法下最短能写多长 |
| 宽度 | 范式里最长的一项（或子句）含几个文字 |
| $k$-DNF、$k$-CNF | 每项（或每个子句）最多 $k$ 个文字的析取（合取）范式 |
| 分离 | 某个函数在一种写法下很短，在另一种写法下必然很长 |
| 奇偶函数 | 若干个事实里取 1 的个数是奇数时输出 1 |
| 奇偶基函数 | 把 0/1 换成 $\pm1$ 以后，一组变元的乘积 |
| 傅里叶系数 | 函数与某个奇偶基函数的相关程度 |
| 次数 | 傅里叶系数不为 0 的变元组里最大的那组有几个变元 |
| 低次算法 | 只估计小变元组的傅里叶系数、再取符号的学习方法 |
| 统计查询 | 学习算法只能问"某个量的平均值是多少"，得到一个带误差的回答 |
| 容差 | 统计查询的回答允许偏离真值的最大幅度 |
| 线性阈值函数 | 给每个事实一个权重，加起来和一个门槛比较 |
| 评分卡 | 权重是小整数的线性阈值函数，可以手算 |
| 单调函数 | 把任何一个事实从 0 改成 1，输出都不会从 1 变成 0 |
| 影响力 | 随机取其余事实、只改动这一个事实时，输出跟着变的概率 |
| 相关免疫 | 输出与任何少数几个输入都统计独立 |
| 恰当学习 | 要求学出来的规则和目标属于同一种写法 |

## 9.1 一个函数，几种写法

### 从"判 S"说起

0.7.3 节在规则甲的 $b=0$ 分支下加了一问 $p$（包装破损导致汁液渗出），得到一棵树："不在时限内→O；否则腐烂→S；否则渗出→S；否则→B"。只看"判不判 S"，它是 $a,b,p$ 上的一个布尔函数，记作 $f_{\mathrm S}$。它至少有六种写法：

1. **真值表**：$2^3=8$ 行，只有 $(a,b,p)=(1,1,0),(1,1,1),(1,0,1)$ 三行为 1。
2. **析取范式**：从树上读出来是 $(a\wedge b)\vee(a\wedge\neg b\wedge p)$；更短的写法是 $(a\wedge b)\vee(a\wedge p)$，2 项，每项 2 个文字。
3. **合取范式**：$a\wedge(b\vee p)$，2 个子句。
4. **决策树**：4 个叶子（O、S、S、B，其中 O 和 B 都算"不判 S"），深度 3。
5. **决策列表**：$(\neg a\to0),(b\to1),(p\to1),(1\to0)$，4 条，每条的条件只有 1 个文字。
6. **阈值函数**："在时限内记 2 分，腐烂记 1 分，渗出记 1 分，总分不低于 3 分判 S"，即 $f_{\mathrm S}=\mathbf{1}[2a+b+p\ge3]$。

把 8 种组合逐一代入，六种写法的输出完全一致（用 Python 核对过）。它们是同一个函数，只是长短不同、读法不同。

### 函数与写法要分开

**定义 9.1（写法与大小）** 一种**写法**（也叫表示类）$\mathcal{R}$ 是一组可以写下来的对象（公式、树、列表、权重向量），连同一条"怎样求值"的规定；每个对象 $r\in\mathcal{R}$ 确定一个布尔函数 $f_r$，并有一个长度 $\lvert r\rvert$。函数 $f$ 在 $\mathcal{R}$ 中的**大小**是能写出它的最短对象的长度：

$$
\operatorname{size}_{\mathcal{R}}(f)=\min\{\lvert r\rvert:r\in\mathcal{R},\ f_r=f\},
$$

写不出来时记为 $\infty$。

**怎么读**：$\lvert r\rvert$ 是"这一个写法有多长"，$\operatorname{size}_{\mathcal{R}}(f)$ 是"这个函数最短能写多长"。代入：$f_{\mathrm S}$ 的析取范式大小（按项数算）是 2。1 项不够：一个项要同时在 $(1,1,0)$ 和 $(1,0,1)$ 上为真，就不能含 $b$ 或 $p$ 的文字（这两行在 $b$、$p$ 上都不同），只能是 $a$ 或空项，而它们在 $(1,0,0)$ 上也为真，那里 $f_{\mathrm S}=0$。

本章用到的长度度量是：

- 真值表：$2^m$ 行，与函数无关。
- 析取范式：项数；最长一项的文字数叫**宽度**。合取范式同样看子句数与宽度。
- 决策树：叶子数 $L$ 和深度 $d$（根到叶子最长路径上的提问数）。二叉树有 $L-1$ 个内部结点。
- 决策列表：条数，以及每条条件最多几个文字。
- 阈值函数：非零权重的个数；权重是整数时，也看权重绝对值的大小。

**定义 9.2（$k$-DNF、$k$-CNF、$k$-决策列表）** 宽度不超过 $k$ 的析取范式叫 **$k$-DNF**，宽度不超过 $k$ 的合取范式叫 **$k$-CNF**；每条条件都是不超过 $k$ 个文字的项的决策列表叫 **$k$-决策列表**（$k$-DL，0.7.3 节）。同一记号也指它们能写出的函数全体。

$f_{\mathrm S}$ 同时属于 2-DNF、2-CNF 和 1-DL。

### 小结

这一节说的是：函数和写法是两回事；同一个函数在不同写法下有不同的大小，大小指能写出它的最短对象的长度；本章关心的度量是项数与宽度、叶子数与深度、列表长度与每条的文字数、权重。

## 9.2 写法之间的转换

### 问题

审核人员拿到一棵树，想把它改写成"若干条互不相关的规则"（析取范式），或者改写成按顺序检查的规则列表。会不会越改越长？下面三个命题说：从树出发，改写的代价很小。

**命题 9.1（树到范式）** 设 $f$ 有一棵 $L$ 个叶子、深度 $d$ 的决策树，其中 $L_1$ 个叶子标 1、$L_0$ 个叶子标 0。则 $f$ 有一个不超过 $L_1$ 项、宽度不超过 $d$ 的析取范式，也有一个不超过 $L_0$ 个子句、宽度不超过 $d$ 的合取范式。特别地，深度 $d$ 的树写出的函数属于 $d$-DNF 与 $d$-CNF 的交集。

**怎么读**：每条到 1 的路径变成一项，每条到 0 的路径变成一个子句。代入 $f_{\mathrm S}$ 的树：$L_1=2$，析取范式 $(a\wedge b)\vee(a\wedge\neg b\wedge p)$；$L_0=2$（O 叶子的路径 $\neg a$，B 叶子的路径 $a\wedge\neg b\wedge\neg p$），合取范式

$$
\neg(\neg a)\wedge\neg(a\wedge\neg b\wedge\neg p)=a\wedge(\neg a\vee b\vee p),
$$

它与 $a\wedge(b\vee p)$ 等价。

#### 证明（第一遍可以跳过）

**思路**：每个输入恰好走到一个叶子，所以"走到某个 1 叶子"就是"$f=1$"。

1. 对每个叶子 $v$，令 $t_v$ 是根到 $v$ 的路径上各个回答的合取（问 $x_j$ 答 1 记文字 $x_j$，答 0 记 $\neg x_j$）。$t_v(x)=1$ 当且仅当 $x$ 走到 $v$，$t_v$ 最多 $d$ 个文字。
2. 每个输入恰好走到一个叶子，所以 $f(x)=1$ 当且仅当某个标 1 的叶子 $v$ 有 $t_v(x)=1$。于是 $f=\bigvee_{v\text{ 标 }1}t_v$，共 $L_1$ 项。
3. 同理 $\neg f=\bigvee_{v\text{ 标 }0}t_v$。取否定并用德摩根律（命题 0.7.1），$f=\bigwedge_{v\text{ 标 }0}\neg t_v$，每个 $\neg t_v$ 是一个最多 $d$ 个文字的子句。$\square$

**命题 9.2（树到决策列表；Rivest 1987）** $L$ 个叶子、深度 $d$ 的决策树可以改写成一个 $L$ 条的 $d$-决策列表。

#### 证明（第一遍可以跳过）

把每个叶子写成一条规则 $(t_v\to v\text{ 的结论})$，按任意顺序排好，再把最后一条的条件换成常量 1。因为每个输入恰好满足一个 $t_v$，任何顺序下第一个触发的都是它所走到的那个叶子；最后一条换成"否则"后，走到这个叶子的输入仍然由它判定（前面的条件都不成立）。$\square$

**命题 9.3** $k$-DNF 和 $k$-CNF 都包含在 $k$-决策列表之中；$k$-决策列表的否定仍是 $k$-决策列表。

#### 证明（第一遍可以跳过）

1. $f=t_1\vee\dots\vee t_s$（每项不超过 $k$ 个文字）写成 $(t_1\to1),\dots,(t_s\to1),(1\to0)$：有一项为真时第一个为真的项输出 1，都不为真时输出 0。
2. $f=c_1\wedge\dots\wedge c_s$ 时，$\neg f=\neg c_1\vee\dots\vee\neg c_s$，每个 $\neg c_i$ 由德摩根律是不超过 $k$ 个文字的项。写成 $(\neg c_1\to0),\dots,(\neg c_s\to0),(1\to1)$。
3. 把决策列表的每个结论 0、1 互换，就得到它的否定。$\square$

把三个命题合起来，得到一条包含链：

$$
\text{深度 }k\text{ 的树}\subseteq k\text{-DNF}\cap k\text{-CNF}\subseteq k\text{-DNF}\cup k\text{-CNF}\subseteq k\text{-DL}.
$$

最后一个包含是严格的（练习 9.3 给出一个 1-决策列表，它既不是 1-DNF 也不是 1-CNF）。决策列表多出来的表达力来自顺序："否则"把前面所有条件的否定免费带进了后面的每一条。

### 小结

这一节说的是：从树出发改写很便宜，到 1 的路径变成项，到 0 的路径变成子句，所有路径排成列表；$k$-DNF 和 $k$-CNF 都是 $k$-决策列表的特例。

## 9.3 指数级的差距

上一节的转换都是"从树出发"。反方向未必便宜。这一节给出两个例子，说明有的函数在一种写法下很短，在另一种写法下必然很长。

### 奇偶函数在每一种写法里都很长

**命题 9.4（奇偶函数）** 设 $\mathrm{PAR}_m(x)=x_1\oplus x_2\oplus\dots\oplus x_m$（$\oplus$ 是模 2 加法，取 1 的个数为奇数时结果为 1），$m\ge1$。

1. 它的每个析取范式至少有 $2^{m-1}$ 项，每个合取范式至少有 $2^{m-1}$ 个子句。
2. 计算它的每棵决策树都恰好有 $2^m$ 个可达的叶子，并且每个输入都要问满 $m$ 个变元。
3. 对 $k<m$，它不是 $k$-决策列表。

**怎么读**：第 1 条 0.7.3 节已经证明过（合取范式的说法对 $\neg\mathrm{PAR}_m$ 用同一个论证再取否定即得）。代入 $m=20$：析取范式至少 524 288 项，决策树 1 048 576 个叶子。用中文说它只要一句话："成立的事实个数是奇数"。**"简单"是相对于写法而言的。**

#### 证明（第一遍可以跳过）

**思路**：只要还有一个变元没被固定，翻转它就会改变奇偶，所以任何"固定了一部分变元就给出答案"的结构都不行。

1. 第 2 条：一个叶子收到的输入，是"路径上问过的变元取路径上的值、其余任意"的全体。若某个可达叶子的路径没有问到某个变元 $x_j$，它收到的输入里就有两个只在 $x_j$ 上不同的输入，它们的奇偶不同，叶子却只有一个结论，矛盾。所以每个可达叶子都问到了全部 $m$ 个变元，恰好收到一个输入；$2^m$ 个输入各占一个叶子。
2. 第 3 条：先删掉条件自相矛盾（同时含 $x_j$ 和 $\neg x_j$）的规则，它们从不触发，删掉不改变函数。若第一条的条件是常量 1，列表是常函数，不是奇偶函数。否则第一条的条件 $t_1$ 可满足且只含不超过 $k<m$ 个文字，满足它的输入里有两个只在某个未出现的变元上不同；它们都由第一条判定，结论相同，但奇偶不同，矛盾。$\square$

### 范式很短、树却很长

奇偶函数在所有写法里都长。更有意思的是写法之间的分离。考虑 $m=2k$ 个变元 $x_1,y_1,\dots,x_k,y_k$ 上的函数

$$
g_k=(x_1\wedge y_1)\vee(x_2\wedge y_2)\vee\dots\vee(x_k\wedge y_k).
$$

**怎么读**：有 $k$ 种独立的"证据组合"，每种要两个条件同时成立，任何一种成立就判 1。售后里的例子是："照片里有霉斑且照片拍摄于签收当天"，或者"买家录了开箱视频且视频里能看到腐烂"，或者……。它是 $k$ 项的 2-DNF，也是 $k+1$ 条的 2-决策列表。

**命题 9.5** 计算 $g_k$ 的每棵决策树至少有 $2^k$ 个标 0 的叶子，所以至少有 $2^{m/2}$ 个叶子。

#### 证明（第一遍可以跳过）

**思路**：由命题 9.1，标 0 的叶子给出 $\neg g_k$ 的一个析取范式，所以只需证明 $\neg g_k$ 的每个析取范式至少有 $2^k$ 项。办法是找出 $2^k$ 个输入，使得任何一项都最多覆盖其中一个。

1. 在 $\neg g_k$ 的析取范式里，每一项 $T$ 为真时 $\neg g_k$ 都为真（否则这个范式在那个输入上算错了）。
2. 对每一种选择 $c=(c_1,\dots,c_k)$，$c_i\in\{x_i,y_i\}$，定义输入 $z_c$：第 $i$ 块里被 $c_i$ 选中的变元取 0、另一个取 1。每块都不全为 1，所以 $\neg g_k(z_c)=1$。这样的输入共 $2^k$ 个。
3. 设某一项 $T$ 在两个不同的 $z_c$、$z_{c'}$ 上都为真，它们在第 $i$ 块的选择不同。那么 $x_i$、$y_i$ 在两个输入上的取值都相反，$T$ 里任何关于 $x_i$ 或 $y_i$ 的文字都会在其中一个上为假，所以 $T$ 不含这两个变元的文字。
4. 从 $z_c$ 出发，把 $x_i$、$y_i$ 都改成 1。$T$ 不涉及它们，仍然为真；但第 $i$ 块全为 1，$g_k=1$，$\neg g_k=0$。这与第 1 步矛盾。所以每一项最多覆盖一个 $z_c$。
5. 范式必须覆盖全部 $2^k$ 个 $z_c$，所以至少有 $2^k$ 项，树至少有 $2^k$ 个标 0 的叶子。$\square$

这个下界差不多是紧的。逐块提问的树（先问 $x_1$，为 0 就去处理剩下的 $k-1$ 块；为 1 再问 $y_1$，为 1 判 1，为 0 也去处理剩下的块）的叶子数满足 $T(k)=2T(k-1)+1$、$T(0)=1$，即 $2^{k+1}-1$。用 Python 对 $k\le4$ 穷举了所有决策树，最少叶子数确实是 3、7、15、31。代入 $k=10$（$m=20$）：析取范式 10 项、决策列表 11 条，决策树至少 1024 个叶子，逐块提问的树有 2047 个。

树之所以长，是因为"第 1 块不成立时检查剩下各块"这一段必须在 $x_1=0$ 和 "$x_1=1$、$y_1=0$" 两个分支里**各抄一遍**。这叫决策树的**重复子树问题**（Pagallo 与 Haussler 1990）。反过来，树也不会比决策列表差太多：Ehrenfeucht 与 Haussler（1989）定义了树的"秩"，Blum（1992）证明秩为 $r$ 的树是 $r$-决策列表，而 $s$ 个叶子的树秩不超过 $\log_2s$。

### 小结

这一节说的是：奇偶函数在范式、树、$k<m$ 的决策列表里都需要指数大小；$g_k$ 是 $m/2$ 项的 2-DNF，决策树却至少要 $2^{m/2}$ 个叶子，原因是树必须把公共的子结构重复抄写。

## 9.4 奇偶函数：单看哪个事实都没有信息

### 一个售后场景

设想另一批 8 个案例，编号 9–16，都在时限内、都已腐烂（$a=b=1$），按规则甲全部判 S。但平台的真实政策是"**腐烂发生时货在谁手里，谁负责**"。语言模型读出两个新事实：

- $u$：买家选择到店自提（1 表示自提）；
- $v$：腐烂发生在运输途中（1 表示是）。

卖家发货时（$u=0$），运输途中腐烂归卖家（S），送达后才腐烂归买家（B）；买家自提时（$u=1$），运输由买家自己负责，途中腐烂归买家（B），自提之前在门店里就坏了归卖家（S）。所以结论是 S 当且仅当 $u\oplus v=1$：

| 案例 | $u$ | $v$ | 结论 |
|---|---|---|---|
| 9、10 | 0 | 0 | B |
| 11、12 | 0 | 1 | S |
| 13、14 | 1 | 0 | S |
| 15、16 | 1 | 1 | B |

**贪心会怎样做？** 根结点有 4 个 S、4 个 B，熵 1 比特，基尼不纯度 0.5。

- 按 $u$ 拆：两边都是 2 个 S、2 个 B，熵仍是 1，基尼仍是 0.5，信息增益和基尼增益都是 0。按 $v$ 拆完全一样。
- 用第 1 章的代价矩阵（$c(\mathrm S,\mathrm B)=3$，其余错误为 1）也一样：根结点判 S 的代价是 4（4 个 B 各错 1），判 B 是 12；按 $u$ 拆以后，两边都判 S，各 2，合计仍是 4，代价下降为 0。

贪心停在根结点，全判 S，代价 4。而"先问 $u$ 再问 $v$"的深度 2 树代价为 0。这正是 0.5.8 节的情形，这里多了一个业务含义：**两个事实各自都"无关"，合起来却完全决定结论**。如果直接让语言模型读第三个事实 $w$："腐烂发生时货物在卖家一方手中"，那么 $w=u\oplus v$，按 $w$ 拆的信息增益是 1 比特，一步到位。（以上数字都用 Python 核对过。）

### 一般结论

**命题 9.6（奇偶函数与任何不完整的事实组合独立）** 设随机输入 $X=(X_1,\dots,X_m)$，非空集合 $A\subseteq\{1,\dots,m\}$，结论 $Y=\bigoplus_{j\in A}X_j$。设 $T$ 是任意一组变元，且 $A$ 中有某个**不在** $T$ 里的变元 $X_j$ 在 $\{0,1\}$ 上均匀分布，并与其余 $m-1$ 个变元独立。则 $Y$ 与 $X_T$（$T$ 中变元的取值）独立：对 $X_T$ 的每个可能取值 $s$，

$$
\Pr(Y=1\mid X_T=s)=\tfrac12 .
$$

因此 $I(X_T;Y)=0$。特别地，若 $X$ 在 $\{0,1\}^m$ 上均匀分布、$Y=\mathrm{PAR}_m(X)$，则任何少于 $m$ 个变元的组合都与 $Y$ 独立：在只问过这些变元的结点上，用其中任何一个变元拆分，熵、基尼不纯度、错误数、加权代价都不会下降。

**怎么读**：还没问到的那个 $X_j$ 像一枚公平的硬币，不管别的事实是什么，它都以一半的概率把结论翻过来。代入售后场景：$A=\{u,v\}$，$T=\{u\}$，$v$ 是那枚硬币（四种组合各占两例，所以在这 8 个案例的经验分布上 $v$ 均匀且与 $u$ 独立），于是 $\Pr(\mathrm S\mid u=0)=\Pr(\mathrm S\mid u=1)=1/2$。

#### 证明（第一遍可以跳过）

**思路**：先固定除 $X_j$ 以外的所有变元，此时 $Y$ 由 $X_j$ 一枚硬币决定，概率 1/2；再按全期望公式平均回去。

1. 记 $Z$ 为除 $X_j$ 以外的全部变元。因为 $j\notin T$，$X_T$ 是 $Z$ 的一部分。$Y=X_j\oplus W$，其中 $W=\bigoplus_{i\in A,i\ne j}X_i$ 只依赖于 $Z$。
2. 给定 $Z=z$，由独立性 $X_j$ 仍均匀，所以 $\Pr(Y=1\mid Z=z)=\Pr(X_j=1\oplus W(z))=1/2$。
3. 对满足 $X_T=s$ 的 $z$ 求平均（全期望公式），$\Pr(Y=1\mid X_T=s)=1/2$，与 $s$ 无关，所以 $Y$ 与 $X_T$ 独立，由命题 0.4.5 互信息为 0。
4. 一个只问过 $T$ 中变元的结点，对应 $X_T$ 的一组取值；在任何这样的结点及其子结点上，结论的分布都是 $(1/2,1/2)$。拆分前后各结点的不纯度相同，加权平均也相同，下降为 0。$\square$

### 三点说明

**往前多看几步也没用。** 当 $\lvert A\rvert=r$ 时，同时考察任意 $r-1$ 个变元的"前瞻"贪心仍然什么也看不到，必须一次看齐全部 $r$ 个。在 $m$ 个事实里，这样的组合有 $\binom{m}{r}$ 个。

**有限样本里，增益不会恰好为 0。** 真实数据中四种组合不会恰好各占一半，各个增益是一些小的随机正数（0.4.6 节的警告）。贪心于是挑中噪声最大的那个变元，比停在根结点更糟：它造出了一个看似有信号的假分支。

**均衡是前提。** 命题要求 $A$ 中有一个没问过的变元是"公平硬币"。若 $u$ 均匀而 $\Pr(v=1)=0.8$，且两者独立，那么 $\Pr(\mathrm S\mid u=0)=0.8$、$\Pr(\mathrm S\mid u=1)=0.2$，$u$ 单看就有很强的信号（这时没问过的 $v$ 不是公平硬币）；但单看 $v$ 仍然是 $1/2$ 对 $1/2$（因为 $u$ 是公平硬币）。所以真实数据里异或结构能不能被贪心碰巧发现，取决于事实的分布，而不是算法。

### 小结

这一节说的是：结论是若干事实的奇偶时，只要还有一个均匀、独立的相关事实没问到，结论就与已问过的事实完全独立；在均匀分布下，奇偶函数让任何不完整的事实组合增益为 0，贪心与有限步前瞻都看不到它；直接测量"组合起来的那个事实"可以一步解决。

## 9.5 傅里叶展开

### 问题

命题 9.6 说的是"奇偶函数与少数变元的任何组合都不相关"。反过来想：能不能给每个布尔函数建立一套"坐标"，一眼看出它和每一组变元的相关有多强？这套坐标就是傅里叶展开。本节和下一节都假设输入在所有 $2^m$ 种组合上**均匀分布**。

### 换成 $\pm1$

把每个 0/1 值 $t$ 换成 $(-1)^t$：0 变成 $+1$，1 变成 $-1$。输出也这样换：$f(x)=-1$ 表示"判 S"（真），$+1$ 表示不判 S。这个换法乍看别扭，好处只有一个，但很关键：

$$
(-1)^{s\oplus t}=(-1)^s\,(-1)^t .
$$

**怎么读**：左边是"先做异或再换号"，右边是"先换号再相乘"。异或变成了乘法。代入 $s=t=1$：$s\oplus t=0$，左边 $+1$；右边 $(-1)(-1)=+1$。（O'Donnell 2014 采用同样的约定。）

**定义 9.3（奇偶基函数与内积）** 对 $A\subseteq\{1,\dots,m\}$，**奇偶基函数**是

$$
\chi_A(x)=\prod_{j\in A}x_j,\qquad x\in\{-1,1\}^m,
$$

约定 $\chi_\varnothing=1$。两个函数 $f,g:\{-1,1\}^m\to\mathbb{R}$ 的**内积**是 $\langle f,g\rangle=\mathbb{E}[f(X)g(X)]$，$X$ 均匀分布。

**怎么读**：$\chi_A$ 就是"$A$ 里的原始事实取 1 的个数是奇数时为 $-1$"，也就是换号后的奇偶函数。共有 $2^m$ 个。对两个取值 $\pm1$ 的函数，$f(x)g(x)$ 在两者相同时为 $+1$、不同时为 $-1$，所以

$$
\langle f,g\rangle=\Pr(f=g)-\Pr(f\ne g)=1-2\Pr(f\ne g),
$$

这就是两者的相关程度：完全一致为 1，完全相反为 $-1$，一半对一半为 0。

**引理 9.7（正交）** $\langle\chi_A,\chi_B\rangle$ 在 $A=B$ 时为 1，否则为 0。

**证明（第一遍可以跳过）.** 因为 $x_j^2=1$，$\chi_A\chi_B=\chi_{A\triangle B}$，$A\triangle B$ 是只属于其中一个集合的元素。若 $A\ne B$，$C=A\triangle B$ 非空，各 $X_j$ 独立且 $\mathbb{E}[X_j]=0$，所以 $\mathbb{E}[\chi_C(X)]=\prod_{j\in C}\mathbb{E}[X_j]=0$。若 $A=B$，乘积恒为 1。$\square$

**定义 9.4（傅里叶系数与次数）** $f$ 在 $A$ 上的**傅里叶系数**是 $\hat f(A)=\langle f,\chi_A\rangle$。$f$ 的**次数**是使 $\hat f(A)\ne0$ 的最大的 $\lvert A\rvert$。

**定理 9.8（傅里叶展开）** 每个 $f:\{-1,1\}^m\to\mathbb{R}$ 都唯一地写成

$$
f=\sum_{A\subseteq\{1,\dots,m\}}\hat f(A)\,\chi_A ,
$$

并且对任意两个函数 $\langle f,g\rangle=\sum_A\hat f(A)\hat g(A)$。特别地，若 $f$ 只取 $\pm1$，则

$$
\sum_A\hat f(A)^2=\mathbb{E}[f(X)^2]=1 .
$$

最后这个等式叫**帕塞瓦尔恒等式**。

**怎么读**：任何布尔函数都是 $2^m$ 个奇偶函数的加权和，权重就是它与每个奇偶函数的相关。帕塞瓦尔恒等式说这些相关的平方和恰好是 1：一个布尔函数有"1 份"总权重，分配在各个变元组上。

#### 证明（第一遍可以跳过）

**思路**：先说明每个函数都能写成奇偶基函数的组合，再用正交性把系数读出来。

1. **能写出来。** 对固定的点 $y$，"$x=y$"的指示函数可以写成 $\mathbf{1}[x=y]=\prod_{j=1}^m\frac{1+x_jy_j}{2}$（每个因子在 $x_j=y_j$ 时为 1，否则为 0）。把乘积展开，每一项是某个 $\chi_A(x)$ 乘一个常数。而 $f(x)=\sum_yf(y)\mathbf{1}[x=y]$，所以 $f$ 是奇偶基函数的线性组合。
2. **系数是唯一的、等于 $\hat f(A)$。** 设 $f=\sum_Ac_A\chi_A$。两边与 $\chi_B$ 取内积，由引理 9.7 右边只剩 $c_B$，所以 $c_B=\langle f,\chi_B\rangle=\hat f(B)$。
3. **内积公式。** 把 $f$、$g$ 的展开代入 $\mathbb{E}[fg]$，交叉项 $\hat f(A)\hat g(B)\langle\chi_A,\chi_B\rangle$ 在 $A\ne B$ 时为 0，剩下 $\sum_A\hat f(A)\hat g(A)$。
4. 取 $g=f$；$f$ 只取 $\pm1$ 时 $f^2=1$。$\square$

### 两个变元的例子

规则甲的"判 S"是 $a\wedge b$。换号后，记 $x_a,x_b\in\{-1,1\}$，直接算四个内积得

$$
\mathrm{AND}(x_a,x_b)=\tfrac12+\tfrac12x_a+\tfrac12x_b-\tfrac12x_ax_b .
$$

**怎么读**：逐行核对。$x_a=x_b=-1$（都成立）：$\frac12-\frac12-\frac12-\frac12=-1$，判 S。$x_a=-1$、$x_b=+1$：$\frac12-\frac12+\frac12+\frac12=1$，不判 S。其余两行同理。四个系数平方和 $4\times\frac14=1$，符合帕塞瓦尔。常数项 $\hat f(\varnothing)=\mathbb{E}[f]=\frac34-\frac14=\frac12$；$\hat f(\{a\})=\frac12$ 表示 $f$ 与 $x_a$ 在 $\frac{1+1/2}{2}=\frac34$ 的输入上一致。

异或则只有一项：$\mathrm{XOR}(x_u,x_v)=x_ux_v$。常数项和两个一次项都是 0，这就是命题 9.6 在傅里叶语言里的样子：**全部权重都在最高次的那一个基函数上**。$m$ 个变元的奇偶函数就是 $\chi_{\{1,\dots,m\}}$ 本身，次数为 $m$，所有低次系数为 0。

### 三个变元的例子

$f_{\mathrm S}=a\wedge(b\vee p)$ 的展开（用 Python 精确计算）是

$$
\begin{aligned}
f_{\mathrm S}={}&\tfrac14+\tfrac34x_a+\tfrac14x_b+\tfrac14x_p\\
&-\tfrac14x_ax_b-\tfrac14x_ax_p+\tfrac14x_bx_p-\tfrac14x_ax_bx_p .
\end{aligned}
$$

**怎么读**：按次数分组，平方和分别是：0 次 $\frac1{16}$，1 次 $\frac9{16}+\frac1{16}+\frac1{16}=\frac{11}{16}$，2 次 $\frac3{16}$，3 次 $\frac1{16}$，合计 1。大部分权重在一次项上，而且集中在 $x_a$：$f_{\mathrm S}$ 与 $x_a$ 在 $\frac{1+3/4}{2}=\frac78$ 的输入上一致（唯一不一致的是"在时限内、不腐烂、不渗出"）。这样的函数，贪心从 $a$ 开始问就对了。

### 浅的树次数低

**命题 9.9** 深度为 $d$ 的决策树计算的函数，次数不超过 $d$。

**证明（第一遍可以跳过）.** 记叶子 $v$ 的结论为 $\ell_v\in\{\pm1\}$，路径上问过的变元集合为 $P_v$（$\lvert P_v\rvert\le d$），要求的取值为 $s_j$。则

$$
f(x)=\sum_v\ell_v\prod_{j\in P_v}\frac{1+s_jx_j}{2}.
$$

每个乘积展开后只含 $\chi_A$，$A\subseteq P_v$，所以 $\lvert A\rvert\le d$。$\square$

由此再看一遍命题 9.4：奇偶函数次数为 $m$，所以任何计算它的树深度都至少是 $m$。

### 小结

这一节说的是：把 0/1 换成 $\pm1$ 后，异或变成乘法；每个布尔函数是 $2^m$ 个奇偶基函数的唯一组合，系数就是它与各基函数的相关，平方和为 1；奇偶函数把全部权重放在一个最高次的基函数上；深度 $d$ 的树次数不超过 $d$。

## 9.6 从相关系数学习：低次算法

### 问题

如果一个函数的傅里叶权重几乎都在低次项上，那么只要估计出少数几个低次系数，就几乎知道了整个函数。而每个系数 $\hat f(A)=\mathbb{E}[f(X)\chi_A(X)]$ 是一个平均值，可以用样本平均来估计。这就是**低次算法**。

**定理 9.10（低次算法；Linial、Mansour、Nisan 1993）** 设 $X$ 在 $\{-1,1\}^m$ 上均匀分布，标签 $Y=f(X)\in\{\pm1\}$。记 $N_d=\sum_{i=0}^d\binom{m}{i}$ 为大小不超过 $d$ 的变元组个数，设

$$
\sum_{\lvert A\rvert>d}\hat f(A)^2\le\varepsilon .
$$

从 $n$ 个独立样本 $(x_i,y_i)$ 计算 $\tilde f(A)=\frac1n\sum_{i=1}^ny_i\chi_A(x_i)$（对所有 $\lvert A\rvert\le d$），令 $g=\sum_{\lvert A\rvert\le d}\tilde f(A)\chi_A$，输出 $h=\operatorname{sgn}(g)$（约定 $\operatorname{sgn}(0)=+1$）。若

$$
n\ge\frac{2N_d\ln(2N_d/\delta)}{\varepsilon},
$$

则以至少 $1-\delta$ 的概率 $\Pr\big(h(X)\ne f(X)\big)\le2\varepsilon$。

**怎么读**：$\varepsilon$ 是"高次项里漏掉的权重"，也是允许的估计误差。代入 $m=20$、$d=2$：$N_2=1+20+190=211$；取 $\varepsilon=\delta=0.05$，$\ln(2\times211/0.05)=\ln8440\approx9.04$，

$$
n\ge\frac{2\times211\times9.04}{0.05}\approx76\,304 .
$$

每个系数估计到 $\pm\sqrt{\varepsilon/N_d}\approx\pm0.0154$ 以内，错误率不超过 0.1。由命题 9.9，深度 2 的树没有高次权重，这时错误率不超过 $\varepsilon=0.05$。这个界很松，但它只要求 $m$ 的多项式（$N_d\le(m+1)^d$）个样本。

#### 证明（第一遍可以跳过）

**思路**：先说明"取符号后的错误率"不超过平方误差，再用定理 9.8 把平方误差拆成"估计误差"和"高次漏掉的权重"，前者用霍夫丁不等式和联合界控制。

1. **逐点比较。** 若 $f(x)\ne\operatorname{sgn}(g(x))$，则 $\lvert f(x)-g(x)\rvert\ge1$：$f=1$ 时 $g<0$；$f=-1$ 时 $g\ge0$。所以 $\mathbf{1}[f\ne\operatorname{sgn}g]\le(f-g)^2$，取期望得 $\Pr(f\ne h)\le\mathbb{E}[(f-g)^2]$。
2. **拆开。** 对 $f-g$ 用定理 9.8，$g$ 在 $\lvert A\rvert\le d$ 上的系数是 $\tilde f(A)$、在更高次上为 0：

$$
\begin{aligned}
\mathbb{E}[(f-g)^2]
&=\sum_{\lvert A\rvert\le d}\big(\hat f(A)-\tilde f(A)\big)^2\\
&\quad+\sum_{\lvert A\rvert>d}\hat f(A)^2 .
\end{aligned}
$$

   第二个和不超过 $\varepsilon$。
3. **一个系数。** $y_i\chi_A(x_i)$ 取值于 $[-1,1]$，期望为 $\mathbb{E}[f(X)\chi_A(X)]=\hat f(A)$。由霍夫丁不等式（定理 2.3，区间长度 2）两侧相加，$\Pr\big(\lvert\tilde f(A)-\hat f(A)\rvert\ge\gamma\big)\le2e^{-n\gamma^2/2}$。
4. **所有系数。** 取 $\gamma^2=\varepsilon/N_d$，由联合界，至少一个系数偏差达到 $\gamma$ 的概率不超过 $2N_de^{-n\varepsilon/(2N_d)}$。当 $n$ 满足定理条件时，它不超过 $\delta$。
5. 其余情形下，第一个和小于 $N_d\gamma^2=\varepsilon$，合计 $\Pr(f\ne h)<2\varepsilon$。$\square$

### 这个算法说明了什么

- **它只用相关系数。** 算法看数据的唯一方式，是计算 $\frac1n\sum y_i\chi_A(x_i)$ 这样的平均值。下一节会看到，这种"只看平均"的方法对低次函数有效，对高次的奇偶函数无效，两件事是一体两面。
- **它依赖均匀分布。** 正交性（引理 9.7）要求各个事实独立、各取一半。真实业务数据里事实既不均衡也不独立，这时系数不再是简单的相关，定理不直接适用。
- **树和电路。** $s$ 个叶子的树，把深度超过 $D=\log_2(s/\varepsilon)$ 的部分剪掉，每个被剪的叶子在均匀分布下只有 $2^{-D}$ 的概率被走到，总共改变不超过 $s2^{-D}=\varepsilon$ 的输入；由此可以推出它在高于 $D$ 次的权重不超过 $4\varepsilon$，低次算法用 $m^{O(\log(s/\varepsilon))}$ 个样本学会它，这比多项式多，叫**拟多项式**。Linial、Mansour 与 Nisan 对常数深度的电路证明了类似的低次集中性。如果允许学习者自己挑输入去问标签（**成员查询**），Kushilevitz 与 Mansour（1993）能在多项式时间内找出所有大系数，从而学会多项式大小的决策树；Jackson（1997）把这条路推进到了多项式大小的 DNF。

### 小结

这一节说的是：傅里叶权重集中在低次的函数，只要估计 $N_d=\sum_{i\le d}\binom mi$ 个相关系数再取符号就能学会；错误率不超过估计误差加上漏掉的高次权重；它依赖均匀分布，而且只用平均值。

## 9.7 统计查询：只看平均值的方法学不了奇偶函数

### 问题：难的是数据还是方法

9.4 节说贪心拆分看不到奇偶函数。是信息不够吗？不是。$m$ 个变元上的奇偶函数一共 $2^m$ 个，$\ln2^m=m\ln2$；由定理 2.9，可实现情形下 $O(m/\varepsilon)$ 个样本就够。而且有高效算法：每个无噪声样本给出一个模 2 的线性方程，用高斯消元解出 $A$。所以难的不是信息，而是**用数据的方式**。下面的模型把"只用平均值"这种用法精确地说出来。

### 统计查询模型

**定义 9.5（统计查询学习；Kearns 1998）** 学习者看不到单个样本，只能向一个**统计查询预言机**提问。每次提问给出一个函数 $q:\mathcal{X}\times\{-1,1\}\to[-1,1]$ 和**容差** $\tau>0$；预言机返回 $[\,\mathbb{E}[q(X,f(X))]-\tau,\ \mathbb{E}[q(X,f(X))]+\tau\,]$ 中的**任意**一个数，可以是最不利于学习者的那个。只用这种提问的学习算法叫**统计查询算法**。

**怎么读**：这里的查询就是第 5 章定义 5.1 的统计查询，只是取值范围从 $[0,1]$ 换成了 $[-1,1]$（线性变换，不影响任何结论）。预言机可以用样本模拟：每个查询用一批新的样本，样本量取 $2\ln(2k/\delta)/\tau^2$，由霍夫丁不等式和联合界，$k$ 个回答以至少 $1-\delta$ 的概率都在容差以内。代入 $\tau=0.01$、$k=100$、$\delta=0.05$：每个查询约需 $2\ln4000/10^{-4}\approx16.6$ 万个样本。

很多常用算法都是统计查询算法：

- 估计一条规则的错误率：$q(x,y)=\mathbf{1}[h(x)\ne y]$。
- 9.6 节的低次算法：对每个 $\lvert A\rvert\le d$ 问 $q_A(x,y)=y\chi_A(x)$，容差 $\sqrt{\varepsilon/N_d}$。
- **基于不纯度的贪心建树**：在路径条件为 $\pi$ 的结点上，比较各个谓词只需要概率 $\Pr(\pi(X)=1,X_j=v,Y=k)$，每个都是查询 $q(x,y)=\mathbf{1}[\pi(x)=1,x_j=v,y=k]$ 的答案；熵、基尼、加权代价都是这些概率的连续函数。

Kearns 证明了统计查询算法自动能容忍随机的标签噪声，这是这个模型的初衷。他也证明了奇偶函数不能被高效地统计查询学习。下面给出这个结论一个简化版本的完整证明。

**定理 9.11（统计查询下界，简化版）** 设 $P$ 是 $\mathcal{X}$ 上的分布，$f_1,\dots,f_D:\mathcal{X}\to\{\pm1\}$ 在 $P$ 下两两不相关：$i\ne j$ 时 $\mathbb{E}[f_i(X)f_j(X)]=0$。设一个确定性的统计查询算法只用容差为 $\tau$ 的 $k$ 次查询，并且无论目标是哪一个 $f_i$，它输出的 $h$ 都满足 $\Pr(h(X)\ne f_i(X))<1/4$。则

$$
k>\tau^2(D-2).
$$

**怎么读**：两两不相关的候选越多（$D$ 越大），要么查询次数 $k$ 要很多，要么容差 $\tau$ 要很小（$1/\tau^2$ 是模拟一次查询所需样本数的量级）。代入均匀分布下的全部奇偶函数：由引理 9.7，$D=2^m$。取 $\tau=0.01$、$m=50$，$k>10^{-4}\times(2^{50}-2)\approx1.1\times10^{11}$。只要 $k$ 是 $m$ 的多项式、$1/\tau$ 也是 $m$ 的多项式，$m$ 稍大时就不可能满足。

#### 证明（第一遍可以跳过）

**思路**：让预言机对每个查询都回答"标签是纯噪声时的那个值"。一次查询最多能"揭穿"不到 $1/\tau^2$ 个候选；查询次数不够时，至少剩下两个没被揭穿的候选，算法分不清它们，而它们相差太远，同一个 $h$ 不可能对两个都好。

1. **拆查询。** 对 $y\in\{\pm1\}$，$q(x,y)=q_0(x)+y\,q_1(x)$，其中 $q_0(x)=\frac{q(x,1)+q(x,-1)}2$，$q_1(x)=\frac{q(x,1)-q(x,-1)}2\in[-1,1]$（代入 $y=1$ 和 $y=-1$ 即可验证）。
2. **目标为 $f_i$ 时的真值。** $\mathbb{E}[q(X,f_i(X))]=\mathbb{E}[q_0(X)]+\mathbb{E}[q_1(X)f_i(X)]$。第一项与 $i$ 无关，记为 $c_0$；第二项记为 $c_i$。
3. **一次查询揭穿的候选不多。** 先证 $\sum_ic_i^2\le\mathbb{E}[q_1^2]$（贝塞尔不等式）：

$$
\begin{aligned}
0&\le\mathbb{E}\Big[\big(q_1-\textstyle\sum_ic_if_i\big)^2\Big]\\
&=\mathbb{E}[q_1^2]-2\sum_ic_i^2+\sum_ic_i^2 ,
\end{aligned}
$$

   这里用了 $\mathbb{E}[f_i^2]=1$ 和两两不相关。又 $\mathbb{E}[q_1^2]\le1$，所以满足 $\lvert c_i\rvert>\tau$ 的 $i$ 少于 $1/\tau^2$ 个。
4. **预言机的策略。** 每次都回答 $c_0$。对满足 $\lvert c_i\rvert\le\tau$ 的目标 $f_i$，这个回答在容差以内，是合法的。算法是确定性的，回答又与目标无关，所以无论目标是谁，它问的都是同一串查询，最后输出同一个 $h$（自适应提问在这里不起作用）。
5. **数一数。** $k$ 次查询一共揭穿少于 $k/\tau^2$ 个候选。若 $k\le\tau^2(D-2)$，被揭穿的少于 $D-2$ 个，至少剩下两个 $f_i$、$f_j$，所有回答对它们都合法，算法对两者输出同一个 $h$。
6. **矛盾。** $f_i$、$f_j$ 不相关，即在恰好一半的输入上不同。但 $\Pr(f_i\ne f_j)\le\Pr(h\ne f_i)+\Pr(h\ne f_j)<\frac14+\frac14=\frac12$，矛盾。$\square$

### 从奇偶函数到树和 DNF

只看 $r$ 个变元的奇偶函数，可以用深度 $r$、$2^r$ 个叶子的树计算，在均匀分布下两两不相关，共 $\binom{m}{r}$ 个。取 $r=\log_2m$，树只有 $m$ 个叶子（多项式大小），候选数却超过任何多项式。代入 $m=256$、$r=8$：$D=\binom{256}{8}\approx4.1\times10^{14}$，$\tau=0.01$ 时 $k>4.1\times10^{10}$。所以**多项式大小的决策树在均匀分布下不能被高效地统计查询学习**；$r$ 个变元的奇偶函数也是 $2^{r-1}$ 项的 DNF，DNF 同样如此。

Blum、Furst、Jackson、Kearns、Mansour 与 Rudich（1994）把"类中两两（近似）不相关的函数最多有多少个"定义为**统计查询维数**，证明它在多项式意义下刻画了弱学习（只要求比瞎猜好一点）所需的查询数与容差，上面的论证是其中最简单的一半。同一篇论文还证明，$s$ 项的 DNF 总与某个奇偶基函数有不小于 $1/(2s+1)$ 的相关，所以借助成员查询可以弱学习 DNF；这正是 Jackson 后来强学习 DNF 的起点。

### 这对贪心拆分意味着什么

基于不纯度的贪心建树是统计查询算法，所以定理 9.11 覆盖了它，而且覆盖的不只是"某一种不纯度"或"某一种停止规则"：**任何只消费结点计数的方法**，无论怎样组合这些计数，面对 $r$ 个事实的奇偶结构，查询次数乘以 $1/\tau^2$ 都要达到 $\binom mr$ 的量级，和直接枚举全部 $r$ 元组差不多。

高斯消元不受这个下界约束，因为它依赖单个样本的精确取值。但只要标签有一点随机噪声，它就失效了。带噪声的奇偶学习（learning parity with noise）目前最好的算法也要 $2^{O(m/\log m)}$ 的时间（Blum、Kalai、Wasserman 2003），一般认为它是困难的，一些密码方案就建立在这个假设上。业务标签总有噪声，所以实际的结论是：**结论若是若干事实的奇偶，从这些事实出发几乎学不出来，要换事实**，像 9.4 节那样直接测量组合后的那个事实。

### 小结

这一节说的是：统计查询算法只能问带误差的平均值；对 $D$ 个两两不相关的候选，$k$ 次容差为 $\tau$ 的查询在 $k\le\tau^2(D-2)$ 时无法把误差压到 1/4 以下；奇偶函数、多项式大小的树和 DNF 都包含指数或超多项式多个这样的候选；基于不纯度的贪心是统计查询算法，所以它的失败不是某个启发式的毛病。

## 9.8 线性阈值函数与评分卡

### 问题

很多行业的人工规则是"打分制"：每条证据记几分，总分过线就判。这种写法能表达什么？

**定义 9.6（线性阈值函数）** 给定实数权重 $w_1,\dots,w_m$ 和门槛 $\theta$，

$$
f(x)=\mathbf{1}\Big[\sum_{j=1}^mw_jx_j\ge\theta\Big],\qquad x\in\{0,1\}^m
$$

叫**线性阈值函数**。权重和门槛都是小整数时，它叫**评分卡**。

**怎么读**：$w_j$ 是第 $j$ 个事实的分值，$\theta$ 是及格线。代入 9.1 节：$w_a=2$、$w_b=w_p=1$、$\theta=3$。案例 6 的 $(a,b,p)=(1,0,1)$，总分 3，判 S；案例 4 的 $(1,0,0)$，总分 2，不判 S。

合取（$\sum x_j\ge m$）、析取（$\sum x_j\ge1$）、多数（$\sum x_j\ge\lceil m/2\rceil$）、"至少 $t$ 条成立"都是线性阈值函数。

**命题 9.12（异或不是线性阈值函数）** $u\oplus v$ 不是线性阈值函数；更一般地，$r\ge2$ 个变元的奇偶函数都不是。

#### 证明（第一遍可以跳过）

**思路**：把四个输入的不等式加起来，自相矛盾。

1. 设 $\mathbf{1}[w_1u+w_2v\ge\theta]=u\oplus v$。由 $(0,0)\mapsto0$ 得 $0<\theta$；由 $(1,0)\mapsto1$ 和 $(0,1)\mapsto1$ 得 $w_1\ge\theta$、$w_2\ge\theta$；由 $(1,1)\mapsto0$ 得 $w_1+w_2<\theta$。
2. 前三条给出 $w_1+w_2\ge2\theta>\theta$，与第四条矛盾。
3. 一般情形：把奇偶函数里除两个变元以外的变元都固定为 0，得到这两个变元的异或；把线性阈值函数里的同样变元固定为 0，得到的仍是线性阈值函数（门槛不变，少了几项）。若奇偶函数是线性阈值函数，异或也是，矛盾。$\square$

这是 Minsky 与 Papert（1969）对单层感知机的著名批评的核心。但"线性"是相对于特征而言的：加入乘积特征 $uv$ 后，$u+v-2uv\ge1$ 恰好是异或（$(1,1)$ 时为 0，$(1,0)$、$(0,1)$ 时为 1，$(0,0)$ 时为 0）。

**命题 9.13** 每个 1-决策列表都是线性阈值函数。

#### 证明（第一遍可以跳过）

**思路**：给越靠前的规则越大的权重，让第一个触发的规则压倒后面所有规则之和。

1. 设列表为 $(\ell_1\to c_1),\dots,(\ell_L\to c_L),(1\to c_{L+1})$，每个 $\ell_i$ 是一个文字，$c_i\in\{0,1\}$。记 $s_i=+1$（若 $c_i=1$）或 $-1$（若 $c_i=0$）。文字是线性的：$x_j$ 本身，或 $\neg x_j=1-x_j$。
2. 令 $F(x)=\sum_{i=1}^Ls_i2^{L+1-i}\ell_i(x)+s_{L+1}$，它是 $x$ 的线性函数加常数。
3. 若第一个触发的是第 $i$ 条，它贡献 $\pm2^{L+1-i}$；后面各项绝对值之和不超过 $2^{L-i}+\dots+2+1=2^{L+1-i}-1$，所以 $F$ 的符号就是 $s_i$。若都不触发，$F=s_{L+1}$。
4. $F$ 是奇数，不会为 0，所以列表的输出等于 $\mathbf{1}[F(x)\ge1]$，这是线性阈值函数。$\square$

**代入规则甲**："判 S"的列表是 $(\neg a\to0),(b\to1),(1\to0)$，$F=-4(1-a)+2b-1=4a+2b-5$，即 $\mathbf{1}[4a+2b\ge6]$：只有 $a=b=1$ 时判 S。

这个构造的权重按 2 的幂增长。同一个函数，写成决策列表一目了然，写成评分卡却要用越来越大的分值。一般而言，有的线性阈值函数必须用指数大小的整数权重才能写出（Håstad 1994）。**评分卡好读，前提是分值小**；这时它能写出的函数比全部线性阈值函数少得多。

评分卡的可解释性来自三处：每个事实的贡献可以单独看见；结论对每个事实的方向固定（$w_j\ge0$ 时，事实 $j$ 只会把结论推向判 1，这正是下一节的单调性）；可以手算。它的盲点也很清楚：写不出事实之间的交互，除非事先把交互作为一个新事实加进来。Ustun 与 Rudin 用整数规划直接学习最优的小整数评分卡（SLIM，2016；RiskSLIM，2019）。从样本复杂度看，$m$ 个输入上的线性阈值函数 VC 维是 $m+1$（半空间的标准结论）。

### 小结

这一节说的是：线性阈值函数把事实的分值加起来与门槛比较，评分卡是小整数版本；它写不出异或和奇偶，但加入交互特征后可以；1-决策列表都是线性阈值函数，代价是权重指数增长，所以"好读的评分卡"是一个更小的类。

## 9.9 单调函数

### 问题

审核人员对规则有一个朴素的期望："多出一条对卖家不利的证据，不应该让结论从'卖家责任'变成'不是卖家责任'。"异或规则违反了这个期望：在 9.4 节的场景里，"腐烂发生在运输途中"在 $u=0$ 时推向 S，在 $u=1$ 时推向 B。这种方向一致性有一个名字。

**定义 9.7（单调函数）** 对 $x,y\in\{0,1\}^m$，若每个分量都有 $x_j\le y_j$，记 $x\le y$。若 $x\le y$ 总蕴含 $f(x)\le f(y)$，就称 $f$ 是**单调**的。

**怎么读**：把任何一个事实从 0 改成 1，输出不会从 1 掉到 0。$f_{\mathrm S}=a\wedge(b\vee p)$ 单调；异或不单调：$(0,1)\le(1,1)$，输出却从 1 变成 0。如果业务上某个事实的方向是"反"的（例如"超时"只会推离 S），先把它取反再要求单调，这叫**单侧**（unate）约束。

**命题 9.14** $f$ 单调，当且仅当它有一个不含否定文字的析取范式。

#### 证明（第一遍可以跳过）

1. **不含否定 ⇒ 单调。** 若 $x\le y$ 且某一项在 $x$ 上为真，这一项的变元在 $x$ 上都是 1，在 $y$ 上也都是 1，所以它在 $y$ 上也为真。
2. **单调 ⇒ 不含否定。** 对每个 $f(y)=1$ 的 $y$，令 $t_y$ 为 $y$ 中取 1 的变元的合取（$y$ 全为 0 时是空项，恒为真）。令 $G=\bigvee_{f(y)=1}t_y$。若 $f(x)=1$，$t_x(x)=1$，所以 $G(x)=1$。若 $G(x)=1$，某个 $t_y(x)=1$，即 $y\le x$，由单调性 $f(x)\ge f(y)=1$。所以 $G=f$。$\square$

### 单调为什么帮助解释

- **方向可以逐个审核。** 每个事实只需一句话："腐烂只会把结论推向卖家责任。"不需要看它和别的事实怎样组合。
- **反事实解释简单。** 要把"判 S"翻成"不判 S"，只需把某些 1 改成 0；最小的改法对应最小的项。
- **读错的后果有方向。** 语言模型漏读一个事实（把 1 读成 0），结论只会朝一个已知方向偏；这与 0.7 节强 Kleene 逻辑的单调性（命题 0.7.7）是同一个道理。
- **假设空间小得多。** $m$ 个变元上的单调函数个数（Dedekind 数）在 $m=4$ 时是 168，全部函数是 65 536；$m=5$ 时是 7581，全部函数是 $2^{32}\approx4.3\times10^9$（都用 Python 穷举核对过；$m=5$ 用的是"5 元单调函数一一对应于满足 $f_0\le f_1$ 的一对 4 元单调函数"这一递推）。$\ln168\approx5.1$，$\ln65536\approx11.1$。

### 单调函数对贪心"总有信号"

奇偶函数让每个单独的事实都没有信息。单调函数正好相反。

**命题 9.15** 设 $X$ 在 $\{0,1\}^m$ 上均匀分布，$f$ 单调。对每个 $i$，

$$
\Pr\big(f(X)=1\mid X_i=1\big)-\Pr\big(f(X)=1\mid X_i=0\big)=\mathrm{Inf}_i(f)\ge0,
$$

其中**影响力** $\mathrm{Inf}_i(f)$ 是"随机取其余变元，把 $x_i$ 从 0 改成 1 会改变 $f$"的概率。若 $f$ 不是常函数，则存在某个 $i$ 使 $\mathrm{Inf}_i(f)\ge2^{-(m-1)}>0$，这时 $X_i$ 在根结点上的信息增益为正。

**怎么读**：单调函数里，每个事实成立时判 1 的比例都不低于不成立时，高出的部分正是这个事实"起决定作用"的概率。代入 $f_{\mathrm S}$：$\mathrm{Inf}_a=\Pr(b\vee p)=3/4$，$\mathrm{Inf}_b=\mathrm{Inf}_p=1/4$，恰好等于 9.5 节的一次系数 $\hat f_{\mathrm S}(\{a\})$、$\hat f_{\mathrm S}(\{b\})$、$\hat f_{\mathrm S}(\{p\})$（在那里的换号约定下，单调函数的一次系数就是影响力）。三元多数函数每个变元的影响力是 $1/2$。

#### 证明（第一遍可以跳过）

1. 记 $x^{i\leftarrow1}$、$x^{i\leftarrow0}$ 为把第 $i$ 位设成 1、0 的输入。$X_i$ 与其余变元独立，所以 $\Pr(f=1\mid X_i=1)=\mathbb{E}[f(X^{i\leftarrow1})]$，另一个同理，二者之差是 $\mathbb{E}[f(X^{i\leftarrow1})-f(X^{i\leftarrow0})]$。
2. 由单调性，这个差在每个输入上是 0 或 1，等于 1 恰好是"改动 $x_i$ 改变了 $f$"，所以期望就是 $\mathrm{Inf}_i(f)$。
3. $f$ 不是常函数，则有 $f(x)=0$、$f(y)=1$。令 $z$ 为 $x$、$y$ 的逐位最大值，由单调性 $f(z)\ge f(y)=1$。从 $x$ 出发，把 $z$ 中多出来的 1 一位一位加上去，$f$ 从 0 走到 1，某一步改动第 $i$ 位时 $f$ 变了。这一步的"其余变元"取值至少占其余变元全部取值的 $2^{-(m-1)}$，所以 $\mathrm{Inf}_i(f)\ge2^{-(m-1)}$。
4. 这时两个条件概率不同，$X_i$ 与 $f(X)$ 不独立，由命题 0.4.5 互信息为正。$\square$

信号存在不等于信号强：$m$ 个变元的合取，每个变元的影响力只有 $2^{-(m-1)}$，$m=10$ 时约 0.002，有限样本下仍可能被噪声淹没。单调性也不能保证贪心找到最优的树。

### 相关免疫函数

与单调函数相对的极端是**相关免疫**。若在均匀分布下 $f(X)$ 与任何不超过 $k$ 个输入变元的组合都独立，称 $f$ 是 **$k$ 阶相关免疫**的（Siegenthaler 1984）。Xiao 与 Massey（1988）证明，这等价于所有满足 $1\le\lvert A\rvert\le k$ 的傅里叶系数 $\hat f(A)$ 都为 0。$m$ 个变元的奇偶函数是 $m-1$ 阶相关免疫的（命题 9.6）；由命题 9.15，非常数的单调函数连 1 阶都不是。密码学里设计流密码的组合函数时，专门要求相关免疫，好让攻击者无法通过"某几个输入与输出的相关"破解；Siegenthaler 还证明了相关免疫阶数越高，函数的代数次数上限越低。对规则学习来说，这是同一枚硬币的另一面：**$k$ 阶相关免疫的结论，任何前瞻少于 $k+1$ 步的贪心都看不见。**

### 小结

这一节说的是：单调函数就是不含否定的析取范式，它让每个事实的方向可以单独审核、漏读的后果有方向、假设空间小得多；均匀分布下单调非常数函数总有一个事实的信息增益为正，正好与奇偶函数相反；相关免疫函数是"对少数输入不可见"的极端。

## 9.10 从 PAC 的角度看：这些类要多少样本

### 问题

第 2 章给出了"假设空间多大，就要多少样本"的定量关系。把它用到本章的几类写法上，就能把"表达力的代价"算出来。

记 $C_k$ 为 $m$ 个变元上不超过 $k$ 个文字的项（含空项）的全体，其个数为

$$
N_k=\sum_{i=0}^k\binom{m}{i}2^i .
$$

**怎么读**：选 $i$ 个变元，每个取正文字或负文字。代入 $m=10$：$N_1=1+20=21$，$N_2=21+45\times4=201$。

**命题 9.16（假设空间的大小与 VC 维）**

1. $\lvert k\text{-DNF}\rvert\le2^{N_k}$；当 $m\ge k$ 时，$\mathrm{VC}(k\text{-DNF})\ge\binom mk$。
2. $\lvert k\text{-DL}\rvert\le3^{N_k}\,N_k!$（Rivest 1987）。
3. 结论为 0/1、深度不超过 $d$ 的决策树最多写出 $m^{2^d-1}2^{2^d}$ 个函数；当 $m\ge d$ 时，它们的 VC 维至少是 $2^d$。

#### 证明（第一遍可以跳过）

1. 一个 $k$-DNF 由它用到的项的集合决定，最多 $2^{N_k}$ 种。VC 下界：取 $\binom mk$ 个恰好有 $k$ 个 1 的输入。对每个这样的输入 $x$，令 $t_x$ 为它取 1 的那 $k$ 个变元的合取；在这组输入中，$t_x$ 只在 $x$ 自己上为真（另一个输入若满足 $t_x$，它的 $k$ 个 1 就恰好是这 $k$ 个变元）。对任何想要的标注，把"要标 1 的那些输入"的 $t_x$ 析取起来即可，所以这组输入被打散。
2. 决策列表里重复出现的项，后一次永远不会触发，可以删掉；"否则"就是空项，排在最后。于是一个列表由"每个项不出现、出现并判 0、出现并判 1"（3 种）加上出现的项的顺序决定，顺序最多 $N_k!$ 种。
3. 深度恰为 $d$ 的满二叉树有 $2^d-1$ 个内部结点（各选一个谓词）和 $2^d$ 个叶子（各选 0 或 1）；更浅的树可以看成兄弟叶子结论相同的满树（第 1 章 1.4.3 节的说法）。VC 下界：在前 $d$ 个变元上取遍 $2^d$ 种组合，问满这 $d$ 个变元的满树可以给每个组合任意结论。$\square$

### 代入数字

取 $m=10$、$\delta=0.05$（$\ln20\approx3.0$）、$\varepsilon=0.1$，用定理 2.9 的可实现情形样本量 $n\ge(\ln\lvert\mathcal{H}\rvert+\ln(1/\delta))/\varepsilon$：

- 深度 2 的树：$\ln\lvert\mathcal{H}\rvert\le3\ln10+4\ln2\approx9.7$，$n\ge127$；深度 3：约 21.7，$n\ge247$。
- 1-决策列表：$\ln(3^{21}\cdot21!)\approx68.5$，$n\ge715$。
- 2-DNF：$201\ln2\approx139.3$，$n\ge1424$。
- 2-决策列表：$\ln(3^{201}\cdot201!)\approx1089$，$n\ge10\,924$。

2-决策列表的计数很松（$201!$ 把大量等价的顺序都算了进去），但 $m^k$ 这个量级是真实的：它包含 2-DNF，而 2-DNF 的 VC 维至少 $\binom{10}2=45$，由第 2 章定理 2.19 的下界，可实现情形至少需要与 $(45+\ln(1/\delta))/\varepsilon$ 成比例的样本。

### Rivest 的算法

数清楚假设空间只解决了"样本够不够"。还要有算法在样本上找到一条一致的规则。

**定理 9.17（Rivest 1987）** 下面的算法在任何"与某个 $k$-决策列表一致"的样本上都会成功停止，输出一个与样本完全一致的 $k$-决策列表；它最多进行 $n$ 轮，每轮检查 $N_k$ 个项。

> 1. 令 $S'$ 为全部案例，列表为空。
> 2. 只要 $S'$ 中两种标签都有：找一个项 $t\in C_k$，使它在 $S'$ 中覆盖至少一个案例，并且覆盖的案例标签都相同（记为 $c$）；把 $(t\to c)$ 加到列表末尾，从 $S'$ 中删掉 $t$ 覆盖的案例。
> 3. $S'$ 中只剩一种标签 $c$（或为空，$c$ 任取）时，加上 $(1\to c)$，停止。

结合定理 2.9：对固定的 $k$，$k$-决策列表在可实现情形下可以高效地 PAC 学习；由 9.2 节的包含链，深度 $k$ 的树、$k$-DNF、$k$-CNF 也都可以，只是输出的是决策列表，不一定是原来的写法。

#### 证明（第一遍可以跳过）

**思路**：目标列表里"第一个还能覆盖剩余案例的规则"，就是算法下一步可以用的项。

1. **不会卡住。** 设样本与 $k$-决策列表 $c^*$ 一致。在任何一轮，$S'$ 中仍有两种标签时，在 $c^*$ 的规则里找出第一个覆盖 $S'$ 中至少一个案例的规则 $(t^*\to c)$。它前面的规则都不覆盖 $S'$ 中的任何案例，所以 $S'$ 中被 $t^*$ 覆盖的案例，在 $c^*$ 里都由这一条判定，标签都是 $c$（样本与 $c^*$ 一致）。于是 $t^*$ 满足第 2 步的要求，算法总能找到一个项。（$t^*$ 不会是最后的"否则"：否则 $S'$ 全部由它判定，只有一种标签。）
2. **会停下。** 每轮至少删掉一个案例，最多 $n$ 轮。
3. **输出一致。** 一个在第 $j$ 轮被删掉的案例，前面各轮的项都不覆盖它（否则早被删了），所以列表在它上面由第 $j$ 条判定，结论等于它的标签。最后剩下的案例前面的项都不覆盖，由"否则"判定，标签也都是 $c$。$\square$

**在 9.4 节的异或案例上跑一遍。** $k=1$ 时：$u$、$\neg u$、$v$、$\neg v$、空项覆盖的案例标签都是混合的，算法卡住。这不是算法的错，是命题 9.4 第 3 条：异或不是 1-决策列表，样本与任何 1-决策列表都不一致。$k=2$ 时，一种可能的运行是：$\neg u\wedge\neg v$ 覆盖案例 9、10，都是 B，加入 $(\neg u\wedge\neg v\to0)$；$\neg u\wedge v$ 覆盖 11、12，加入 $(\neg u\wedge v\to1)$；$u\wedge\neg v$ 覆盖 13、14，加入 $(u\wedge\neg v\to1)$；剩下 15、16 都是 B，加入 $(1\to0)$。

### 两点提醒

- **一致性是硬要求。** 第 1 章的 8 个案例里，案例 1–3 事实相同、结论不同（碰撞），任何只看这些事实的规则都不一致，算法会卡住（练习 9.7）。标签有噪声时，找"错误最少的 $k$-决策列表"在计算上一般是困难的，后面讲规则学习时会回到这个问题。
- **恰当与非恰当学习。** 要求输出的规则与目标属于同一写法，叫**恰当学习**。Pitt 与 Valiant（1988）证明，对 $k\ge2$，用 $k$ 项 DNF 去学 $k$ 项 DNF 是 NP 难的（除非 $\mathrm{RP}=\mathrm{NP}$）；但 $k$ 项 DNF 可以展开成 $k$-CNF，用消去法高效地学出来。**换一种更大的写法输出，问题可能从难变易**；对可解释系统，这意味着"好学"和"输出的形式好读"可能需要取舍。

### 小结

这一节说的是：$k$-DNF 和 $k$-决策列表的 $\ln\lvert\mathcal{H}\rvert$ 是 $m^k$ 量级，深度 $d$ 的树是 $2^d\ln m$ 量级，代入定理 2.9 得到具体样本量；Rivest 的算法每步找一个"覆盖的剩余案例标签纯"的项，在一致的样本上总能成功；它要求样本一致，而且输出不一定是目标的原始写法。

## 9.11 表达能力对可解释系统意味着什么

### 三个维度

一种写法的"表达能力"不是一个数，而是三个相互牵制的维度：

1. **能短写出哪些函数。** 真值表能写出一切，但一律 $2^m$ 行；决策树短写"先分情况再判"的函数，却要重复抄写 $g_k$ 的子结构；决策列表短写"按优先级的例外"；评分卡短写"证据累加"；所有这些写法都写不短奇偶函数。
2. **要多少样本。** 由命题 9.16，表达力的增加直接变成 $\ln\lvert\mathcal{H}\rvert$ 的增加；$m=10$ 时，从深度 2 的树到 2-决策列表，可实现情形的样本量从一百多涨到一万多。
3. **人读起来要花多少力气。** 大小只是一部分。决策列表的第 $i$ 条只有在"前面都不成立"时才有意义，读后面的规则要记住前面的；析取范式的每一项可以单独读，没有顺序；树的每条路径自成一体，但同一个概念可能散在多条路径里；评分卡可以手算，但看不出交互。

把本章的几种写法对照一下（$m=10$ 时的 $\ln\lvert\mathcal{H}\rvert$ 取 9.10 节的上界）：

| 写法 | 短写的典型函数 | 写不短的函数 | $\ln\lvert\mathcal{H}\rvert$（$m=10$） | 读法 |
|---|---|---|---|---|
| 真值表 | 无 | 全部，一律 $2^m$ 行 | $2^{10}\ln2\approx710$ | 逐行查 |
| 深度 2 的树 | 两层分情况 | $g_k$、奇偶 | 约 9.7 | 沿路径读 |
| 2-DNF | 若干条两条件证据 | 奇偶 | 约 139 | 每项独立读 |
| 2-决策列表 | 带优先级的例外 | 奇偶（$m>2$ 时） | 不超过约 1089 | 按顺序读 |
| 评分卡 | 证据累加、至少 $t$ 条 | 异或、奇偶 | VC 维 $m+1=11$ | 手算总分 |
| 单调 DNF | 方向一致的证据 | 任何方向会翻转的规则 | 比全部函数小得多 | 每个事实一句方向 |

### 表达能力是相对于事实的

9.4 节的异或在 $(u,v)$ 上难倒了本章的每一种写法和每一种统计查询方法，在 $w$（货在谁手里）上却是一个单谓词规则。**复杂度可以从规则搬到事实上。** 在"语言模型读事实、规则做判定"的系统里，这是最便宜的增加表达力的方式：问对一个问题，往往胜过把树加深两层。

但这个搬运不是免费的。第一，组合出来的事实本身是更复杂的测量，读错的概率可能更高，也更难核对；第二，如果新事实是看着训练标签想出来的，第 2 章 2.10 节的问题就出现了，假设空间实际上变大了。后面讲特征构造的那一章会专门讨论这两点。

### 一点实用的判断

把第 1 章的碰撞下界和本章的结论放在一起，可以诊断"规则学不好"的原因：

- 碰撞下界高：事实不够，换什么写法都没用（表示误差）。
- 碰撞下界接近 0，但贪心的树很差：可能是异或或奇偶这样的交互结构（命题 9.6），优化误差大；可以试前瞻、精确搜索，或者更好的办法，直接问交互事实。
- 精确搜索在小写法里也做不好，而大写法在留出数据上表现好：近似误差大，需要更有表达力的写法，样本量要按命题 9.16 重新估计。

### 小结

这一节说的是：表达能力有三个维度，即能短写什么、要多少样本、读起来多费力，三者互相牵制；表达能力是相对于事实的，把复杂度搬到一个问对了的事实上往往最划算，但要付测量和选择偏差的代价。

## 9.13 本章小结

- 函数与写法要分开；大小是能写出函数的最短对象的长度（定义 9.1）。
- 树到范式、树到决策列表都便宜（命题 9.1、9.2）；深度 $k$ 的树 $\subseteq$ $k$-DNF $\cap$ $k$-CNF，$k$-DNF $\cup$ $k$-CNF $\subseteq$ $k$-DL（命题 9.3）。
- 奇偶函数在范式、树、$k<m$ 的决策列表里都需要指数大小（命题 9.4）；$g_k$ 是 $m/2$ 项的 2-DNF，决策树却至少要 $2^{m/2}$ 个叶子（命题 9.5）。
- 均匀分布下，奇偶结论与任何不完整的事实组合独立，增益为 0（命题 9.6）。
- 换成 $\pm1$ 后，每个函数是奇偶基函数的唯一组合，系数平方和为 1（引理 9.7、定理 9.8）；深度 $d$ 的树次数不超过 $d$（命题 9.9）；低次函数可以靠估计相关系数学会（定理 9.10）。
- 统计查询算法面对 $D$ 个两两不相关的候选，需要 $k>\tau^2(D-2)$（定理 9.11）；奇偶函数、多项式大小的树和 DNF 都因此不能被高效地统计查询学习，基于不纯度的贪心在其中。
- 异或不是线性阈值函数（命题 9.12）；1-决策列表都是线性阈值函数，但权重指数增长（命题 9.13）。
- 单调等于不含否定的析取范式（命题 9.14）；单调非常数函数总有一个事实有正的信息增益（命题 9.15）；相关免疫函数对少数输入不可见。
- $k$-DNF、$k$-DL 的 $\ln\lvert\mathcal{H}\rvert$ 是 $m^k$ 量级，深度 $d$ 的树是 $2^d\ln m$ 量级（命题 9.16）；Rivest 的算法在一致的样本上总能找到一致的 $k$-决策列表（定理 9.17）。

**练习 9.4** ★★ 用 9.5 节的换号约定，求两个变元的析取 $a\vee b$ 的傅里叶展开，验证帕塞瓦尔恒等式，并算出它与 $x_a$ 在多大比例的输入上一致。

**练习 9.5** ★★ 证明：深度为 $d$ 的决策树计算的函数，每个傅里叶系数都是 $2^{-d}$ 的整数倍。（提示：沿用命题 9.9 的证明。）

**练习 9.6** ★★ 三元多数函数 $\mathrm{MAJ}_3$ 是不是线性阈值函数？是不是单调的？求每个变元的影响力，并说明均匀分布下贪心建树在根结点会怎样选。它的傅里叶展开是什么？

**练习 9.7** ★★ 把第 1 章的 8 个案例的标签改成"是否 S"（1 表示 S），在事实 $(a,b)$ 上运行 Rivest 的算法（$k=1$）。在哪一步卡住？加上事实 $p$ 后再运行一次。卡住的原因与第 1 章的哪个命题有关？

**练习 9.8** ★★ 9.6 节 $m=20$、$d=2$、$\varepsilon=0.05$ 的低次算法可以看成一个统计查询算法。它用了多少次查询、容差多少？把这两个数代入定理 9.11 的不等式（$D$ 取次数不超过 2 的奇偶基函数个数），说明两者为什么不矛盾。

**练习 9.9** ★★★ 为生鲜售后设计一张带单调约束的评分卡（至少 5 个事实），说明每个事实的方向和分值的理由。9.4 节的"自提"与"运输途中腐烂"应该怎样处理，才能既保留单调性、又不丢掉政策？

**练习 9.10** ★★★ 一个团队发现：在某类案例上碰撞下界接近 0，但贪心树的错误率很高。他们有两个选择：（甲）允许深度 4 的树并用精确搜索；（乙）让语言模型多读一个"组合事实"。从样本复杂度、可读性、测量可靠性、选择偏差四个角度比较两种选择，并说明你会先做哪个实验来区分它们。

## 练习提示与答案

<details>
<summary>练习 9.1</summary>

"判 S"当且仅当 $a=1$。最短析取范式和合取范式都是 $a$（1 项或 1 个子句）；决策树 2 个叶子、深度 1；决策列表 $(a\to1),(1\to0)$；阈值函数 $\mathbf{1}[a\ge1]$。所有写法都是最短的，因为这个函数只依赖一个事实。

</details>

<details>
<summary>练习 9.2</summary>

在 9.4 节的例子里，$u$ 单独的增益为 0，但 $u$ 与 $v$ 合起来完全决定结论；删掉 $u$ 后，任何规则都至少错一半。增益为 0 只说明 $u$ 单独与结论独立，不说明它在组合里没用。命题 9.6 必需的条件是：结论所依赖的奇偶集合 $A$ 中有一个没问过的变元均匀分布且与其余变元独立；若 $v$ 偏斜（例如 $\Pr(v=1)=0.8$），$u$ 单看就有增益。

</details>

<details>
<summary>练习 9.3</summary>

函数为 $f=x_1\vee(\neg x_2\wedge x_3)$，这就是一个 2-DNF。

不是 1-DNF：1-DNF 是若干文字的析取。$f(0,0,1)=1$，所以某个文字在 $(0,0,1)$ 上为真，只能是 $\neg x_1$、$\neg x_2$ 或 $x_3$。前两个在 $(0,0,0)$ 上为真，而 $f(0,0,0)=0$；$x_3$ 在 $(0,1,1)$ 上为真，而 $f(0,1,1)=0$。矛盾。

不是 1-CNF：1-CNF 是若干文字的合取（或常量 1）。$f(1,1,0)=1$ 且 $f(0,0,1)=1$，合取里的每个文字都要在这两点上为真；两点在每个变元上都不同，没有这样的文字，合取只能为空，即常量 1，但 $f(0,0,0)=0$。矛盾。

</details>

<details>
<summary>练习 9.4</summary>

$\mathrm{OR}(x_a,x_b)=-\frac12+\frac12x_a+\frac12x_b+\frac12x_ax_b$。核对：两者都不成立（$+1,+1$）时为 $1$；$x_a=-1$、$x_b=+1$ 时 $-\frac12-\frac12+\frac12-\frac12=-1$，判真。平方和 $4\times\frac14=1$。与 $x_a$ 一致的比例是 $\frac{1+1/2}{2}=\frac34$：只在"$a$ 不成立、$b$ 成立"时不一致。

</details>

<details>
<summary>练习 9.5</summary>

$f(x)=\sum_v\ell_v\prod_{j\in P_v}\frac{1+s_jx_j}{2}$。叶子 $v$ 的乘积展开后，每个 $\chi_A$（$A\subseteq P_v$）的系数是 $\pm2^{-\lvert P_v\rvert}$，乘上 $\ell_v=\pm1$ 仍是 $\pm2^{-\lvert P_v\rvert}$。$\lvert P_v\rvert\le d$，所以 $2^{-\lvert P_v\rvert}$ 是 $2^{-d}$ 的整数倍。把所有叶子的贡献加起来，每个系数仍是 $2^{-d}$ 的整数倍。

</details>

<details>
<summary>练习 9.6</summary>

$\mathrm{MAJ}_3=\mathbf{1}[x_1+x_2+x_3\ge2]$，是线性阈值函数；它不含否定的析取范式是 $(x_1\wedge x_2)\vee(x_1\wedge x_3)\vee(x_2\wedge x_3)$，所以单调。每个变元在另外两个取值不同时起决定作用，影响力都是 $1/2$。均匀分布下三个变元的增益相同且为正，贪心任选一个都有收益。换号后的展开是 $\frac12x_1+\frac12x_2+\frac12x_3-\frac12x_1x_2x_3$，一次项权重 $3/4$，三次项 $1/4$（Python 核对过）。

</details>

<details>
<summary>练习 9.7</summary>

标签：案例 1、2、6 为 1，其余为 0。第一轮：$\neg a$ 覆盖案例 7、8，都是 0，加入 $(\neg a\to0)$。剩下案例 1–6：$a$ 覆盖全部（混合），$b$ 覆盖 1、2、3（1、1、0），$\neg b$ 覆盖 4、5、6（0、0、1），$\neg a$ 不覆盖任何剩余案例，空项也混合。卡住。

加入 $p$ 后：$(\neg a\to0)$；$p$ 只覆盖案例 6，加入 $(p\to1)$；剩下 1–5，$\neg b$ 覆盖 4、5，都是 0，加入 $(\neg b\to0)$；剩下 1、2、3，它们的 $(a,b,p)$ 完全相同、标签为 1、1、0，再次卡住。原因是碰撞：事实相同、结论不同的案例，任何只看这些事实的规则都无法全部判对（第 1 章命题 1.9），样本与任何决策列表都不一致，定理 9.17 的前提不成立。

</details>

<details>
<summary>练习 9.8</summary>

查询次数 $N_2=211$，容差 $\gamma=\sqrt{0.05/211}\approx0.0154$。定理 9.11 要求 $k>\gamma^2(D-2)$，这里 $D=211$，右边 $\approx\frac{0.05}{211}\times209\approx0.0495$，而 $k=211$，远大于它，不矛盾。直观地说：次数不超过 2 的奇偶基函数只有 211 个，每次查询直接问一个，自然能问遍；下界只在候选数是指数级时才有杀伤力。

</details>

<details>
<summary>练习 9.9</summary>

开放题。一种合理的做法：时限内 +3，照片显示腐烂 +2，描述提到腐烂 +1，包装破损渗出 +2，冷链温度记录异常 +2，买家有多次可疑申请记录 −2，门槛 5 分判 S。每个事实的方向都应当有业务理由，并且能用一句话说给审核人员听。

"自提"与"运输途中腐烂"的方向会随对方翻转，任何单调的组合都写不出这条政策。保留单调性的办法是不直接用 $u$、$v$，而是读组合事实 $w$（"腐烂发生时货物在卖家一方手中"），给 $w$ 正分。代价是 $w$ 的测量更难，需要单独检验它的准确率。

</details>

<details>
<summary>练习 9.10</summary>

开放题。要点：

- 样本复杂度：深度 4 的树 $\ln\lvert\mathcal{H}\rvert$ 约为 $15\ln m+16\ln2$，比深度 2 大得多；多读一个事实只让 $m$ 加 1，但如果这个事实是看着错误案例想出来的，要按 2.10 节付选择偏差的代价，最好在留出数据上检验。
- 可读性：深一层的树往往重复子结构（9.3 节）；一个组合事实让规则变短，但要向审核人员解释这个事实的含义。
- 测量可靠性：组合事实需要语言模型做更多推理，读错的概率可能更高；树只用已有的、已经验证过的事实。
- 先做的实验：在留出数据上，检查能否找到一对（或一组）事实，使"按这一组分组"的结论纯度很高而每个事实单独的增益接近 0。这正是命题 9.6 描述的特征。找到了，就先试组合事实；找不到，说明交互结构更散，精确搜索更合适。

</details>
