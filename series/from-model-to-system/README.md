# 从模型能力到系统能力

## AI 应用中的表征、计算与学习

这组六期文档围绕同一个问题展开：一个模型具备的能力，怎样成为系统持续、可靠地解决现实问题的能力？

前三篇讨论问题怎样被表示、表达与求解；后三篇继续追问判断的根据、改动的效果，以及经验怎样成为后续任务可以使用的能力。每篇沿着具体案例展开概念和推演，可以独立阅读，也可以按顺序阅读。
