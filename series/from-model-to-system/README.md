# 从模型能力到系统能力

## AI 应用中的表征、计算与学习

模型能参与证明黎曼猜想，却会在应用里把吊牌当成衣服。这组六篇文章想回答的是：模型拥有的能力，怎样变成系统能够持续、可靠地解决现实问题的能力？

前三篇讲问题怎样被表示、被表达、被求解；后三篇追问判断凭什么成立、改动凭什么有效、经验怎样留下来。每篇围绕一个具体案例展开，可以单独读，也可以按顺序读。
