# 第 0 章　文档说明

## 0.1 这本书说明什么

本书是 [`Rajahn/engine-cli-minimal`](https://github.com/Rajahn/engine-cli-minimal) 的设计说明书。它从问题与目标讲起，逐层说明这套系统怎样从样本建立可解释的决策程序、怎样持续改进已有程序，以及每一处设计为什么是现在的样子。

仓库本身已经有面向使用者的文档：README、STATUS、`engine/docs/`、`cli/docs/` 和 `cli/iteration/*.md`。那些文档按命令和合同组织，回答"怎样调用、字段是什么、保证到哪里"。本书换一个组织方式：

- **按设计层次组织**：从目标与原则，到执行底座、数据合同、预算，再到学习、蒸馏、诊断、迭代各子系统。
- **把散落在各文档里的约束连起来**：例如"四态值不补全"同时影响谓词生成、学习器输入、导出回退和局部修复，本书在一个地方说明它为什么必须这样。
- **单列设计决策**：第 15 章用"决策、备选、理由、代价"的格式记录主要取舍。

本书只描述当前设计，不记录开发历史，也不包含改进计划。对设计的评审意见、开放问题与研究方向放在乙篇（理论篇）的相关章节里讨论。

## 0.2 对应的版本

本书描述的是 `engine-cli-minimal` 的以下版本：

| 项 | 值 |
|---|---|
| 分支与提交 | `main`，`db8c1a8` |
| 引擎与 CLI 版本 | `0.18.0` |
| 执行协议 | `execution-rpc/2` |
| 作者语言 | `v5-author/1`（展开为 core `5`） |

仓库后续变化时，以仓库内的文档和源码为准，并按新版本修订本书相应章节。书中的事实陈述都可以在仓库中找到出处；引用仓库文件时写相对于仓库根目录的路径，例如 `cli/docs/distillation.md`、`cli/iteration/fitting.py`。

## 0.3 读者与预备知识

本书面向需要理解、评审或参与这套系统设计的人。读者不需要事先读过仓库代码，但最好知道：

- JSON 和命令行的基本用法；
- "训练集、测试集、过拟合"这些机器学习常识（不熟悉时可先读乙篇第 1 章）；
- 大语言模型可以按提示回答问题，并且回答有随机性和成本。

涉及理论的地方，本书只说明结论和它在设计中的作用，推导放在乙篇。每章末尾的"延伸"一节列出对应的乙篇章节。

## 0.4 怎样阅读

| 目的 | 建议的章节 |

| 先建立整体印象 | 第 1、2 章 |

第 1 章引入一个贯穿全书的小例子（生鲜售后定责）。后续章节在讲到具体机制时，会回到这个例子上演示。

## 0.5 书写约定

- **术语**：中文术语后面第一次出现时附仓库中的英文标识，例如"四态值（known、unknown、absent、error）"。完整对照见附录 E。
- **标识与路径**：命令、字段名、算法 ID、文件路径用等宽字体，例如 `distill`、`nonknown_fallback`、`partition-refinement-tree/1`。
- **"服务"与"CLI"**：本书中"执行服务"或"服务"指 `engine/` 提供的执行侧；"CLI"指 `cli/` 下的 Java 分析命令；"宿主"指 `cli/iteration/` 下的 Python 流程（迭代宿主、交替蒸馏宿主、管线）。
- **示例**：示例中的地址使用保留示例域名 `example.invalid`，模型标识使用虚构值（如 `example-model@1`），金额和次数只示意格式。
