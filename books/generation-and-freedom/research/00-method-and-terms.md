# 研究方法与共同术语

本文件规定《生成与自由：计算、主体与社会的理论》第一版的概念用法与证据标准。它是正文的研究说明，不替代正文论证。

## 研究问题

有限而相互依赖的过程，怎样形成能够维持自身的组织；组织怎样产生记录、意义、行动与自我描述；人的语言、技术和制度怎样把这些能力转化为历史；历史地形成的人怎样获得参与形成和修订自身生活条件的能力与地位。

本书把数学与计算放在理论基础中，把二阶控制论理解为观察者属于被研究世界这一关系的研究。反身性是需要解释的一种关系，不能单独承担整个理论。

## 共同术语

| 术语 | 本书用法 |
| --- | --- |
| 过程 | 随时间发生、具有物质实现条件的变化。用数学描述过程，不等于已经证明宇宙是一台数字计算机。 |
| 约束 | 限定变化方式的条件。约束既可能阻断活动，也可能使稳定、可组合的活动成为可能。 |
| 组织 | 若干过程在相互作用中形成、并通过特定关系持续存在的安排。持续存在并非所有组织的唯一目的。 |
| 记录 | 过去的活动留下、能够影响后来活动的相对持久差异。记录不自动等于记忆或意义。 |
| 表征 | 在特定活动中代替对象、支持某类区分和操作的结构。表征必然具有选择性，其适用性取决于所支持的任务。 |
| 意义 | 某种差异在一个组织的活动、维持或社会使用中获得的相关性。信息量与意义不能互相替代。 |
| 主体 | 能够形成相对持续的活动边界、根据自身处境调节行动，并在人的情形中形成和修订自我描述、承担理由关系的组织。这里的功能分析不声称解决了现象意识。 |
| 技术外化 | 活动的组织方式、知识和能力被稳定在身体之外的材料、符号、装置与协作关系中，并改变后来活动的条件。 |
| 制度 | 在持续实践、期待、认可与执行中再生产的公共行动规则及其地位安排。制度的稳定不等于制度正当。 |
| 权力 | 改变他人或共同活动条件的关系性能力，包括安排议程、分配资源、规定资格、实施强制与控制可见性。 |
| 自由 | 人参与形成、维持与修订自身目的及共同生活条件的有效能力与地位。本书进一步论证其物质条件、相互承认与防止支配的要求。它是待展开和可修订的概念，不能由一个数值完全代替。 |
| 历史性 | 过去的活动改变后来活动的物质、符号和制度条件；当下行动者及其概念也在这一过程中形成。 |

## 区分四类论断

1. **形式命题**：写清对象、量词和假设，给出证明与反例边界。形式结论的社会应用需要另行论证对应关系。
2. **机制解释**：说明谁通过什么活动改变什么条件，给出与竞争解释不同的可观察后果。
3. **经验判断**：保留数据时间、地域、样本与识别限制。观察到相关变化不等于识别了因果效应。
4. **规范主张**：明确所承担的价值承诺和可辩护的理由，不把历史来源、生存效果或数学可行性直接写成道德正当性。

正文中的构造例子只用于说明机制，不作为经验事实。预测是带时间范围和修订信号的判断，不是必然历史规律。

## 跨部论证次序

第一部说明过程、计算、观察、尺度、可达性、维持与规则变换的形式基础。第二部说明组织、意义与主体的形成。第三部说明语言、技术、规范和制度如何积累为历史。第四、五部据此分别研究经济与政治的特殊机制。第六部论证自由、价值与共同生活。第七部才将前述理论用于 AI 时代的变化、判断与制度实践。

## 必须避免的概念跳跃

- 复杂性增加，不自动推出意识出现，更不自动推出道德地位。
- 人受社会条件塑造，不推出人的行动没有因果作用。
- 生存压力、反思能力和资源占有的差异，不推出社会地位天然应当不平等。
- 不预设反思能力服从正态分布，也不预设权力与能力的错配必然自行纠正。
- 生产能力的扩展，不自动推出劳动收入、政治参与或共同自由同步扩展。
- 不把所有历史变化压缩为一条技术决定的阶段序列。
- 把冲突写成约束不相容，并不取消强制、损失及其承担者。
- 价值的历史形成与价值的正当性分别论证；互惠、平等地位等承诺不能假装来自热力学定律。

各部使用独立编号：I-01、II-01，依此类推。正文以 `〔I-01〕` 标注，并在本部调研文件中给出作者、年份、题名、稳定链接、所支持的具体论断及不能据此推出的结论。以原始论文、著作原文和机构报告为主。研究截止时间为 2026 年 11 月 28 日；经典文献的解释与当代经验材料分开标明。

本书的综合框架与例子由本稿提出。已有的概念、命题和机制按来源归属，避免把重新组织写成首次发现。理论的解释力以能否保留关键区别、提出可核对的机制和允许修订来评价。
