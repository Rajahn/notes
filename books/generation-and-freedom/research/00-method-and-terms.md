# 研究方法与共同术语

本文件规定《生成与自由：计算、主体与社会的理论》第二版的概念用法、理论比较和证据标准。它是研究说明，正文承担具体论证。研究截止日期为 2026 年 11 月 28 日。

## 一　共同研究对象

本书研究活动如何形成自己的条件，这些条件如何形成后来活动者，以及活动者如何获得修订条件的能力与地位。对象包括物质实现、记录使用、组织维持、目的形成、社会继承、生产、权力和规范。统一来自问题之间可说明的连接，不来自把全部对象改称为同一种系统。

理论采用的基本次序是：明确实际过程与形式表示的对应；说明组织通过什么关系维持；说明差异怎样进入行动与意义；说明行动者和共同规则怎样历史地形成；分析生活条件及修订权如何分配；最后论证共同自由并用于 AI 时代。各层增加新的解释责任，不能仅由前一层的名词替代。

## 二　共同术语

| 术语 | 本书用法及必要区别 |
| --- | --- |
| 过程 | 有实现条件的变化。数学状态是对过程的表示，不等于未经论证的世界本体。 |
| 约束 | 限定变化方式的条件；既可能阻断活动，也可能使稳定、组合和合作成为可能。 |
| 组织 | 若干过程相互提供条件、通过一定关系持续发生的安排。并非所有稳定过程都是自主组织。 |
| 记录 | 过去活动留下、能够影响后来活动的相对持久差异；只有通过使用才能形成具体记忆作用。 |
| 表征 | 在特定活动中代替对象并支持区分和操作的结构；其适用性需要按任务与代价检验。 |
| 意义 | 差异在组织活动、维持和社会使用中的相关性；信息量、功能意义与公共理由分别分析。 |
| 主体 | 能够形成相对持续的活动边界并根据处境调节行动的组织；人的主体还涉及自我描述、理由和社会地位。功能分析不等于现象意识的充分理论。 |
| 技术外化 | 活动的一部分组织稳定在材料、符号与协作安排中，使能力可以传承、组合并在新关系中重新形成。 |
| 制度 | 在实践、期待、认可和执行中再生产的公共规则及地位安排；文字规则、习惯和实际资格并非同一层次。 |
| 再生产 | 使活动得以继续的材料、能力、关系和规则被补充、维持或重新形成；包括照护与训练，不能只计当期产出。 |
| 权力 | 改变他人或共同活动条件的关系性能力；机制包括资源依赖、议程、资格、强制、可见性与目的形成。 |
| 自由 | 人参与形成、维持与修订自身目的及共同生活条件的有效能力与地位。维持可信承诺与获得修订途径同样重要。 |
| 历史性 | 过去活动改变后来者的起点，后来者又通过继承、使用与冲突改变这些条件；概念本身也属于这一过程。 |
| 二阶关系 | 观察、分类和干预者属于其研究对象，并改变后续对象及证据；必须进一步解释观察者、目标与权限的形成。 |

术语应减少解释负担。如果同一段内容用日常词语即可准确表达，不为显示统一而重复命名。“生成”不能代替形成机制，“历史”不能代替传承载体，“反身性”不能代替后果如何返回行动的具体路径。

## 三　四种论断及其不同责任

**形式命题**写清对象、假设与量词，给出证明或明确的构造。有限、完全观察、确定性、固定规则等条件不得在应用时悄然消失。枚举与数值检查只能检查相应实例；一般结论仍依赖证明。

**机制解释**说明什么行动者或过程，通过何种资源、记录、约束或规则改变哪些后果。机制必须允许辨认竞争解释。例如招聘减少可能来自替代，也可能来自业务萎缩；需要可区分的联合观察，不能只对同一数字重新命名。

**经验判断**区分材料来源、时间窗口、地域、样本、测量口径与识别范围。论文发表年不等于数据发生年，观察性差异不等于已排除所有替代原因，实验的局部效果也不能直接给出普遍制度结论。

**规范主张**说明理由、受影响者与冲突。功能维持可以解释一种规范的形成，却不能独自赋予它正当性。平等回应、基本地位和共同自由需给出积极论证，同时面对依赖、非互惠和家长主义等反例。

这四种论断相互连接。例如形式条件帮助识别机制缺口，经验材料帮助检验机制，规范理由决定哪类结果需要改变；但一种论断的成功不能充当另一种论断的证明。

## 四　怎样建立跨层连接

从模型进入现实，至少检查三个问题。第一，状态和动作分别指什么，有没有删去会改变判断的差异；第二，系统边界外的资源、劳动和权力是否实际上承担关键作用；第三，模型中的规则在现实里是固定的，还是参与者可以改变的对象。

从组织进入主体，需要说明调节、记录和目的怎样依赖组织自身活动，不能因装置有反馈就称它拥有完整主体性。从主体进入社会，需要说明语言、纠错、授权和承认如何形成公共关系，不能把多人行为相似当作共同规范已经成立。

从共同能力进入分配，需要说明产权、资格、合同、议价与财政。技术上存在的东西可能无法取得，法律上的权利也可能缺少实物和执行条件。经济与政治的区分在这里体现为不同问题：生活条件怎样被生产和取得，改变这些条件的权力怎样形成和执行。

从历史形成进入自由，需要说明为什么一个受共同规则影响的人具有要求回应的地位，并处理不能直接表达者的支持与代表。社会依赖使这一规范问题出现，但“存在依赖”本身不是完整伦理证明。

## 五　理论比较怎样避免弱化对手

每次比较先确定共同问题，再呈现竞争理论最有解释力的版本，随后指出它依赖哪些条件、解释何种结果，以及本书增加了什么关系。不能用一个传统的简化口号与本书的完整机制比较。

例如，价格的信息作用与知识生产成本可以同时重要；个体选择与制度形成可以解释不同环节；共同认可与强制能力可以相互支持；消极自由对家长主义的警惕与实际能力对贫困的关注，需要在同一具体安排上检验。

一种综合若只是把已有结论并列，应该如实称为整理。只有当新增联系能区分先前难以区分的结果、修正原有判断、解释反例或形成可检验预测时，才取得解释增量。第二版围绕这些要求重写章节，新增文献为争点服务。

## 六　构造、历史材料与未来判断

构造例子用于展示可能机制，正文明确使用“设想”“构造”或写明参数假定。它们可以证明某种逻辑关系能够发生，不能证明发生频率。数学模型中的参数若没有实际估计，就不写成现实时间和政策最优值。

历史材料要区分事件、作者解释与本书重构。对经典的使用既保留原有问题，也允许提出新的比较；不将当代计算术语追溯成作者实际使用的概念。跨尺度相似也不等于严格同构，除非给出映射及保留的关系。

预测必须确定范围、方向、时间和修订条件。第七部的六项预测属于机制支持的研究判断；“较强”“中等”不是统计概率。后续版本保存原预测，在新材料出现时改变相应判断，不通过调整原对象维持事后正确。

## 七　文献范围、引用和版本

正文采用部内编号，例如“〔I-03〕”。各部研究札记列出作者、年份、题名、原始链接、使用范围及实际访问程度。不同部可以引用同一作品；因此“部内参考条目数”不等于互不重复的作品数。

研究以原始论文、著作、作者提供的版本和机构材料为主。只有摘要或目录可得时，明确限制归属；不借未读文本的权威补足自己的论证。经典文本的翻译和刊行年份，以及当代工作论文的修订日期分别记录。

本书的概念综合、构造和未来判断按本稿承担责任。已有数学思想和成熟机制保留来源，不把重新组织写成首次发现。第二版的实质变化见 [逐章修订说明](10-v2-revision.md)，核查范围见 [校订记录](09-editorial-review.md)。
