# 第二版校订与核查记录

版本：2.0。研究截止日期：2026 年 11 月 28 日。第一版保存在提交 [9c1d29a](https://github.com/Rajahn/notes/tree/9c1d29a6c527859587e72d066fa5fe5b941df2c6/books/generation-and-freedom)；逐章改动见[第二版修订说明](10-v2-revision.md)。

## 一　完成范围与版本含义

第二版保持七部、37 章正文，以及导论、结语的结构，逐章扩展问题、竞争解释、机制、推导和反例。七部各有独立文献调研；共同术语、思想对话总表、校订记录和逐章修订说明共同构成研究附录。逐章文件是正文来源，合订稿由同一组文件生成。实际汉字数、分部规模、引用条目数及章节校验值见 [STATS.json](../STATS.json)。

这一版的完成，指全部篇章已写成连续论述，并完成所列范围的核查。它不等于跨学科解释已经获得经验确认，也不等于复杂的哲学争议已被公式解决。新增篇幅的作用，是使读者能够检查每一步增加了什么理由、依赖什么条件、面对什么竞争解释。解释优势应由具体争点中的表现确认，不能由全书的覆盖面预先宣布。

## 二　形式推导的审读范围

第一部保留并扩展了有限观察下的行动判准、粗粒化闭包、有限维持核。第二版进一步区分保证与平均表现，给出信息加工下策略可模拟的方向、观察细化与动态闭包的不同性质、近似误差传播、扰动量词和部分观察下的知识状态。相关推导各自标出有限性、可用信息、动作时序和评价函数，避免把一种模型的结论直接推广到另一种模型。

第二部还给出维修资源的阈值推导、任务相关历史等价类的记忆下界及构造、变分推断恒等式，以及自我估计影响练习和能力的收敛模型。经典构造注明理论来源；书中自行设计的例子说明其隔离的机制，不把数值设定冒充调查资料。

形式审读特别检查了几个容易混淆的关系：

- 信息更丰富可以允许更多决策策略，却不保证新增宏观变量具有闭合动力学；观察的两个用途需要分别证明。
- 全局存在共同解，不保证各参与者凭各自信息能够执行它。异或协调例子需要双方交换读数，或把结果回传；单向传递只能使接收者取得相应知识。
- 固定点存在、最优配置、动态收敛和分配正当性是不同结论。第 21 章的福利命题采用明确的纯交换条件；第 23 章债务网络的最大清算向量构造不冒充无条件唯一性。
- 逻辑擦除的标准热量下界与总不可逆熵产生不能混同；计算步骤数也不能直接换算成普遍适用的实际耗能。
- 第 34 章复核选择的解受到可用复核时间、工资、可避免错误及损失口径限制。私人损失参数不自动包括全部社会损害。
- 独立错误与共同错误可以有相同预期总损失、不同损失方差；相关性不能只用一句“可靠性更低”概括。
- 第 34 章需求模型把生产率写成相对基期的无量纲倍数，并保留基期单位工时，避免量纲含混。第 35 章区分维持门槛的必要进入量、初始能力条件与从低位恢复的路径；AI 改变训练效率或所需能力时，需要重新估计这些量。
- 第 37 章现金约束排除资产收入重复，并明示现金余额及其他融资的简化条件。延迟控制和施为性预测分别说明两个具体机制：前者不是宏观治理的通用稳定定理，后者的损失函数也不自动提供伦理标准。

第 23 章需求调整模型保留零乘子的边界：在正文参数范围内，调整系数位于 $[0,1)$，包括一步到达均衡的特殊情况。对边界值和量词的修订不会只停在脚注中，而同步进入正文解释。

## 三　独立有限实例核查

核查程序采用与正文推导不同的枚举或比较方式，帮助发现有限情形中的错误。结果如下：

| 对象 | 核查规模 | 方法与结果 |
| --- | ---: | --- |
| 观察行动可行性 | 512 个实例 | 穷举 3 状态、2 动作下的二值观察和可接受动作集合；直接枚举策略，与交集判准比较，全部一致。 |
| 确定性粗粒化闭包 | 216 个实例 | 穷举 3 状态转移及二值观察；直接枚举粗规则，与同类后继条件比较，全部一致。 |
| 有限确定性维持核 | 6,856 个实例 | 比较递减集合算法与独立的可达循环判定，覆盖不同安全集和可用动作，全部一致。 |
| 一周期延迟控制 | 71 个参数点 | 计算特征根，与正文严格稳定区间比较，全部一致。 |
| 复核时间的成本选择 | 144 组参数 | 将解析最优解与独立成本网格比较，覆盖零可避免损失、零复核及时间上限等情形，结果一致。 |
| 独立错误与共同错误 | 20 组分布 | 直接枚举错误组合，以精确分数计算矩，核对预期损失和方差关系。 |
| 能力存量递推 | 288 个时点 | 以精确分数逐期递推，与闭式解比较，覆盖不同折损、培养、进入率和初值，全部一致。 |
| 第 34、37 章数值例子 | 逐项复算 | 替代成本、收入和施为性风险的数值一致。 |

这些检查共覆盖 8,107 个表列实例或参数时点，另有数值例子。计数不能作为理论可信程度的评分：一个例子可能发现错误，再多有限例子也不构成一般证明。部分观察下的维持、随机闭包和其他新增结论以正文推导为依据，本程序没有穷举验证这些更大的范围。

复现命令：

```bash
python books/generation-and-freedom/tools/check_formal_examples.py
```

## 四　跨部概念与理论对话

自由的正式定义继续保留“形成、维持与修订”。有效能力不能代替主体地位，地位也不能代替实际支持。稳定投入、可信承诺和不必持续反思每个生活选择，都进入自由的评价；不能把永久自我改造规定为自由者的义务。

外化统一理解为活动组织稳定在材料、符号和协作安排中，使能力得以传承、组合并重新形成。语言、工具与制度不是已经完成的人类本性的被动附件；但这种共同形成也不能独自证明现象体验如何产生。组织维持、功能意义、公共理由、能动性与规范自由分别承担不同的解释任务。

历史与主体之间使用可比较的机制，不未经证明宣称数学同构。工作日立法案例区分权利要求、组织、记录与执行，并保留受保护类别的历史范围。技术对可行性的改变、规范理由的扩展和政治行动相互连接，不把社会变化写成生产能力自动选择最优制度的过程。

理论对话采用竞争解释的较强版本。资源论不被缩成金钱数量，市场知识论不被缩成所有人都理性，制度与政治不被缩成国家纠正个人错误，二阶控制论不被缩成一般反馈。这些理论已有的解释力被明确保留；本书增加的关系和受到的反驳也分别写出。

规范部分进一步说明平等回应为何值得坚持，同时承认这是一项需要理由的规范承诺。照护、不能互惠者和反对共同原则者都进入讨论。数学中的对称性、系统的生存效率或历史中的成功，均不被当作平等地位已经得到证明的替代物。

## 五　文献、版本与经验范围

各部调研列出原始来源、具体使用范围及访问边界。部内编号便于逐部阅读，同一作品可能出现在不同部，因此条目总数不等于互不重复的著作数。引用较多也不代表对某一传统已经作出穷尽研究。

文献核对区分原始出版、重印、翻译和工作论文修订。只有作者摘要、出版社介绍或目录可以取得的来源，明确记录这一限制，不以它们支持尚未读取的细节。经典著作的自建解释与作者原意分别表述；正文中的有限构造与例子也标明其作用，不借文献权威替代证明。

第七部区分研究发布日期、数据窗口和预测时间窗。丹麦论文的 2026 年版本使用到 2024 年底的劳动记录；美国青年就业研究的相对差距不能改写成裁员比例；澳大利亚材料区分本国结果与国际讨论。任务暴露、基准任务表现、实际采用、组织变化和就业结果分别处理。

新纳入的增长模型说明不同假设下的机制，不被当作确定的时间预测；2026 年的变革性 AI 情景报告明确属于情景分析。教育实验用于区分辅助完成表现与离开辅助后的学习，不能直接推广到所有学校和专业训练。基本收入试验同时记录执行范围、制度背景与识别限制，不据小规模试验断言全国财政和宏观效果。
