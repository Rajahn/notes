# 第一版校订与核查记录

版本：1.0。研究截止日期：2026 年 11 月 28 日。

## 完成范围

第一版包含七部、37 章正文，以及导论、结语。七部各有独立文献调研，另附共同术语、思想对话总表和本记录。逐章文件构成正文来源；合订稿由同一组来源生成。实际汉字数、分部规模、引用条目数及章节校验值见 [STATS.json](../STATS.json)。

这里的“完整”指七部的研究安排和正文论证均已展开，没有以章节提纲代替正文。书稿属于可继续发展和批评的理论第一版；解释优势、历史机制与未来判断仍需要研究共同体和后续材料检验。

## 一　形式推导与数值核查

第 3—5 章的观察行动判准、确定性粗粒化闭包和有限确定性维持核，均给出完整证明。核对特别关注量词、观察范围、有限性和策略所能使用的信息。部分观察、外部扰动、连续状态及近似模型没有被冒充为这些命题已经覆盖的对象。

独立的有限实例核查结果如下：

| 对象 | 核查规模 | 方法与结果 |
| --- | ---: | --- |
| 观察行动可行性 | 512 个实例 | 穷举 3 状态、2 动作下的二值观察和可接受动作集合；直接枚举策略，与交集判准比较，全部一致。 |
| 粗粒化闭包 | 216 个实例 | 穷举 3 状态确定性转移及二值观察；直接枚举粗规则，与同类后继条件比较，全部一致。 |
| 有限维持核 | 6,856 个实例 | 比较递减集合算法与独立的可达循环判定；覆盖 2 状态下变化的可用动作，以及 3 状态下两个动作全可用的情况，全部一致。 |
| 一周期延迟控制 | 71 个参数点 | 计算特征根，与正文的严格稳定区间比较，全部一致。 |
| 第 34、37 章算例 | 逐项复算 | 替代成本、工时、收入、稳定风险与部署风险的计算一致。 |

这些枚举为书稿校订提供有限范围的独立检查，不能代替一般证明。复现命令：

```bash
python books/generation-and-freedom/tools/check_formal_examples.py
```

## 二　交叉审读中已完成的实质修订

1. **自由定义保留维持。** 导论、共同术语、书稿首页与第六部采用同一正式定义。目的的持续投入、可信支持和不必不断反思自身生活，同样进入自由。
2. **外化包含能力的重新形成。** 导论改为活动组织稳定在材料、符号与协作安排中，避免暗示已经完整存在的能力只是从身体内搬到身体外。
3. **退出成本分别评价。** 结语区分合理承诺及其转换成本，与任意阻断修订、无法质疑的退出负担。
4. **生产线模型补全条件。** 第 20 章的瓶颈等式限定为投入充足、可协调节拍、具有必要周转条件的理想稳态最大速度；实际速度可能更低，首日与稳态分开。
5. **需求模型明确静态性质。** 第 23 章写明消费参数范围及静态均衡假设，没有将代数关系冒充经济的实际时间路径。
6. **实际收入采用一致价格口径。** 第 34 章的劳动收入与增加值在同一实际价格口径下计算。
7. **分红截断不掩盖融资缺口。** 第 37 章补明收益少于必须留存时，即使分红为零仍需要其他资金或调整投入。
8. **训练均值与有限样本分开。** 第 37 章的施为性例子明确使用总体均值更新，并说明每个固定部署参数下扰动的矩条件。

组织、意义、主体与经济政治的衔接经过独立审读；导论、结语与自由论的衔接也经过独立审读。修订保留组织维持、功能规范、现象体验、能动性和规范自由之间的差别。

## 三　文献版本与证据范围

文献调研记录原始来源和具体使用范围，使用同一作品的不同部分时保留部内编号。部内条目数包含重复作品，不能当作互不相同的独立来源数量。

本轮校订核对了 Pask 论文集的会议年与出版年、Hegel 相关译本及节号、Dewey 转录页标题与章节、Clark 和 Chalmers 作者页与期刊分页的差异。个别著作只能取得作者摘要、出版社介绍或目录时，调研明确记录访问程度；本稿自行证明的有限命题没有借未读原著的权威代替推导。

第七部将研究发布日期与数据窗口分开。丹麦论文的 2026 年版本使用到 2024 年底的劳动记录；美国青年就业的 2026 年修订是描述性比较；澳大利亚材料区分本国结果与国际综述。任务暴露、实际采用和就业结果分别使用，没有把职业暴露比例当作实际裁员比例。

预测截止后的材料不追溯性地写入第一版。未来修订应记录新增资料和改变了哪一项判断。

## 四　装订与阅读检查

合订程序检查 39 个正文文件是否齐全、每章是否有实质篇幅、引文编号是否有定义、展示公式分隔符是否配对，以及 Markdown 本地链接是否指向现有文件。章节采用统一的中文章号，并提供上一章、目录、下一章及本部文献入口。

合订文件中的相对链接会按其新位置重写，正文与调研内容来自同一组源文件。程序不会核验外部网站未来是否持续开放，也不会把排版检查当成论证验证。

```bash
python books/generation-and-freedom/tools/assemble.py
```

形式错误应直接修正，并说明被影响的论证。经验判断的修订应保留原版本、观察窗口和新材料。规范争议应呈现理由及其对具体处境的影响，不能仅以流行术语替换原有概念。
