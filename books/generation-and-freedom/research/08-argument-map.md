# 论证与思想对话总表

本表供读者检查全书的论证连接。第二版将比较从“接受某个思想、再补充某个思想”推进到共同问题上的竞争解释。章节的完整论证、原典范围与经验材料分别见正文及各部调研。

## 一　全书的中心关系

活动在既有条件中发生，又将材料、记录、技能和规则留给后来活动。后来者通过这些条件形成主体、目的与能力，再参与维持或改变条件。经济研究生活条件怎样被生产和取得，政治研究改变共同条件的权力怎样形成和执行，自由论追问每个人怎样成为这些形成与修订过程的有效参与者。

这一结构包含三项彼此关联但不相同的解释：**能力的实现、条件的再生产、修订地位的分配**。它们分别需要物质与计算条件、持续组织机制和权利理由。一个环节的进步可以扩大另一个环节的可能，也可能在新的依赖中被限制。

本书希望取得的统一，是让领域之间的转换具有可检查的位置。它不宣称用一套总方程取代所有专业理论，也不把规范结论藏进“系统更复杂”的描述中。

## 二　六处连接及其证明责任

| 连接 | 正文的具体推进 | 哪种反例会要求修订 |
| --- | --- | --- |
| 物质过程到计算表示 | 实现需要支持相应操作与反事实，不只给一段轨迹贴标签；有限时间和存储进入计算对象 | 同一形式结构在不同实现中产生不同关键行为，而模型没有表达差异 |
| 组织维持到意义与行动 | 区分耗散的持续、约束互相维持、记录使用、相关性及可调节行动 | 所谓意义只是研究者赋予的功能名词，没有说明它怎样进入组织的实际选择 |
| 个体活动到公共历史 | 从纠错、授权、技术载体和制度资格说明经验如何跨人、跨代接续 | 行为相似却没有共同规范，或记录仍在而使用和执行关系已经断裂 |
| 共同能力到经济分配 | 区分需要、支付、产权、投资、照护与训练；权利改变资源能否被实际取得 | 把产出改善当作普遍福利，遗漏收入入口和再生产条件的损耗 |
| 社会组织到政治权力 | 把依赖、议程、合法性、行政执行和组织冲突分开；解释稳定如何不等于公共优越 | 只见服从就推断认可，或假定低效制度必然被更优者淘汰 |
| 历史主体到共同自由 | 论证受影响者的回应地位，纳入依赖、支持、稳定承诺与目的修订 | 以反思能力高低决定基本地位，或将保护变成当事人无法质疑的支配 |

第七部将这些连接用于 AI：可复制技术怎样获得执行能力，采用怎样改变任务与收入，训练怎样被补充，受影响者怎样参与制度修订。每次跨层都增加现实对应和理由，不能靠相同符号把问题省略。

## 三　与既有理论的强版本比较

### 1. 黑格尔：制度中的自由与内在批判

黑格尔使个人自由与共同制度相联系，并要求从一种形态自身的承诺理解其不足。〔III-06；III-21；VI-12〕本书使用这一问题意识，比较一个制度声称提供什么与它实际需要哪些条件：若一项权利在实施中不断被自己的资格规则阻断，矛盾就可以有明确对象。

改写在于把实现、观察、资源和执行结构展开，使“未能实现自身要求”进一步成为可分析的机制。内在张力并不单独保证新制度出现；还需解释组织、联盟、可行替代和转换成本。第十八章将思想层次与工作日的具体历史分析区分又连接。

### 2. 马克思：生产条件与人的再生产

马克思将生产、社会关系和历史行动放在共同问题中，人的活动同时改变物质条件并再生产一定关系中的人。〔IV-01；IV-07；III-08〕本书据此拒绝把技术当作社会之外的独立原因，也拒绝把经济缩成既定物品的事后分配。

本书增加的连接集中在记录、观察、能力形成与修订权：共同知识可以被外化，却不因此共同掌握；当前产出可以增长，却消耗训练和照护；一种制度可以扩大生产，却保留无法质疑的依赖。这些问题与马克思传统有连续性，是否构成解释改进，要看机制是否比已有分析更清楚，而非是否换了词语。

### 3. 控制论：从调节到调节者的形成

Ashby 的调节问题要求区分扰动、观察和可用行动，二阶控制论把观察者的活动也纳入描述。〔I-03；I-08；II-09〕第二版进一步处理观察细化、动力学闭包与维持可行性的差别，避免把“更多信息总更好”当作无条件规律。

社会应用还需解释目标由谁形成、观察者靠什么资源维持、哪些主体可以改动分类。反馈稳定与目标合理是不同问题；第 37 章的延迟控制和施为性构造将这种区别具体化。政治和伦理由此不是控制器之外的注脚，而是控制活动本身的形成条件。

### 4. 生命与认知理论：功能、意义和公共理由

自创生、约束闭包、适应性和行动生成研究，对组织边界与功能规范给出不同解释。〔II-02；II-03；II-04；II-05〕它们使“某个信号对系统重要”获得比外部比喻更明确的基础。

人的意义还涉及可以共同纠正的用法、理由和地位。因此，第二部的组织论与第三部的语言论需要衔接：有利于维持的差异可以解释功能相关性，不能独自解释一项承诺为何使他人有资格要求履行。扩展认知也需要说明材料如何在实践中参与能力，而非把所有环境条件都称为心灵。

第二版进一步对读感觉运动理论、主动推断、延展心灵及其机制论反对意见。〔II-13；II-19；II-08；II-16〕比较落在可区分的问题上：行动怎样改变可取得的信息，精确后验为何仍可能属于错误模型，外部材料何时承担任务内容而不只是背景条件。记忆下界和自我估计反馈的构造，使主体形成不再只由概念之间的递进说明，而获得可以核对的局部机制。

### 5. 语言与制度理论：使用、授权和再生产

规则跟随强调可纠错的共同实践，施为分析揭示话语改变公共关系需要适当条件；制度地位理论、惯习与资本研究、系统论和路径依赖则各自突出不同机制。〔III-11；III-12；III-17；III-18；III-19；III-20〕

本书用贯穿案例比较这些机制：同一句话为何在不同位置有不同效力，同一份证书为何不能自动转成能力，同一规则为何可以在文字不变时改变实际作用。所谓制度不是一种单一材料，而是不同机制在具体活动中的连接。这个连接是否稳定，需要观察训练、期待、资源和执行。

### 6. 经济理论：稀缺选择、知识生产与共同维护

稀缺选择解释相互竞争用途，生计组织解释生活的实际维持，分工和递增收益解释能力如何在协作中生成。它们不必互相否定，但各自单独使用会留下不同问题。第四部将需要、有效需求、真实资源与资格分别分析。

价格可以传播分散知识，生产知识却有成本；产权可以激励投资，也决定剩余控制和议价；交易费用可以说明组织边界，却不能单独评价分配。第二版用共同生产、价格调整、福利命题、资本关系和危机链条展开这些分歧。均衡存在、配置效率、动态收敛与公平各自有条件，不以其中一个结果替代其他结果。

### 7. 政治理论：可见决定与条件形成

Dahl 的决定关系、Emerson 的依赖、Bachrach 与 Baratz 的议程控制及 Foucault 的主体形成，揭示权力的不同位置。〔V-01；V-02；V-03；V-04〕第五部继续比较强制、共同支持、基础设施能力和合法性，使权力分析既能解释明显冲突，也能解释问题为何未进入公共决定。

本书的推进是把这些机制接到替代来源、执行结构和修订费用。制度选择可能选择最有利于维持权力的安排，而非最有利于共同生活的安排；不满也需要组织和资源才能改变规则。由此能够解释能力与权力的长期错配，而不预设它会自动向某个公正均值回归。

### 8. 自由理论：选项、能力、地位与形成史

消极自由对干涉的警惕、Rawls 对基本自由及其价值的区分、Sen 的能力、Pettit 的非支配与 Honneth 的社会自由，为同一处境提出不同检查。〔VI-15；VI-16；VI-01；VI-02；VI-05〕第六部以目的形成、历史认同、照护和不可修订等级为核心争点，而非给传统分别贴标签。

本书的定义将这些问题组织起来，但不因维度更多就自动优越。它必须解释：何时支持能够扩大自由，何时支持变成支配；何时稳定承诺值得维持，何时承诺的形成条件要求重审；为何不能充分反思的人仍具有基本地位。自由也不能把真理、照护等价值全部化为可替换数量。

### 9. AI 经济与社会技术研究：从平均效应到功能连接

任务模型、增长瓶颈、专家能力扩散、转职摩擦和施为性预测已经提供不同解释。〔VII-07；VII-11；VII-12；VII-13；VII-14；VII-23；VII-08〕本书承接这些研究，进一步追踪能力取得、采用、收益、训练与公共资格如何按不同速度变化。

第 34—35 章的完整成本、复核选择、需求吸收与能力存量模型，具体说明这些转换。第 36 章预测变化次序，第 37 章比较保障、服务、资产与治理。新的贡献若成立，应体现为更早识别功能失配和更准确确定修订对象，而不是声称 AI 使所有旧理论立即失效。

## 四　形式推导在论证中承担什么

| 形式对象 | 对应理论问题 | 不由其直接决定的问题 |
| --- | --- | --- |
| 实现与可计算性 | 一段过程何以是特定计算，有限资源限制何种操作 | 宇宙是否唯一采用某种计算本体，意识的充分条件 |
| 观察与行动交集 | 现有分类是否保存取得可接受行动所需的区别 | 哪些社会结果应被视为可接受 |
| 动力学闭包与误差 | 粗表示何时支持预测，近似误差怎样传播 | 一个统计尺度是否适合所有公共用途 |
| 维持核与信息状态 | 什么状态能够持续保留可行行动，观察限制如何改变策略 | 值得维持哪一种组织与生活 |
| 联合可行与协调 | 相容方案与分散执行之间为何存在距离 | 谁应承担协调代价，谁有决定资格 |
| 维修资源阈值 | 循环依赖在什么速率条件下足以支持正的持续状态 | 一个抽象维修系统是否已经构成生命或主体 |
| 历史等价类与记忆 | 固定任务为何要求至少保留某些历史差别，怎样构造相应记忆 | 哪些未来问题值得为其保存资料，怎样取得低成本实现 |
| 变分推断恒等式 | 给定模型与观察时，近似后验怎样接近模型后验 | 模型是否真实、偏好何以形成、是否具有体验 |
| 自我估计与练习反馈 | 描述怎样通过投入影响后来能力，并在收敛后得到表现支持 | 人的表现是否普遍由信心决定、初始描述是否正当 |
| 价格、生产与网络模型 | 局部互动如何收敛、扩散或受瓶颈限制 | 既有产权和分配是否正当 |
| 采用与能力再生产 | 技术何时具有私人采用吸引力，训练能否补充能力 | 私人收益是否充分反映社会代价 |
| 延迟与施为性反馈 | 稳定区间、自洽训练与整体风险的区别 | 指标和损失定义的公共正当性 |

这些命题主要使用已有数学思想，本稿自行展开证明和与问题相配的构造。它们是理论的基础部分，不被宣称为全部新的数学发现。

## 五　解释增量怎样被检验

本书需要在三个层次接受比较。**概念层次**看是否去除了真实混淆，例如将技能、资格和责任分开；**机制层次**看是否说明了同一表象的不同来源，例如价格传递与知识生产、增长与能力耗损；**判断层次**看是否产生原先不明确的可观察次序与可修订预测。

如果一种综合只使每个现象都多出几种可能说法，却不能决定应观察什么，它就没有完成工作。如果一个新增术语没有增加区别，应删除术语。如果所谓共同形式不能保留领域中关键关系，应缩小适用范围。

宏大的理论尺度与这种逐项责任相容。前者要求问题彼此连接，后者要求连接有内容。本书对自己最强的要求，正是让两者同时成立。
